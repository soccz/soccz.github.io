경로 / vkospi_external_state

경로 검수 완료

VKOSPI·외부 상태변수

VKOSPI 기반 외부 signal이 내부 WML history만 쓴 전략보다 실시간 순경제가치를 주는가, 그리고 이를 별도 미래분산 forecast로 시험할 경우 forecast gate도 통과하는가?

이 경로를 시작할 때

  • WML 자체 history 밖의 forward-looking 또는 시장상태 변수를 추가한다.
  • VKOSPI 등 외부자료의 PIT 가용성과 비용을 감사할 수 있다.

읽기와 판단 순서

  1. 출발

    27 · VIX-managed portfolios

    여기서 가져올 것

    • 월중 daily VIX 제곱을 집계하고 과거 36개월 recursive normalization으로 다음달 비중을 만드는 위험관리 규칙
    • 옵션 내재변동성 자료를 사용할 때의 시점·비용·시장차이

    필요한 입력

    • 월말까지 실제 공개된 daily VKOSPI와 거래일·단위·산출방법 변경 이력
    • 27식 월중 VKOSPI 제곱 집계 사양과 level·change·term 확장 사양의 분리
    • revision·휴장·missing 값 처리 원장
    • WML-only RW126·HAR 기준
    멈춤 조건VKOSPI의 역사적 가용시점·정의변경·결측을 복원할 수 없거나 VIX 결과를 한국에 그대로 외삽한다.

    다음으로: PIT 외부변수가 준비되면 27의 scaling strategy를 내부 downside·conditional 전략과 비교하고, 미래분산 forecast로 쓸 때는 별도 forecast-loss gate를 추가한다.

  2. 비교

    18 · Conditional Volatility Targeting21 · Downside Risk and the Performance of Volatility-Managed Portfolios

    여기서 가져올 것

    • 외부 옵션자료 없이 극단·downside 상태에서만 노출을 바꾸는 대안
    • 추가 데이터와 내부 signal의 cost-benefit 비교

    필요한 입력

    • WML-only conditional/downside benchmark
    • 동일 target·cap·월별 적용 시점
    멈춤 조건외부변수 후보만 다른 scaling·target 또는 사후 threshold를 사용한다.

    다음으로: 동일 조건에서 WML-only 대안을 넘는 증분만 경제성과로 이동한다.

  3. 경제성과 gate

    01 · On the Performance of Volatility-Managed Portfolios24 · A Multifactor Perspective on Volatility-Managed Portfolios30 · Do Limits to Arbitrage Explain the Benefits of Volatility-Managed Portfolios?

    여기서 가져올 것

    • 실시간 성과·비용·factor exposure·시장마찰 검증
    • 추가 데이터가 투자자에게 주는 실제 순가치

    필요한 입력

    • 데이터 구입·지연 비용과 turnover
    • 공통 gross/net performance와 tail 지표
    멈춤 조건외부 signal의 순성과가 데이터비용·거래비용 후 사라지거나 위기 한 구간에만 집중된다.

    다음으로: PIT·순가치·안정성을 통과할 때만 확장모형으로 채택한다.

구현 체크리스트

  • VKOSPI 원자료·정의·공개시점·revision을 별도 manifest로 만든다.
  • 27의 월중 daily VKOSPI 제곱 집계와 recursive 36개월 normalization을 먼저 별도 전략으로 재현한다.
  • WML-only 기준과 동일 origin·cap·비용으로 비교하되, 27의 strategy signal을 자산별 variance forecast와 혼동하지 않는다.
  • level·change·term·state threshold 확장은 train-only로 선택하고 원형 사양과 분리한다.
  • 데이터비용 포함 net value와 crisis concentration을 보고한다.

금지할 추론

  • 미국 VIX 결과를 한국 VKOSPI 성과로 간주하지 않는다.
  • 27이 자산별 미래분산의 QLIKE·MSE 우위를 입증한 forecast 논문이라고 부르지 않는다.
  • 옵션시장의 forward-looking 성격만으로 증분가치를 가정하지 않는다.
  • 사후 crisis threshold를 실시간 규칙으로 바꾸지 않는다.

근거 대조 지점

  • 27의 월중 daily VIX 제곱 집계, recursive 36개월 normalization, signal timing과 overlay-cost 조건
  • 18·21의 WML-only conditional/downside 대안
  • 01·24·30의 실시간·비용·마찰 gate
  • VKOSPI 공급원의 point-in-time 가용성
