경로 검수 완료

OOS 누수·공정성 점검

각 forecast와 scaling weight가 당시 이용 가능한 정보만 쓰고 모든 후보가 같은 조건에서 비교됐는가?

이 경로를 시작할 때

  • 모형 우열·예측 개선·경제성과를 주장하기 직전이다.
  • 모든 후보의 정보집합·학습창·tuning·재추정·평가월을 감사한다.

읽기와 판단 순서

  1. 출발

    04 · HARd to beat: The overlooked impact of rolling windows in the era of machine learning

    여기서 가져올 것

    • rolling window·stride·refit 빈도를 별도 treatment로 보는 관점
    • static ML과 rolling HAR의 불공정 비교가 순위를 바꿀 수 있다는 반례
    • validation·test·계산비용을 함께 기록하는 규약

    필요한 입력

    • 후보별 origin, training start/end, validation end, refit flag, hyperparameter hash
    • 공통 OOS target와 평가월
    • 미래 prefix를 바꿔도 과거 forecast가 불변인 test
    멈춤 조건한 후보의 test 정보가 scaling·feature·threshold·hyperparameter 선택에 들어간다.

    다음으로: 시점 감사 통과 후 loss·measurement·economic 평가의 공정성을 점검한다.

  2. 예측 gate

    09 · HARK the SHARK: Realized Volatility Modeling with Measurement Errors and Nonlinear Dependencies17 · Realized Variance Modeling - Decoupling Forecasting from Estimation22 · Realized Volatility Forecasting - Robustness to Measurement Errors

    여기서 가져올 것

    • measurement model·nonlinearity·estimation loss의 효과를 분리하는 방법
    • noisy realized proxy에서 MSE와 QLIKE의 역할
    • 사양 선택과 평가 loss를 같은 test 결과로 튜닝하지 않는 원칙

    필요한 입력

    • 모든 후보의 양의 forecast와 동일 loss 계산 코드
    • benchmark 상대 loss·DM/MCS·multiple-testing 절차
    • 모형·loss·proxy ablation 표
    멈춤 조건평가 loss를 보고 후보·창·feature를 사후 선택하거나 benchmark가 후보별로 달라진다.

    다음으로: forecast gate를 통과한 사전 후보만 실시간 경제성과로 이동한다.

  3. 경제성과 gate

    01 · On the Performance of Volatility-Managed Portfolios24 · A Multifactor Perspective on Volatility-Managed Portfolios

    여기서 가져올 것

    • 사후 경계와 실시간 투자결과의 차이
    • 비용·노출·factor control을 포함한 OOS 경제평가

    필요한 입력

    • 사전 target·cap·비용모형
    • 동일 월표본의 gross/net returns와 exposure
    멈춤 조건full-sample scalar·사후 최적 threshold·다른 평가월이 실시간 성과에 들어간다.

    다음으로: 누수·불공정 0건인 결과만 최종 표와 주장 지도에 올린다.

금지할 추론

  • rolling과 static 결과를 순수 모형 차이로 해석하지 않는다.
  • test 결과로 고른 창·feature·threshold를 OOS라고 부르지 않는다.
  • full-sample risk equalization을 실시간 투자자의 가용정보로 간주하지 않는다.
