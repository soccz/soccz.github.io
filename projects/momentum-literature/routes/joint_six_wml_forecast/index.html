경로 검수 완료

6개 WML 공동예측

공동예측이 여섯 개별 단변량 기준보다 OOS와 경제성과에서 증분가치를 주는가?

이 경로를 시작할 때

  • D10·Q5·P30 × VW·EW 여섯 WML의 공통 변동성 움직임을 활용한다.
  • 여섯 series가 같은 KOSPI 종목·월을 공유한다는 의존성을 유지한다.

읽기와 판단 순서

  1. 출발

    28 · Multivariate Volatility Forecasts for Stock Market Indices

    여기서 가져올 것

    • 여러 지수의 변동성을 공동으로 예측하는 multivariate benchmark
    • own-history와 cross-series 정보의 증분을 분리하는 비교

    필요한 입력

    • 6개 WML의 동일 거래일 패널과 missing-day 규칙
    • 각 series 단변량 RW126·HAR forecast
    • 공통 OOS origin
    멈춤 조건여섯 WML의 달력·target 정의가 다르거나 cross-series 계수 또는 별도 공분산 branch를 추정할 표본이 부족하다.

    다음으로: 단순 multivariate 기준이 안정되면 network·GNN·covariance 확장을 별도 ablation으로 추가한다.

  2. 확장

    25 · Network Log-ARCH Models for Forecasting Stock Market Volatility26 · Forecasting Realized Volatility with Spillover Effects - Perspectives from Graph Neural Networks02 · The contribution of realized variance–covariance models to the economic value of volatility timing

    여기서 가져올 것

    • network log-ARCH와 nonlinear spillover의 패널 정보 사용법
    • 공분산 예측을 투자 가치로 바꾸는 경제평가
    • 종목 네트워크 원형과 6-WML 소형패널 적응의 차이

    필요한 입력

    • 25·26 graph branch에서는 사전에 고정한 6×6 adjacency 또는 train-only graph와 lagged cross-WML 입력
    • 02 covariance branch를 실제 자산배분에 쓸 때만 대칭·양의 정부호 행렬과 portfolio objective를 검사
    • 02 원형에 필요한 일중 공분산이 없다는 명시
    멈춤 조건test 구간으로 graph를 만들거나 종목패널 원형을 6개 WML에 그대로 재현했다고 주장한다.

    다음으로: 단변량 대비 cross-series 증분이 남는 후보만 공정성 gate로 보낸다.

  3. 예측 gate

    04 · HARd to beat: The overlooked impact of rolling windows in the era of machine learning17 · Realized Variance Modeling - Decoupling Forecasting from Estimation22 · Realized Volatility Forecasting - Robustness to Measurement Errors

    여기서 가져올 것

    • 창·refit·loss·measurement error를 맞춘 비교
    • 모형 복잡성과 추정법의 증분 분리

    필요한 입력

    • series별·joint QLIKE/MSE와 다중비교
    • 같은 fitting window와 retune budget
    멈춤 조건공동모형이 더 많은 데이터·refit·tuning을 쓰는 이점만 남는다.

    다음으로: joint forecast가 6개 방향과 평균에서 안정적이면 경제성과로 이동한다.

  4. 경제성과 gate

    01 · On the Performance of Volatility-Managed Portfolios24 · A Multifactor Perspective on Volatility-Managed Portfolios

    여기서 가져올 것

    • 의존된 전략의 실시간 경제평가
    • 노출·비용·factor 조건을 포함한 OOS 검증

    필요한 입력

    • 6개별 관리수익과 joint bootstrap
    • 공통 target·cap·비용모형
    멈춤 조건평균 개선이 특정 한 구성에만 의존하거나 6개 중 사후 최고 선택으로 만들어진다.

    다음으로: 공통성의 증분이 joint 검정과 경제성과에 남을 때만 확장으로 채택한다.

구현 체크리스트

  • 6개 WML의 달력·target·scaling 코드를 공유한다.
  • 단변량→단순 multivariate→network/GNN 순서로 ablation한다.
  • graph와 hyperparameter는 train-only로 고정한다.
  • series별 결과와 joint 의존성 보정 결과를 함께 보고한다.

금지할 추론

  • 6개 WML을 독립된 여섯 표본으로 취급하지 않는다.
  • 종목패널 network 원형을 6개 factor series에 무수정 재현했다고 쓰지 않는다.
  • 여섯 분산을 함께 예측하는 vector problem과 6×6 covariance matrix 예측을 같은 문제로 취급하지 않는다.
  • 사후 최고 구성 하나로 공동모형의 성공을 선언하지 않는다.
