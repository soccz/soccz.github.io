SYY17

한국주식시장에서의 위험관리 모멘텀 투자전략

손경우 · 윤병욱 · 윤보현 · 2017 · 금융지식연구

기초 전제

30초 판정

한국 KOSPI에서 BS15형 RW126·12% 위험관리를 직접 적용한 선행 앵커이지만, 30/30 동일가중 명세이므로 현재 6개 WML grid의 숫자 복제 목표로 쓰지 않는다.

사용할 때

  • 한국 주식시장에 BS15형 위험관리 모멘텀의 직접 선행연구가 있는지 확인할 때
  • 30/30 동일가중 WML과 현재 10분위·5분위·30/40/30, VW·EW 여섯 구성을 구별할 때
  • 126거래일·연 12% scaling의 한국 적용과 하위기간 결과를 대조할 때

사용하지 말아야 할 때

  • 현재 10/10 가치가중 WML이 논문의 Sharpe 0.61을 그대로 내야 한다고 주장할 때
  • 한국 주식시장의 보편적 표본필터·포트폴리오 규약을 이 한 논문으로 고정할 때
  • 원 WISEfn 빈티지와 누락 세칙 없이 1995–2014 게재표를 정확 복제했다고 말할 때

한국 WML 변환기

고정

  • SYY17을 한국 BS15 적용의 별도 30/30 EW 검산 앵커로 유지한다.
  • 126거래일, 월말 정보, 다음 달 적용, 연 12% 목표변동성의 시간순서를 보존한다.
  • 논문형 구성과 현재 여섯 WML grid를 각각 독립 결과열로 보존한다.

교체

  • 현재 주연구의 PIT KOSPI universe·스크린·10분위·5분위·30/40/30 및 VW·EW 정의를 SYY17의 30/30 EW로 덮어쓰지 않는다.
  • SYY17 대조실험은 현재 자료의 가용 범위와 필터 차이를 명시한 별도 적응으로 구현한다.

현재 입력

  • PIT KOSPI 종목별 일별수익과 월말 구성정보
  • 현재 여섯 WML의 일별·월별 수익
  • BS15 RW126·12% 공통 scaling 함수

부족한 입력

  • 1995–2014 원 WISEfn 빈티지와 전기간 자본잠식 판정자료
  • 1994–2000의 정확한 시점별 산업분류
  • 논문이 적지 않은 일별 WML 보유·동률·상장폐지 세칙

최소 구현 순서

  • 논문형 30/30 EW WML을 현재 주결과와 별도 이름으로 구성한다.
  • 직전 126개 일별 WML로 21×평균제곱 위험을 만들고 12% 목표비중을 다음 달에 적용한다.
  • 논문과 겹치는 기간·하위기간을 따로 보고하되 필터·빈티지 차이를 결과표 앞에 둔다.
  • 현재 여섯 WML과의 차이를 계산오류가 아니라 구성 민감도로 해석한다.

실패의 의미

현재 여섯 WML이 게재 Sharpe 0.61과 다르더라도 SYY17 복제 실패가 아니다. 먼저 30/30 EW 구성, 표본필터, 원자료 빈티지와 일별 보유세칙의 차이를 분리해야 한다.

구현 단위검사

  • 형성월 수익구간이 보유월 기준 t−12~t−2인지 검사한다.
  • Winner·Loser가 각각 30%이고 각 leg가 동일가중인지 검사한다.
  • 월 t의 WML* 비중에 t월 이후 일별수익이 들어가지 않는 prefix-invariance test
  • 논문형과 현재 6-grid 결과열이 서로 덮어쓰지 않는 식별자 test

주장 방화벽

허용 주장

  • 한국 KOSPI에서 BS15형 126일·12% 위험관리 모멘텀을 직접 적용한 2017년 선행연구가 있다.

    이유: 자료·30/30 EW 구성·위험식과 Tables 3–6이 게재본에 명시돼 있다. · 교정: 항상 30/30 동일가중, 1995–2014 논문 표본이라는 조건을 붙인다. · 근거: syy17_sample · syy17_wml_definition · syy17_scaling · syy17_table3

  • SYY17은 한국 BS15 검산 앵커이지만 현재 여섯 WML 구성의 숫자 복제 target은 아니다.

    이유: 현재 grid와 논문의 꼬리비율·가중·스크린이 서로 다르다. · 교정: 두 명세를 별도 결과열로 보존하고 구성 민감도를 보고한다. · 근거: syy17_sample · syy17_wml_definition

금지 주장

  • 현재 10/10 가치가중 WML이 SYY17의 Sharpe 0.61을 그대로 재현해야 한다.

    이유: SYY17은 상·하위 30% 동일가중 WML이며 표본필터도 현재 주명세와 다르다. · 교정: 동일 30/30 EW 적응을 별도로 만든 뒤 같은 명세끼리 비교한다. · 근거: syy17_sample · syy17_wml_definition · syy17_table3

  • SYY17 Table 3의 WML* 초과첨도는 1.42다.

    이유: 게재본 Table 3과 Table 6의 전체표본 WML* 초과첨도는 모두 1.24다. · 교정: Table 3 WML* 초과첨도는 1.24로 인용하고 현재 여섯 WML에 전이하지 않는다. · 근거: syy17_table3 · syy17_table5_6

문헌에서 해결되지 않은 항목

  • 원 WISEfn 빈티지, 전기간 자본잠식·산업분류와 일별 WML 세부 보유규칙이 공개 레코드의 재현 범위에 포함되지 않는다.
