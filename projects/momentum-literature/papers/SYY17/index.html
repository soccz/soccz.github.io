SYY17

한국주식시장에서의 위험관리 모멘텀 투자전략

손경우 · 윤병욱 · 윤보현 · 2017 · 금융지식연구

기초 전제
이 페이지에서30초 판정문제와 답논증수식표 읽기한국 실험자가점검원문 위치

30초 판정

한국 KOSPI에서 BS15형 RW126·12% 위험관리를 직접 적용한 선행 앵커이지만, 30/30 동일가중 명세이므로 현재 6개 WML grid의 숫자 복제 목표로 쓰지 않는다.

사용할 때

  • 한국 주식시장에 BS15형 위험관리 모멘텀의 직접 선행연구가 있는지 확인할 때
  • 30/30 동일가중 WML과 현재 10분위·5분위·30/40/30, VW·EW 여섯 구성을 구별할 때
  • 126거래일·연 12% scaling의 한국 적용과 하위기간 결과를 대조할 때

사용하지 말아야 할 때

  • 현재 10/10 가치가중 WML이 논문의 Sharpe 0.61을 그대로 내야 한다고 주장할 때
  • 한국 주식시장의 보편적 표본필터·포트폴리오 규약을 이 한 논문으로 고정할 때
  • 원 WISEfn 빈티지와 누락 세칙 없이 1995–2014 게재표를 정확 복제했다고 말할 때

DEEP DIVE · 검토자 종합

왜 이 논문이 필요한가

딥다이브 독립검수 완료 · 2026-08-16 · 전체 서술과 동일 논문 근거 위치를 재대조했습니다.

출처 구분: 수식·연구설계·“저자 보고” 결과는 원문 내용이고, 해석·한계·자가점검은 검토자 종합, 한국 실험실은 프로젝트 적용안입니다.

문제

한국 주식으로 위험관리 모멘텀을 실제 구성한 직접 선행연구다. 미국 결과를 한국에 옮길 수 있는지를 묻는 수준을 넘어, 어떤 종목을 어떻게 고르고 어떤 위험창으로 얼마만큼 노출을 조절했는지까지 국내 표본에서 보여 준다.

중심 질문

KOSPI에서 과거 승자 매수·패자 매도 모멘텀의 변동성을 직전 정보로 관리하면, 원 모멘텀보다 위험 한 단위당 성과와 꼬리 모양이 개선되는가?

기존 문헌의 빈틈

한국 모멘텀 연구는 평균수익 존재 여부에 집중한 경우가 많았고, 모멘텀 크래시를 줄이는 Barroso–Santa-Clara식 변동성 관리가 한국의 구체적 유니버스와 포트폴리오 규칙에서도 작동하는지는 별도로 확인할 필요가 있었다.

논문의 답

저자들은 KOSPI 표본에서 과거수익 상위·하위 30%를 각각 동일가중해 WML을 만들고, 직전 126거래일의 일별 WML 제곱수익으로 연환산 위험을 추정해 연 12% 목표변동성으로 노출을 조절한다. 동일위험 비교와 하위기간 표는 위험관리 후 Sharpe와 왜도가 개선되는 방향을 보이지만, 이 결론은 30/30 동일가중 구성에 조건부다. 현재 프로젝트의 10분위·5분위·30/40/30 및 EW/VW 여섯 WML은 포트폴리오 자체가 다르므로 이 논문은 숫자 복사본이 아니라 한국 직접 기준선이자 구성 민감도 검사의 출발점이다.

수식은 암기 대상이 아니라 입력·출력·시점·실패 조건을 고정하는 계약입니다.

위험추정과 WML* · 직전 126일 일별 WML 제곱수익의 월간화된 평균으로 위험을 추정하고, 연 12% 목표와 예측위험의 비율만큼 다음 WML 노출을 조절한다.

직관: 위험이 평소의 두 배로 예측되면 노출을 대략 절반으로 줄이는 역변동성 규칙이다. 크래시 직전 위험이 이미 상승해 있어야 보호효과가 생긴다.

구현할 때: 위험창의 마지막 날짜가 노출을 적용하는 보유기간보다 앞서야 한다. 논문에는 레버리지 상한이 명시되지 않았으므로 프로젝트 cap을 쓰면 별도 적응 사양으로 표시한다.

표본과 입력

  • 저자 표본은 1995–2014 KOSPI이며 자본잠식, 금융업, 관리종목 제외 규칙을 둔다.
  • 월별 종목수익과 시가정보로 모멘텀을 구성하고, 별도의 일별 WML 수익이 위험예측 입력이다.
  • 현재 프로젝트는 PIT 유니버스와 여섯 WML을 그대로 유지하고 논문형 30/30 EW를 별도 비교선으로 보존한다.

예측대상과 시점

  • 형성월의 과거 12–2 수익으로 정렬하고 다음 달을 보유한다.
  • 노출 배율은 보유월이 시작되기 전에 끝난 126거래일 일별 WML만 사용한다.
  • 성과 target은 다음 보유월 WML 수익이며 사후 실현변동성은 평가에만 쓴다.

추정과 표본외 검증

  • RW126은 별도 모수최적화 없이 고정창을 이동시키는 규칙이다.
  • 목표변동성 12%, 126일, 30/30 EW를 먼저 고정해 사후 최적화를 막는다.
  • 현재 프로젝트에서 새 모형과 비교할 때도 같은 origin·평가월·비용 가정을 사용한다.

평가와 통과 기준

  • 원 WML, 관리 WML*, 동일위험 원 WML의 평균·변동성·Sharpe를 분리한다.
  • 왜도·초과첨도·최악월과 하위기간 결과를 함께 읽어 평균 Sharpe만으로 결론 내리지 않는다.
  • 논문형 30/30 EW와 현재 여섯 WML의 수치가 다르면 계산 오류보다 구성 차이를 먼저 점검한다.

왜 작동하는가: 메커니즘과 반증 저자 제안 · 검토자 진단

저자가 제안한 작동 경로

  • 모멘텀 크래시 전후에 일별 WML 위험이 높아지면 역변동성 배율이 노출을 줄여 큰 손실을 완화한다.
  • 저위험기에는 노출이 커져 위험예산을 더 일정하게 사용하고 평균수익을 보존할 수 있다.

그 경로를 지지하는 관찰

  • 동일위험 Table 3에서 Sharpe와 왜도가 함께 개선되는 방향은 단순 위험량 차이보다 타이밍 채널과 일치한다.
  • 하위표본 Table 6은 개선 크기가 시기별로 달라 위험상태 의존적이라는 해석과 맞는다.

경쟁 설명

  • 30/30 동일가중이 소형주·극단반전 종목을 많이 담아 원 WML과 관리효과를 동시에 키웠을 수 있다.
  • 표본 스크린, 수정주가와 상장폐지 처리 차이가 위기월 수익을 바꿀 수 있다.

반증되려면 무엇이 보여야 하나

  • 동일 origin에서 RW126 배율이 큰 손실 전에 낮아지지 않고 손실 뒤에만 반응한다면 예방적 채널은 약하다.

한국 6-WML 적용 실험실 프로젝트 적용안

원 논문을 복제하는 것이 아니라, 고정된 WML·RW126 기준선 안에서 검증 가능한 조각만 옮깁니다.

원 논문 요소를 한국 6-WML 실험에 옮기는 대응 관계
원 논문의 요소이 프로젝트의 대응물왜 이렇게 옮기나
30/30 동일가중 WML논문형 비교선과 고정된 여섯 WML을 병렬 보존국내 직접재현과 프로젝트 본선의 구성 차이를 혼동하지 않기 위해서다.
직전 126일 제곱수익 위험각 WML별 BS15 RW126 baseline미래 위험모형을 바꾸더라도 기준 분모를 동일하게 유지한다.
연 12% 무상한 배율기본 원형과 cap·비용 robustness를 별도 보고원문 비교가능성과 실제 운용가능성을 동시에 보존한다.

실험 순서

  • PIT KOSPI 유니버스에서 논문형 30/30 EW와 여섯 WML을 서로 다른 series id로 생성한다.
  • 각 월말 직전까지의 일별 WML 126개로 위험을 계산하고 사용 가능일을 저장한다.
  • 원 WML, RW126 WML*, 동일위험 원 WML을 같은 월 mask에서 만든다.
  • 평균·변동성·Sharpe·왜도·초과첨도·최악월·MDD를 전체와 사전 기간별로 계산한다.
  • 구성비율, EW/VW, 스크린을 한 번에 하나씩 바꿔 결과 차이를 분해한다.
  • cap·회전율·거래비용을 추가한 운용 패널을 원형 결과와 분리한다.

채택 기준

  • 모든 월에서 위험입력의 최대일이 노출 적용월 시작일보다 앞선다.
  • 동일위험 비교의 실현변동성이 사전 허용오차 안에서 일치한다.
  • 최소한 하나의 본선 WML에서 비용 후 Sharpe와 하방지표가 함께 개선되고 하위기간 한 곳에만 의존하지 않는다.

실패 진단

  • 논문형만 개선되면 꼬리비율·동일가중·소형주 노출에 의존하는 구성효과를 우선 의심한다.
  • 위기 직후에만 배율이 줄면 126일 예측의 반응지연을 진단한다.
  • gross는 개선되고 net은 악화되면 turnover·financing·leverage cap을 원인으로 분리한다.

  • 126거래일, 월말 정보, 다음 달 적용, 연 12% 목표변동성의 시간순서를 보존한다.

  • 현재 주연구의 PIT KOSPI universe·스크린·10분위·5분위·30/40/30 및 VW·EW 정의를 SYY17의 30/30 EW로 덮어쓰지 않는다.
  • SYY17 대조실험은 현재 자료의 가용 범위와 필터 차이를 명시한 별도 적응으로 구현한다.

현재 입력

  • PIT KOSPI 종목별 일별수익과 월말 구성정보
  • 현재 여섯 WML의 일별·월별 수익

  • 1995–2014 원 WISEfn 빈티지와 전기간 자본잠식 판정자료
  • 1994–2000의 정확한 시점별 산업분류

최소 구현 순서

  • 논문형 30/30 EW WML을 현재 주결과와 별도 이름으로 구성한다.
  • 직전 126개 일별 WML로 21×평균제곱 위험을 만들고 12% 목표비중을 다음 달에 적용한다.
  • 논문과 겹치는 기간·하위기간을 따로 보고하되 필터·빈티지 차이를 결과표 앞에 둔다.
  • 현재 여섯 WML과의 차이를 계산오류가 아니라 구성 민감도로 해석한다.

실패의 의미

현재 여섯 WML이 게재 Sharpe 0.61과 다르더라도 SYY17 복제 실패가 아니다. 먼저 30/30 EW 구성, 표본필터, 원자료 빈티지와 일별 보유세칙의 차이를 분리해야 한다.

구현 단위검사

  • 형성월 수익구간이 보유월 기준 t−12~t−2인지 검사한다.

  • 논문형과 현재 6-grid 결과열이 서로 덮어쓰지 않는 식별자 test
