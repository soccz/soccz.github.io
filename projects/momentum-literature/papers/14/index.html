Exploiting Intraday Decompositions in Realized Volatility Forecasting - A Forecast Reconciliation Approach

Massimiliano Caporin · Tommaso Di Fonzo · Daniele Girolimetto · 2024 · Journal of Financial Econometrics

방법 확장후속 확장추가자료 필요검수 완료독립검수 완료

30초 판정

정확한 합계 제약을 가진 일중 변동성 구성요소를 따로 예측해 reconcile하는 후속확장 문헌이며, 6개 WML 자체를 임의로 묶는 근거는 아니다.

사용할 때

  • positive·negative 또는 partial variance의 합이 total variation과 정확히 맞을 때
  • bottom-up과 MinT-shrinkage의 증분을 비교할 때
  • 고변동기 decomposition 이득을 진단할 때

사용하지 말아야 할 때

  • 1분 자료 없이 원형 partial/time hierarchy를 구현했다고 할 때
  • 서로 다른 여섯 WML forecast를 합계 제약 없이 reconcile할 때
  • QLIKE 개선을 WML Sharpe 개선으로 바꿔 말할 때

방법 여권

data
DJIA 지수와 26개 구성주식의 조정 1분 가격, 2003년 초–2022년 6월 말 4,908 full trading days [원문 보고]

origin까지의 daily total·semivariance·partial variance·시간대 component history와 HAR 1·5·22일 lag [원문 보고]
lookback
HAR feature는 1·5·22일; 모수추정은 별도 1,007일 rolling window [원문 보고]
horizon
1·5·22일 direct forecast [원문 보고]
model family
component-level HAR, bottom-up, MinT-shrinkage forecast reconciliation, direct SV와 PV(3)
training window
2003-01-02–2006-12-29의 1,007일을 시작으로 같은 길이의 rolling window를 사용한다.
retune
각 origin에서 component HAR와 reconciliation error covariance를 rolling history로 갱신한다.
benchmarks
top-level direct HAR · direct signed-semivariance model · direct PV(3) · bottom-up component forecasts
loss / test
MSE · QLIKE · HAR 대비 loss ratio · one-sided Diebold–Mariano · 80% Model Confidence Set · MCB Nemenyi test · 22일 block과 10,000 bootstrap MCS
economic metrics
투자수익·Sharpe·turnover는 보고되지 않는다.

turnover
포트폴리오 비중과 회전율을 평가하지 않는다.

한국 WML 변환기

고정

  • PIT KOSPI·12–2·6개 WML·BS15 RW126을 고정한다.
  • 정의상 합계가 성립하는 component에만 reconciliation을 적용한다.
  • MSE와 QLIKE 및 경제성과를 별도 판정한다.

교체

  • 일중 partial variance 대신 일별 WML positive/negative squared-return component를 쓰는 경우 daily-sign adaptation으로 명명한다.
  • 1·5·22일 stock RV target을 다음 보유월 WML 제곱수익 합으로 바꾼다.

현재 입력

  • 6개 일별 WML
  • positive·negative WML 제곱수익 합
  • RW126·HAR 공통 forecast matrix

부족한 입력

  • 한국 종목 또는 WML의 동기화된 1분 수익
  • 세 partial-variance threshold와 다섯 시간대의 coherent hierarchy

최소 구현 순서

  • 각 WML 안에서 total squared return=positive+negative component 항등식을 먼저 검증한다.
  • RW126·HAR·signed-HAR를 같은 origin·target으로 비교한다.
  • coherent top/bottom forecast에만 bottom-up 또는 shrinkage reconciliation을 적용한다.
  • 6개 서로 다른 전략 간에는 reconciliation을 적용하지 않고 동일 BS15 gate를 별도로 실행한다.

실패의 의미

daily-sign component가 HAR를 이기지 못하면 coarse 부호정보의 추가 예측력을 기각한다. 이는 일중 partial-variance 원형의 실패를 뜻하지 않는다.

구현 단위검사

  • component 합이 total target과 수치적으로 일치하는 coherence test
  • 여섯 WML 사이 reconciliation을 차단하는 target-identity test
  • reconciliation covariance가 origin 이후를 참조하지 않는 prefix test
  • 1분 원형과 daily-sign adaptation 라벨을 구분하는 provenance-free method test

주장 방화벽

허용 주장

  • 검증한 저자 선행판에서는 정확한 합계 hierarchy의 partial-variance forecasts를 reconcile한 PV(3)shr가 특히 개별주식 QLIKE에서 강했다.

    이유: 방법의 coherence 조건과 Tables 4–7이 함께 제시된다. · 교정: 1분 자료, 26개 주식, horizon·loss와 선행판을 붙인다. · 근거: p14_reconcile · p14_data · p14_table4 · p14_table6 · p14_table7

금지 주장

  • 현재 일별 WML로 원 논문의 partial/time hierarchy를 재현할 수 있다.

    이유: 원형에는 거래일당 390개의 1분 관측과 정확한 time hierarchy가 필요하다. · 교정: daily-sign adaptation과 원형을 분리한다. · 근거: p14_data

  • 여섯 WML forecast를 MinT로 합치면 원 논문의 forecast reconciliation이다.

    이유: 여섯 전략은 합이 하나의 total series가 되는 hierarchy가 아니다. · 교정: 각 WML 내부의 정의상 component 합에만 적용한다. · 근거: p14_reconcile

  • PV(3)shr는 모든 자산·loss·horizon에서 단독 winner다.

    이유: 지수 h=1의 MSE와 QLIKE 판정이 반대로 움직였다. · 교정: loss·자산·horizon별 수치를 함께 보고한다. · 근거: p14_table4

문헌에서 해결되지 않은 항목

  • 최종 JFEC 조판본과 2023년 선행판의 전 표·부록 판본대조 및 1분 원자료 기반 독립 재현은 이 레코드 범위에 포함되지 않는다.
