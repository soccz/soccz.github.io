03

A Machine Learning Approach to Volatility Forecasting

Kim Christensen · Mathias Siggaard · Bezirgen Veliyev · 2023 · Journal of Financial Econometrics

핵심 예측필독적응 필요검수 완료독립검수 완료

30초 판정

HAR·regularization·tree·NN을 같은 예측 origin에서 단계적으로 비교하되 feature 확장과 모형 비선형성의 증분을 분리할 때 쓰는 본선 forecast 설계 문헌이다.

사용할 때

  • 한국 WML의 RW126 다음에 HAR·LogHAR·ridge/lasso·RF·NN 비교사다리를 설계할 때
  • 동일 feature 비교와 추가 feature 비교를 분리해 ML의 증분가치를 측정할 때
  • 1일·5일·22일 horizon별 모형순위와 VaR 반례를 함께 이해할 때

사용하지 말아야 할 때

  • ML이 모든 데이터·horizon에서 HAR보다 우월하다고 주장할 때
  • 29개 미국 대형주의 5분 RV 결과를 한국 월별 WML 위험에 직접 이전할 때
  • MSE 개선만으로 WML scaling의 Sharpe·CER 개선을 선언할 때

한국 WML 변환기

고정

  • PIT KOSPI·12–2·월별 형성과 다음 달 보유의 6개 WML, BS15 RW126과 동일한 경제적 스케일링 함수를 고정한다.
  • 동일 forecast origin, 시간순 outer test, train-only preprocessing, 과거자료 안의 hyperparameter 선택을 유지한다.
  • 동일 feature 비교, feature 확장 비교, 경제성과 평가를 세 층으로 분리한다.

교체

  • 29개 미국 주식의 5분 RV target을 각 한국 WML의 다음 보유월 일별 제곱수익 합으로 교체한다.
  • 1·5·22일 HAR 입력을 월말 기준 21·63·126거래일 WML 분산 입력으로 적응한다.
  • 종목패널 test를 6개 상관된 WML의 공통 OOS 월로 교체한다.

현재 입력

  • 6개 구성의 일별 WML
  • 6개 구성의 월별 WML
  • 월말 PIT formation과 screen 원장
  • BS15 RW126 기준예측과 동일 경제성과 함수

부족한 입력

  • 원 논문의 5분 realized variance와 동일 빈도의 한국 WML 측정치
  • 전 기간의 한국 옵션 내재변동성·earnings indicator·dollar volume·EPU·ADS 대응변수와 시점가용성 원장

최소 구현 순서

  • 다음 달 WML 일별 제곱수익 합을 target으로 사전 고정하고 21·63·126일 lag variance를 공통 feature로 만든다.
  • RW126·historical mean 다음에 HAR·LogHAR를 먼저 확정하고 ridge/lasso·RF·NN을 순차 추가한다.
  • 각 OOS origin의 과거자료 안에서만 scaler와 tuning을 다시 fit하고 모든 모형의 forecast 월을 일치시킨다.
  • QLIKE·MSE·DM 또는 block-bootstrap 예측표와 동일 BS15 mapping의 Sharpe·CER·최악월·turnover 표를 분리한다.

실패의 의미

복잡모형이 같은 feature의 HAR·LogHAR보다 공통 OOS QLIKE/MSE를 낮추지 못하면 한국 월별 WML 표본에서는 ML 복잡성의 증분가치가 없다고 해석한다; loss가 낮아도 Sharpe·CER가 개선되지 않으면 경제적 전이가 실패한 것이다.

구현 단위검사

  • forecast origin 뒤의 값을 바꿔도 과거 feature·scaler·forecast가 변하지 않는 prefix-invariance test
  • outer train·inner validation·test 날짜가 겹치지 않는 분할 test
  • 전체표본 표준화와 random cross-validation을 차단하는 preprocessing test
  • 모든 모형을 같은 target-vol·floor·cap 함수에 넣는 공통 mapping test
  • RF·NN seed 반복의 중앙값과 분산을 저장하는 randomness test

주장 방화벽

허용 주장

  • 29개 DJIA 종목의 accepted manuscript에서는 제한 HAR 입력의 1일 ML 이득은 혼합됐고, MALL 추가변수와 긴 horizon에서 tree·NN의 MSE 이득이 커졌다.

    이유: MHAR Table 2와 MALL Tables 3·5·7을 함께 읽을 때 feature와 horizon의 조건부 패턴이 드러난다. · 교정: 항상 29개 미국 대형주, 5분 RV, MALL 여부, horizon, accepted-manuscript 판본을 함께 적는다. · 근거: p03_table2 · p03_table3 · p03_table5 · p03_table7

  • 한국 WML에서 HAR·LogHAR는 ML의 필수 benchmark이고 forecast loss와 경제성과는 분리해야 한다.

    이유: 논문은 basic HAR의 강건성과 MSE 순위가 VaR로 완전히 이전되지 않는 반례를 함께 제공한다. · 교정: 한국 적응에서는 RW126→HAR·LogHAR→regularization·tree→NN 순서를 고정하고 같은 OOS 월을 사용한다. · 근거: p03_har · p03_table8 · p03_table9

금지 주장

  • 이 논문은 ML이 언제나 HAR보다 우월함을 증명했다.

    이유: MHAR 1일에서는 여러 regularization·tree 모형이 HAR와 비슷하거나 더 나쁘고, 결과는 feature set과 horizon에 따라 바뀐다. · 교정: 같은 feature와 horizon에서 모형별 상대 MSE와 검정을 조건부로 보고한다. · 근거: p03_table2 · p03_table3 · p03_table5 · p03_table7

  • MALL 월 horizon의 약 40% 상대 MSE 개선은 모든 주식·모형의 절대오차가 40% 줄었다는 뜻이다.

    이유: 표 값은 29종목 평균 pairwise relative MSE이고 추가변수와 일부 benchmark 악화가 함께 작용한다. · 교정: 선택한 benchmark, 절대 MSE, 종목별 분포, DM/MCS를 함께 제시한다. · 근거: p03_table7

  • 모든 모형은 동일한 재추정 빈도와 계산예산의 untouched OOS에서 비교됐다.

    이유: rolling 갱신과 validation 방식이 모형군별로 다르고 NN은 test 동안 가중치를 고정한다. · 교정: 각 모형의 fitting window·retune frequency·tuning budget을 공정성 표에 공개한다. · 근거: p03_fit_scheme
