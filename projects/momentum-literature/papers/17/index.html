Realized Variance Modeling - Decoupling Forecasting from Estimation

Fabrizio Cipollini · Giampiero M. Gallo · Alessandro Palandri · 2020 · Journal of Financial Econometrics

기준선필독적응 필요검수 완료독립검수 완료

30초 판정

추정 criterion과 forecast loss를 분리하고 MLOG(2,1)를 복잡모형 앞의 강한 단순 baseline으로 두게 하는 필수 검증 문헌이다.

사용할 때

  • MSE·log-MSE·QLIKE별로 estimation choice를 교차평가할 때
  • HAR보다 단순한 log-ARMA baseline을 빠뜨리지 않게 할 때
  • BIC의 in-sample 선택과 OOS winner가 다른지 검정할 때

사용하지 말아야 할 때

  • 평가 loss와 같은 추정 criterion이 항상 최선이라고 가정할 때
  • 일별 realized-kernel 결과를 한국 다음달 WML 분산에 직접 이전할 때
  • 5년 estimation sample을 5년 feature lookback으로 부를 때

한국 WML 변환기

고정

  • PIT KOSPI·12–2·6개 WML·BS15 RW126을 고정한다.
  • 모든 모형에 같은 target·origin·OOS months를 사용한다.
  • forecast gate와 economic gate를 분리한다.

교체

  • 일별 realized-kernel target을 다음 보유월의 WML 일별 제곱수익 합으로 바꾼다.
  • 1일 static forecast를 월말-origin 다음달 direct forecast로 적응한다.

현재 입력

  • 6개 일별·월별 WML
  • RW126·HAR·log-HAR 입력
  • 다음달 squared-return target

부족한 입력

  • TAQ realized kernel과 동일한 noise-robust WML target
  • 원 종목자료·코드 기반 수치재현

최소 구현 순서

  • RW126·historical mean·HAR·log-HAR·MLOG(1,1)/(2,1)를 모든 WML의 첫 baseline ladder로 둔다.
  • MSE·log-MSE·QLIKE를 사전 고정하고 EC 선택은 outer origin 내부 validation에서만 한다.
  • 월별 rolling 또는 expanding 재추정과 positivity·log floor·failure 규칙을 고정한다.
  • loss별 DM/MCS 표 뒤 동일 BS15 scaling의 경제성과를 별도 보고한다.

실패의 의미

복잡한 ML·long-memory 모형이 MLOG/HAR를 이기지 못하면 그 증분가치를 기각하고, QLIKE가 좋아도 경제성과가 나쁘면 투자효용 주장을 기각한다.

구현 단위검사

  • test loss로 estimation criterion을 사후 선택하지 못하게 하는 nested-selection test
  • training window와 feature lag를 분리하는 semantics test
  • log floor와 inverse transform positivity test
  • winsorized·raw target의 forecast origin 일치 test

주장 방화벽

허용 주장

  • 검증한 working paper의 DJIA 실험에서 estimation criterion과 forecast loss의 최적 조합은 자동 일치하지 않았고 MLOG(2,1)가 강한 단순 baseline이었다.

    이유: criterion 정의와 Tables 1–12의 case frequencies·loss가 이를 직접 보인다. · 교정: working paper, 28개 대형주, 일별 realized kernel, static annual re-estimation을 붙인다. · 근거: p17_losses · p17_mlog · p17_tables1_2 · p17_tables3_4 · p17_tables5_6 · p17_tables7_8 · p17_tables9_10 · p17_tables11_12

금지 주장

  • forecast loss와 같은 함수형의 estimation criterion이 항상 최선이다.

    이유: LS·SDLS에는 LNLS가 더 자주 좋았던 반례가 있다. · 교정: EC×loss를 과거 validation에서 교차평가한다. · 근거: p17_tables1_2 · p17_tables3_4 · p17_tables5_6 · p17_tables7_8

  • BIC가 고른 모형은 OOS에서도 신뢰할 winner다.

    이유: 특히 QML loss 일치율은 3%로 보고됐다. · 교정: BIC와 nested OOS validation을 함께 사용한다. · 근거: p17_tables9_10 · p17_tables11_12

  • MLOG의 일별 미국주식 결과는 한국 다음달 WML 분산에 그대로 성립한다.

    이유: 자산·horizon·target proxy가 다르다. · 교정: MLOG를 필수 baseline으로만 두고 한국 OOS를 새로 평가한다. · 근거: p17_design · p17_tables9_10 · p17_tables11_12

문헌에서 해결되지 않은 항목

  • 최종 JFEC 조판본과 2019 working paper의 전 표·supplement 대조 및 TAQ 원자료 기반 독립 재현은 이 레코드 범위에 포함되지 않는다.
  • Tables 13-24 explicitly remove winsorization from IS data; the artifact does not clearly state whether OOS actual preprocessing changes.
