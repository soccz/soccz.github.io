08

Volatility Forecasting with Machine Learning and Intraday Commonality

Chao Zhang · Yihuang Zhang · Mihai Cucuringu · Zhongmin Qian · 2024 · Journal of Financial Econometrics

방법 확장후속 확장추가자료 필요검수 완료독립검수 완료

30초 판정

6개 WML을 따로 학습하는 Single, 함께 학습하는 Universal, 공통시장 위험을 더하는 Augmented의 단계적 설계를 시험할 때 쓰되, 일중 NN 우위를 월별 빈도로 외삽하지 않는다.

사용할 때

  • 여러 포트폴리오의 공통 위험을 pooled model로 학습할 때
  • 시장 공통변동성 feature의 Universal 대비 증분을 분리할 때
  • intraday와 daily 집계에서 nonlinear model의 가치가 달라지는지 볼 때

사용하지 말아야 할 때

  • 16 unseen stocks를 국가·기간 외부타당성으로 해석할 때
  • daily 선형모형 반례를 빼고 NN이 모든 horizon에서 최고라고 말할 때
  • 일별 한국 입력을 1분 Intraday2Daily 원형으로 부를 때

한국 WML 변환기

고정

  • PIT KOSPI·12–2·6개 WML·월말 형성·다음달 보유와 BS15 mapping을 고정한다.
  • Single→Universal→Augmented의 증분을 단계별로 분리한다.
  • 예측 loss와 비용 후 utility를 같은 OOS origins에서 평가한다.

교체

  • 93개 종목 intraday panel을 6개 WML의 일별위험 panel로 교체한다.
  • market intraday RV를 formation cutoff까지의 KOSPI 위험·횡단면 분산·WML 공통위험으로 교체한다.
  • 1분 원형이라는 명칭을 low-frequency commonality adaptation으로 교체한다.

현재 입력

  • 6개 WML 일별·월별 수익
  • KOSPI 시장 일별수익
  • 월말 formation·target row 원장

부족한 입력

  • 1분 top-of-book와 constituent intraday returns
  • 10·30·65분 portfolio RV와 realized quarticity
  • 장기 bid–ask·대차료·시장충격 비용

최소 구현 순서

  • 각 WML별 HAR/OLS Single을 먼저 만든다.
  • portfolio ID 또는 fixed effect를 포함한 pooled Universal을 동일 outer origin에 fit한다.
  • 과거 KOSPI·횡단면·공통 WML risk를 더한 Augmented를 Universal과 비교한다.
  • NN은 작은 sample-size gate와 nested validation을 통과할 때만 robustness로 둔다.

실패의 의미

Universal이 Single을 못 이기면 pooling 가정을, Augmented가 Universal을 못 이기면 공통위험의 증분을 기각하며 loss만 좋아지고 net utility가 나빠져도 채택하지 않는다.

구현 단위검사

  • Single·Universal·Augmented의 origin/target row-hash 동일성 test
  • winsorization·normalization의 past-only prefix test
  • portfolio-ID shuffle과 leave-one-portfolio-out pooling test
  • market feature 자기포함 민감도 test
  • 동일 cap·cost 경제 mapping test

주장 방화벽

허용 주장

  • author preprint에서 pooled·market-augmented NN은 intraday RV에 강했지만 daily에서는 선형모형이 비슷하거나 더 좋았다.

    이유: Table 3의 intraday와 daily QLIKE 순위가 다르다. · 교정: horizon별 결과를 한 문장에 함께 둔다. · 근거: p08_table3 · p08_table3_text

  • 공통시장 위험과 pooling을 한국 6개 WML의 단계적 challenger로 시험할 수 있다.

    이유: Single·Universal·Augmented가 pooling과 market augmentation을 분리한다. · 교정: 저빈도 adaptation이라고 명시한다. · 근거: p08_commonality · p08_table3

금지 주장

  • NN은 daily·monthly volatility에서 항상 선형모형을 이긴다.

    이유: daily Table 3과 held-out Table 4에서는 OLS·LASSO가 더 낮은 QLIKE를 보인다. · 교정: intraday 강점과 daily 반례를 함께 보고한다. · 근거: p08_table3 · p08_unseen

  • 16 unseen stocks는 다른 국가·시장·시기의 외부타당성을 입증한다.

    이유: 같은 미국 대형주 환경에서 학습종목만 제외한 횡단면 실험이다. · 교정: within-environment cross-sectional portability라고 부른다. · 근거: p08_unseen

문헌에서 해결되지 않은 항목

  • winsorization cutoff의 past-only 산출과 LASSO 5-fold의 시간순서는 preprint에서 완전히 특정되지 않는다.
  • Table 3 해설의 HAR-D Augmented 일반화에는 30분 QLIKE 0.227 대 Single 0.222라는 표 내부 반례가 있다.
