Stock market volatility forecasting: Do we need high-frequency data?

Štefan Lyócsa · Peter Molnár · Tomáš Výrost · 2021 · International Journal of Forecasting

기준선우선적응 필요검수 완료독립검수 완료

30초 판정

고빈도 자료의 증분가치가 horizon과 저빈도 estimator의 정보량에 달린다는 benchmark로 쓰고, 한국 월 WML에는 투명한 일별 기준선을 먼저 세우되 OHLC·5분 branch와 구분한다.

사용할 때

  • 5분 RV와 강한 OHLC range benchmark의 우위가 horizon에 따라 줄어드는지 볼 때
  • KS11을 포함한 국제지수의 22일 evidence를 보조근거로 쓸 때
  • forecast combinations와 economic Sharpe를 별도 평가할 때

사용하지 말아야 할 때

  • 고빈도 자료가 전혀 필요 없음을 증명한 논문으로 인용할 때
  • daily close squared return을 OHLC range와 같은 정보집합으로 부를 때
  • 85% MCS 동시포함을 equivalence proof로 해석할 때

한국 WML 변환기

고정

  • PIT KOSPI·12–2·6개 WML·월말 형성·다음달 보유와 BS15 mapping을 고정한다.
  • 모든 input-frequency arm에 같은 next-month target과 OOS months를 사용한다.
  • QLIKE·MSFE와 비용 후 Sharpe·CER를 별도 게이트로 둔다.

교체

  • 18개 지수 target을 6개 WML의 next holding-month variance로 교체한다.
  • 1,000일 창은 원재현 benchmark로 두고 504·756일을 past-only inner validation 후보로 둔다.
  • 현재 종가수익 branch를 OHLC range가 아닌 lower-information daily baseline으로 명시한다.

현재 입력

  • 6개 WML 일별·월별 수익
  • KS11·KOSPI 일별 종가수익
  • RW126·HAR·leverage-HAR targets

부족한 입력

  • portfolio-level OHLC path를 구성할 constituent intraday/OHLC data
  • formation weights를 고정한 5분 WML returns
  • bid–ask·세금·대차료·시장충격 비용

최소 구현 순서

  • daily close-return RW126·direct HAR·leverage-HAR를 공통 target에 비교한다.
  • OHLC branch는 constituent 경로로 실제 WML portfolio high/low를 만들 수 있을 때만 연다.
  • HF branch는 formation weights를 5분 constituent returns에 적용해 portfolio RV를 직접 만든다.
  • 모든 arm을 동일 BS15 cap·cost·target vol로 경제평가한다.

실패의 의미

daily branch가 intraday branch에 common OOS loss나 비용 후 성과에서 명확히 열위면 월 horizon의 low-frequency sufficiency 해석을 폐기한다.

구현 단위검사

  • calendar-month target과 fixed H=22 target 분리 test
  • OHLC range·overnight 공식 toy-case test
  • rolling 99.5/99.9 cutoff와 weights의 prefix test
  • insanity-filter 발생 원장 test
  • 21 candidates와 6 WML의 row-hash 동일성 test

주장 방화벽

허용 주장

  • anonymized preprint의 18개 지수에서 고빈도 우위는 1일에 크고 22일로 갈수록 줄었다.

    이유: Tables 3–5와 horizon별 MCS가 이 패턴을 보인다. · 교정: 저빈도가 OHLC range이고 gap이 0이 아니라는 조건을 붙인다. · 근거: p10_day · p10_month · p10_measures

  • KS11의 22일 결과는 한국 월별 위험예측에 투명한 daily benchmark를 둘 보조근거다.

    이유: KS11이 표본에 포함되고 H=22 HF/LF 결과가 보고된다. · 교정: index long-only와 WML long–short 차이를 함께 적는다. · 근거: p10_month · p10_sharpe

금지 주장

  • 이 논문은 고빈도 자료가 필요 없음을 증명했다.

    이유: H=1에서 고빈도 우위가 크고 H=22 gap도 0이 아니다. · 교정: 증분가치가 horizon과 LF estimator quality에 의존한다고 쓴다. · 근거: p10_day · p10_month

  • 85% MCS 동시포함은 HF와 LF의 equivalence proof다.

    이유: MCS 비기각은 동등성 검정이 아니며 confidence level도 85%다. · 교정: superior set에서 구분하지 못했다고 표현한다. · 근거: p10_mcs · p10_month

문헌에서 해결되지 않은 항목

  • 초기 overnight weights·insanity-filter 발생횟수·ARFIMA truncation과 bootstrap block distribution은 preprint에서 완전한 재현사양으로 닫히지 않는다.
  • 최종 IJF VOR의 저자페이지·copyediting·표 변경과 온라인 Supplement는 이 artifact와 전면 대조하지 않았다.
