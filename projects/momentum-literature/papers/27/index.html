27

VIX-managed portfolios

Miloš Božović · 2024 · International Review of Financial Analysis

경제성 평가보조추가자료 필요검수 완료독립검수 완료

30초 판정

과거 WML 가격정보의 대체가 아니라 VKOSPI라는 옵션시장 외부상태가 비용 후 scaling에 증분가치를 주는지 보는 경제성 challenger이며, 해당 시계열을 확보하기 전에는 구현 대상이 아니다.

사용할 때

  • 과거 realized risk와 forward-looking implied-risk signal을 비교할 때
  • weight 안정성과 거래비용이 alpha·Sharpe에 미치는 경로를 볼 때
  • 한국 확장에 필요한 VKOSPI 자료요건을 명시할 때

사용하지 말아야 할 때

  • 현재 WML 일별수익만으로 VIX 전략을 구현할 때
  • VIX를 개별 WML의 정확한 미래분산으로 부를 때
  • working-paper Table 9의 충돌을 숨기고 anomaly count를 인용할 때

한국 WML 변환기

고정

  • PIT KOSPI·12–2·6개 WML·월말 정보와 동일 BS15 target·cap을 유지한다.
  • 가격자료-only forecast 결과를 먼저 완결한다.
  • forecast calibration과 비용 후 경제성과를 별도 평가한다.

교체

  • CBOE VIX를 검증된 VKOSPI 일별 level과 방법론 이력으로 교체한다.
  • S&P 음수일 downside 정의를 KOSPI 지수 음수일 또는 WML 음수일 중 사전등록한 하나로 교체한다.
  • 원문의 c_t/variance 비중 대신 동일 BS15 mapping에 VKOSPI risk signal을 넣는다.

현재 입력

  • 6개 WML 일별·월별수익
  • KOSPI 지수 일별수익
  • 동일 BS15 경제성과 함수

부족한 입력

  • VKOSPI 일별 level·최초가용일·산출방법 변경 이력
  • 옵션·현물 거래일 정렬과 월말 가용성 원장
  • funding·세금·대차를 포함한 한국 비용자료

최소 구현 순서

  • VKOSPI 자료와 단위·방법론·calendar를 먼저 감사한다.
  • VKOSPI-level·downside-VKOSPI·RW126 세 신호만 사전 고정한다.
  • annualized VKOSPI를 BS15 월 위험단위로 일관되게 변환한다.
  • QLIKE·MSE calibration과 비용 후 Sharpe·최악월·turnover를 분리한다.

실패의 의미

VKOSPI challenger가 RW126보다 forecast 또는 비용 후 경제성과를 개선하지 못하면 해당 공통 옵션신호의 한국 6-WML 증분가치가 없다고 기록한다. 옵션정보 일반의 무용성을 뜻하지 않는다.

구현 단위검사

  • VKOSPI 월말 이후 수정·look-ahead 차단 test
  • annualized-to-monthly 단위 test
  • 현물·옵션 거래일 정렬 test
  • downside day definition lock test
  • 동일 BS15 target·cap test
  • Table-like sign counts 합계 test

주장 방화벽

허용 주장

  • working paper의 미국 표본에서 VIX scaling은 RV scaling보다 weight가 안정적이고 비용 후 alpha가 잘 유지됐지만 Sharpe 우위는 제한적이었다.

    이유: Tables 5·6·8이 alpha, Sharpe와 weight-change 경로를 분리한다. · 교정: working-paper 판본과 stylized overlay cost를 함께 적는다. · 근거: p27_anomalies · p27_cost · p27_turnover

  • 한국에서는 VKOSPI를 확보한 뒤 외부상태 economic challenger로 검정할 수 있다.

    이유: VIX는 test asset 자체의 과거수익이 아닌 옵션시장 공통신호다. · 교정: VKOSPI 자료감사 전에는 구현 가능하다고 쓰지 않는다. · 근거: p27_risk_proxies

금지 주장

  • 현재 WML 일별수익만으로 VIX-managed 전략을 구현할 수 있다.

    이유: forward-looking 옵션지수 시계열이 별도 입력으로 필요하다. · 교정: VKOSPI를 추가자료로 명시한다. · 근거: p27_risk_proxies

  • VIX는 모든 factor의 정확한 미래분산이고 양의 alpha는 곧 Sharpe 개선이다.

    이유: VIX는 공통 시장·tail proxy이며 anomaly Sharpe 부호는 거의 반반이다. · 교정: alpha·Sharpe·calibration을 분리한다. · 근거: p27_anomalies

  • Table 9의 0bp anomaly counts는 오류 없이 176개와 일치한다.

    이유: downside-VIX row가 Table 5와 충돌하고 합계가 186이다. · 교정: Table 5를 기준으로 하고 Table 9 충돌을 명시한다. · 근거: p27_anomalies · p27_table9_conflict

문헌에서 해결되지 않은 항목

  • 2024년 IRFA VOR에서 Table 9·Figure 1 기간충돌이 수정됐는지 이 레코드에서 판본 간 대조하지 않았다.
  • VKOSPI 자료·최종 저자코드와 anomaly 원자료 재계산은 근거 범위 밖이다.
