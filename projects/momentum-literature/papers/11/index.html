11

Decoupling the Short- and Long-Term Behavior of Stochastic Volatility

Mikkel Bennedsen · Asger Lunde · Mikko S. Pakkanen · 2022 · Journal of Financial Econometrics

핵심 예측필독적응 필요검수 완료독립검수 완료

30초 판정

단기 roughness와 장기 persistence를 한 계수로 뭉개지 않고 분리하는 장기의존 challenger를 설계할 때 읽는 필수 문헌이다.

사용할 때

  • RW126보다 긴 정보가 다음달 WML 위험예측에 추가 가치를 주는지 검정할 때
  • 로그분산 예측의 수준 재변환에서 Jensen 편향을 처리할 때
  • horizon별 모형순위와 복수 benchmark를 사전 고정할 때

사용하지 말아야 할 때

  • 일중 pre-averaged variation과 일별 WML 제곱수익 합을 같은 측정치로 취급할 때
  • 200관측 rolling 추정창을 126일 feature lookback과 동일시할 때
  • 한국 WML의 Sharpe 개선을 이 논문의 예측표만으로 선언할 때

방법 여권

data
CME E-mini S&P 500 tick 자료 2011-01-02–2014-12-31의 996거래일과 약 2천 개 미국주식의 보조 횡단면 [원문 보고] · 점프와 미시구조 잡음에 강건한 pre-averaged bipower variation 및 일중 계절조정 [원문 보고]
target
15·30·65분 또는 1일 간격에서 앞으로 1·2·5·10·20개 구간의 integrated variance 합 [원문 보고]
information set
각 origin까지 관측된 로그 realized measure와 그 시점에 추정 가능한 계절요인 [원문 보고]
lookback
모수추정은 최근 200관측 rolling window; 모형의 장기 kernel history와는 별개 [원문 보고]
horizon
1·2·5·10·20 step; 1일 간격 20-step이 약 한 달에 가장 가깝다 [원문 보고]
model family
Cauchy, Power-BSS, Gamma-BSS의 short/long-dependence 분리 모형과 RW·AR·ARMA·log-HAR·ARFIMA·RFSV
training window
각 forecast origin에서 최근 200개 관측을 고정 길이로 사용한다.
retune
모형은 rolling origin마다 다시 추정하며 window와 후보군을 위한 별도 nested validation은 보고하지 않는다.
benchmarks
random walk · AR(5) · AR(10) · ARMA(1,1) · log-HAR · ARFIMA · RFSV
loss / test
MSE · QLIKE · 75%·90% Model Confidence Set · block bootstrap 25,000회와 block length 6
economic metrics
포트폴리오 Sharpe·CER·turnover는 보고되지 않는다.
trading costs
거래전략을 구성하지 않아 거래비용을 평가하지 않는다.
turnover
포트폴리오 비중과 회전율을 평가하지 않는다.

한국 WML 변환기

고정

  • PIT KOSPI, 12–2 신호, 월별 형성과 다음 달 보유, D10·Q5·P30 × VW·EW의 6개 WML을 고정한다.
  • BS15 RW126과 연 12% 목표 스케일링을 기준선으로 보존하고 위험예측치만 교체한다.
  • forecast loss와 BS15 경제성과를 서로 다른 gate로 보고한다.

교체

  • 일중 integrated variance를 다음 보유월의 WML 일별 제곱수익 합으로 교체한다.
  • 연속시간 BSS 원형 대신 월말 정보만 쓰는 discrete short/long-kernel challenger를 사용한다.

현재 입력

  • 6개 구성의 일별 WML
  • 6개 구성의 월별 WML
  • 월말 formation 원장
  • RW126 기준예측과 공통 경제성과 함수

부족한 입력

  • E-mini형 tick 자료와 pre-averaged bipower variation
  • 일중 계절성과 미시구조 잡음을 같은 방식으로 보정한 WML measure

최소 구현 순서

  • 월말마다 다음 약 21–22거래일 WML 제곱수익 합을 target으로 정의하고 log floor를 사전 고정한다.
  • RW126·log-AR·HAR·MLOG 뒤에 short/long kernel 또는 fractional challenger를 둔다.
  • window·kernel·재변환 방식은 각 outer origin의 과거 validation에서만 선택한다.
  • MSE·QLIKE·DM/MCS 표와 동일 BS15 mapping의 Sharpe·최악월·drawdown·turnover 표를 분리한다.

실패의 의미

장·단기 분리 모형이 한국 6개 WML의 공통 OOS에서 단순 HAR/MLOG를 이기지 못하면, 해당 표본에서는 추가 long-dependence 복잡성의 증분가치가 없다고 해석한다.

구현 단위검사

  • 미래 수익을 바꿔도 과거 origin의 feature·forecast가 변하지 않는 prefix-invariance test
  • 200관측 estimation window와 feature lag를 별도 열로 검증하는 window-semantics test
  • 로그예측의 단순 지수변환과 Jensen 보정을 구분하는 level-transform test
  • 6개 모형 출력에 동일한 BS15 scaling 함수만 적용하는 common-mapping test

주장 방화벽

허용 주장

  • 검증한 저자 선행판에서는 단기 roughness와 장기 persistence를 분리한 모형이 여러 RV horizon에서 경쟁력 있는 예측을 보였다.

    이유: 모형 정의와 Tables 4–5가 horizon·loss별 결과를 제시한다. · 교정: 판본, E-mini 일중자료, horizon과 loss를 함께 적고 MCS의 공동 생존을 밝힌다. · 근거: p11_model · p11_table4 · p11_table5

  • 한국 WML에서는 short/long 정보분리를 복잡모형의 사전 정당화가 아니라 검정 가능한 challenger로 사용할 수 있다.

    이유: 논문 자체가 horizon별 winner 변화와 측정오차 한계를 함께 보인다. · 교정: RW126·HAR·MLOG를 같은 origin에서 비교하고 경제성과를 별도 평가한다. · 근거: p11_table5 · p11_limit

금지 주장

  • 이 논문은 한국 WML의 다음달 분산과 Sharpe 개선을 입증했다.

    이유: 표본·측정치·투자전략이 모두 다르며 경제성과를 평가하지 않는다. · 교정: 한국 6개 WML에서 forecast와 economic gate를 새로 실행한다. · 근거: p11_target · p11_limit

  • 200관측 rolling window는 BS15의 126거래일 위험 lookback과 같은 뜻이다.

    이유: 전자는 모수 추정창이고 후자는 위험 feature 정의다. · 교정: training window와 feature lookback을 별도 항목으로 기록한다. · 근거: p11_target

  • Table 4–5의 선행판 locator를 최종 JFEC 조판 페이지로 사용할 수 있다.

    이유: 실제로 읽은 artifact는 최종 게재 전 판본이다. · 교정: 결과에는 선행판임을 붙이고 최종본 locator는 별도 판본감사 뒤에만 추가한다. · 근거: p11_table4 · p11_table5

문헌에서 해결되지 않은 항목

  • 최종 JFEC 조판본과 2021년 선행판의 모든 표·부록을 문장 단위로 대조한 증거는 이 레코드 범위에 포함되지 않는다.
  • 저자 코드와 원 tick 자료를 이용한 독립 수치 재현은 이 레코드 범위에 포함되지 않는다.
