The Contribution of Jump Signs and Activity to Forecasting Stock Price Volatility

Ruijun Bu · Rodrigo Hizmeri · Marwan Izzeldin · Anthony Murphy · Mike G. Tsionas · 2023 · Journal of Empirical Finance

방법 확장후속 확장추가자료 필요검수 완료독립검수 완료

30초 판정

signed finite/infinite jump 원형에는 초고빈도 자료가 필요하지만, 실시간 OOS loss로 강한 baseline forecast를 결합하는 규약은 현재 자료에도 적응 가능한 후속확장 문헌이다.

사용할 때

  • sampling frequency와 noise correction이 jump decomposition을 얼마나 바꾸는지 볼 때
  • 단일 사후 winner 대신 equal·inverse-MSPE·inverse-rank ensemble을 설계할 때
  • MCS membership과 combination weights를 origin별로 감사할 때

사용하지 말아야 할 때

  • 큰 음의 일별 WML 수익을 negative finite 또는 infinite jump라고 부를 때
  • 전체 OOS loss로 사후 weight를 만들어 실시간 forecast라고 할 때
  • MSPE 개선을 WML Sharpe 개선으로 번역할 때

한국 WML 변환기

고정

  • PIT KOSPI·12–2·6개 WML·BS15 RW126 target와 mapping을 고정한다.
  • 각 WML 안에서 같은 origin·target의 base forecasts만 결합한다.
  • forecast loss와 economic performance를 별도 gate로 둔다.

교체

  • 현 단계에서는 jump decomposition이 아니라 RW126·HAR·MLOG 등의 forecast matrix를 결합한다.
  • 원형 jump 연구는 동시시각 intraday 종목자료 확보 뒤 별도 확장한다.

현재 입력

  • 6개 WML의 origin별 RW126·HAR·log-HAR·MLOG forecasts
  • 각 origin 이전에 실현된 OOS losses
  • 동일 BS15 economic mapping

부족한 입력

  • 구성종목의 tick 또는 최소 5분 동기화 가격
  • signed finite/infinite jump test용 noise-robust realized measures
  • 동일 규칙의 거래시각·corporate-action 자료

최소 구현 순서

  • 각 WML별 base forecast matrix를 만들고 서로 다른 WML targets는 섞지 않는다.
  • 최소 36개월 과거 OOS loss 뒤 equal·inverse-MSPE·inverse-rank를 origin별로 계산한다.
  • minimum-variance 조합에는 ridge·weight bound·singular 처리 규칙을 사전 고정한다.
  • component forecasts·weights·available-through date를 저장하고 forecast와 economic 표를 분리한다.

실패의 의미

조합이 best single baseline과 equal weight를 loss·경제성과에서 이기지 못하면 adaptive ensemble의 증분가치를 기각하며 jump mechanism의 실패로 확대하지 않는다.

구현 단위검사

  • 각 weight가 origin 이전 realized losses만 참조하는 prefix test
  • 여섯 WML targets 사이 forecast mixing을 차단하는 identity test
  • weights 합·bound·singular fallback test
  • first-combination month의 minimum-history test

주장 방화벽

허용 주장

  • 검증한 working paper의 미국 고빈도 표본에서는 jump-model winner가 horizon과 sampling에 따라 달랐고 실시간 loss 기반 forecast combinations가 HAR보다 낮은 MSPE를 보인 경우가 많았다.

    이유: 측정·rolling 설계와 Tables 3·4·8·11이 조건부 결과를 제시한다. · 교정: working paper, SPY·20 stocks, sampling, horizon과 forecast-only 평가를 붙인다. · 근거: p19_measure · p19_design · p19_table3 · p19_table4 · p19_table8 · p19_table11

금지 주장

  • 큰 음의 일별 WML 수익은 negative finite 또는 infinite jump다.

    이유: 원형 분류에는 초고빈도 path와 ABD·SFA tests가 필요하다. · 교정: 일별 downside proxy와 intraday jump를 구분한다. · 근거: p19_measure

  • 전체 OOS 성과로 고른 weight는 실시간 implementable combination이다.

    이유: 미래 realized errors가 weight에 들어가면 leakage다. · 교정: 각 origin 이전 forecast errors만 사용한다. · 근거: p19_design · p19_combine

  • MSPE 개선은 한국 WML의 Sharpe 개선을 뜻한다.

    이유: 논문은 투자전략·비용·경제가치를 평가하지 않는다. · 교정: 동일 BS15 economic gate를 별도로 실행한다. · 근거: p19_table8

문헌에서 해결되지 않은 항목

  • 최종 JEF 조판본과 2022년 개정 working paper의 전 표 판본대조 및 TickData 기반 독립 재현은 이 레코드 범위에 포함되지 않는다.
  • 많은 사양·frequency·loss 비교의 multiplicity는 MCS만으로 완전히 제거되지 않는다.
  • Minimum-variance combination covariance history, singular-matrix handling, and weight constraints are not fully specified in the working paper.
