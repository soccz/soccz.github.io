Multivariate Leverage Effects and Realized Semicovariance GARCH Models

Tim Bollerslev · Andrew J. Patton · Rogier Quaedvlieg · 2020 · Journal of Econometrics

방법 확장후속 확장추가자료 필요검수 완료독립검수 완료

30초 판정

15분 동시수익의 부호조합으로 연속적 multivariate leverage를 모델링하는 최종 원전이지만, 현재 일별 WML 본선에는 daily-sign 축약만 가능한 후속확장 문헌이다.

사용할 때

  • 다음날 covariance에 joint-negative와 mixed-sign variation이 주는 효과를 분리할 때
  • daily threshold와 continuous intraday asymmetry를 비교할 때
  • 다변량 WML allocation을 별도 연구질문으로 설계할 때

사용하지 말아야 할 때

  • 일별 negative WML squared return을 realized negative semicovariance라고 부를 때
  • 단일전략 scaling에 목적 없이 24차원 DCC를 넣을 때
  • covariance loss 개선을 WML Sharpe 개선으로 번역할 때

문제

전통 leverage model은 하루 전체수익이 음수인지 양수인지 한 번만 보고 그날 covariance shock을 분류한다. 실제 하루 안에는 같은 방향과 반대방향 움직임이 섞이므로 일중 부호비중을 연속적으로 보존하면 다변량 위험반응을 더 정확히 볼 수 있다.

중심 질문

15분 realized covariance를 positive-positive, negative-negative와 두 mixed-sign components로 나눠 GARCH·DCC에 넣으면 daily-sign threshold보다 다음날 covariance forecast와 crisis correlation 반응이 개선되는가?

기존 문헌의 빈틈

GJR·threshold DCC는 하루 한 번의 sign으로 모든 variation을 good 또는 bad로 분류하고, symmetric realized-GARCH는 고빈도 covariance를 쓰더라도 방향을 지운다. 고차원에서 continuous asymmetric information을 안정적으로 쓰는 비교가 필요했다.

논문의 답

저자들은 24개 DJIA 주식과 S&P 500의 동기화된 15분수익으로 RCOV=P+N+M+ +M− 분해를 만들고, bivariate BG 계열과 24차원 DCC 계열에 component별 반응을 허용한다. In-sample likelihood와 news-impact/IRF는 continuous asymmetry를 지지한다. OOS에서는 bivariate Frobenius의 최저가 crBG-S인 반면 QLIKE 최저는 daily-threshold tBG여서 단일 winner가 아니지만, 24차원 두 loss에서는 crDCC가 가장 강하다. 한국 WML 일별자료는 원형을 재현할 수 없고, joint covariance가 실제 allocation target일 때만 synchronized intraday six-WML panel 확장을 정당화할 수 있다.

수식은 암기 대상이 아니라 입력·출력·시점·실패 조건을 고정하는 계약입니다.

RCOV = P + N + M_plus + M_minus

표본과 입력

  • 2000–2014 내내 거래된 DJIA 24종목과 value-weighted S&P 500, 3,773일을 사용한다.
  • daily return outer products와 동기화된 15분 RCOV·semicovariance를 병렬 입력으로 만든다.
  • 한국 원형에는 당시 WML constituent의 PIT weights와 synchronized intraday bars가 필요하다.

예측대상과 시점

  • target은 다음날 conditional covariance H이고 ex-post proxy는 다음날 15분 RCOV다.
  • bivariate는 각 stock–market 2×2, 고차원은 24-stock 24×24 one-step forecast다.
  • 30일 IRF는 simulation response이지 30일 OOS target이 아니다.

추정과 표본외 검증

  • QMLE·covariance targeting으로 적합하고 최근 1,000일 rolling window를 쓴다.
  • parameter는 20관측마다 재추정하고 사이 날짜에는 carry-forward해 2,773 one-step forecasts를 만든다.
  • margin class selection과 target mean은 training window 안에서만 수행해야 한다.

평가와 통과 기준

  • in-sample likelihood·LR/Rivers–Vuong과 OOS Frobenius·QLIKE를 분리한다.
  • bivariate MCS inclusion fraction과 high-dimensional MCS p-value를 다른 단위로 저장한다.
  • covariance loss 뒤 실제 allocation utility·weight stability·cost를 별도 gate로 추가한다.

왜 작동하는가: 메커니즘과 반증 저자 제안 · 검토자 진단

저자가 제안한 작동 경로

  • joint negative intraday variation은 future variance·covariance를 더 크게 올리고, mixed signs는 asset ordering에 따라 다른 correlation response를 만든다.
  • continuous component shares는 하루 sign threshold가 지우는 intraday reversal·co-movement 정도를 보존한다.
  • 고차원 correlation에서는 여러 pair의 signed signals가 공통 crisis state를 더 선명하게 드러낼 수 있다.

그 경로를 지지하는 관찰

  • Table 3 fit과 news-impact/IRF 방향은 negative concordant·mixed response 차이를 지지한다.
  • Table 7의 crDCC two-loss 우위는 고차원 signed-correlation channel과 일치한다.

경쟁 설명

  • survivor 대형주와 15분 frequency·cleaned data가 continuous measures에 유리할 수 있다.
  • full-sample margin class 선택 또는 covariance target이 OOS 성과를 낙관적으로 만들 수 있다.

반증되려면 무엇이 보여야 하나

  • training-only margin selection 아래 crDCC가 tDCC·rDCC 대비 두 loss를 개선하지 못하면 continuous correlation channel을 기각한다.
  • covariance loss가 좋아도 portfolio weights가 불안정하고 비용 후 utility가 악화되면 실전 채널을 기각한다.

강건성·한계·빈칸 검토자 종합

버틴 결과

  • bivariate와 24차원, threshold·realized·continuous families, 두 matrix losses를 비교한다.
  • likelihood뿐 아니라 NIS·IRF·rolling OOS와 MCS를 연결한다.

약해지는 조건

  • bivariate QLIKE에서는 daily threshold가 continuous model보다 강하다.
  • split asymmetry가 유의한 종목은 전체가 아니며 한 frequency만 사용한다.

검증하지 않은 것

  • 한국 WML, multi-step covariance, portfolio Sharpe·turnover·cost와 alternative intraday frequencies를 시험하지 않았다.
  • 온라인 Supplement의 종목별 loss·margin table을 현재 근거에서 확인하지 못했다.

실험 순서

  • 먼저 단일 WML 목적에는 RW126·HAR·daily-sign asymmetric challenger만 비교한다.
  • joint allocation 질문을 사전 정의하고 여섯 WML의 synchronized intraday returns를 구축한다.
  • 매일 RCOV/P/N/M identities·PSD·eigenvalues를 검사한다.
  • DCC·tDCC·rDCC·trDCC·crDCC를 동일 rolling window·optimizer로 적합한다.
  • one-step 또는 사전 고정 monthly covariance target의 Frobenius·QLIKE·MCS를 계산한다.
  • regularized allocation에 넣어 weight stability·turnover·cost·utility를 평가한다.

채택 기준

  • 모든 matrix identity와 timestamp alignment가 tolerance를 통과한다.
  • margin class·covariance target·hyperparameter가 outer target을 보지 않는다.
  • crDCC가 두 matrix loss 중 사전 주 loss를 개선하고 비용 후 allocation utility도 악화시키지 않는다.

실패 진단

  • bivariate만 실패하면 loss conflict와 asset-order split 필요성을 진단한다.
  • 고차원 PSD failure가 나면 mixed matrix·target shrinkage·parameter bounds를 점검한다.
  • loss는 개선되고 utility가 악화되면 covariance inversion·weight regularization·turnover를 원인으로 분리한다.

한국 WML 변환기

고정

  • PIT KOSPI·12–2·6개 WML·BS15 RW126과 월별 target을 본선에서 고정한다.
  • 대칭 baseline과 비대칭 challenger를 같은 origin에서 비교한다.
  • forecast와 economic gate를 분리한다.

교체

  • 현재는 같은 126일 WML return의 positive/negative squared sums를 쓰는 GJR·downside-HAR로 축약하고 daily-sign adaptation으로 표시한다.
  • 원형은 구성종목의 동기화된 15분 수익과 월별 PIT weights가 확보된 뒤 crBG/crDCC로 확장한다.

현재 입력

  • 6개 일별 WML
  • positive·negative daily squared-return features
  • RW126·HAR·GJR baselines

부족한 입력

  • 구성종목의 동기화된 15분 가격
  • 월별 PIT holdings와 interval weights
  • overnight·stale price·corporate action 처리자료
  • realized semicovariance matrices

최소 구현 순서

  • 본선에서는 symmetric RW126·HAR와 daily-sign GJR/downside-HAR만 다음달 target에 비교한다.
  • 6개 WML joint covariance 예측의 경제적 목적이 생길 때만 daily DCC를 먼저 baseline으로 둔다.
  • intraday 확장에서는 RCOV=P+N+M+ +M− 항등식과 positive definiteness를 매일 감사한다.
  • MSE·QLIKE·DM/MCS와 동일 BS15 scaling의 경제성과를 별도 표로 보고한다.

실패의 의미

daily downside proxy가 symmetric baseline을 이기지 못하면 coarse 비대칭 정보의 증분가치만 기각하며, 원형 intraday semicovariance channel의 실패로 확대하지 않는다.

구현 단위검사

  • 원형 RCOV component-sum identity test
  • rolling sample 안에서만 covariance target을 계산하는 prefix test
  • filtered covariance의 symmetry·positive-definiteness test
  • daily-sign adaptation과 realized semicovariance 원형을 구분하는 label test

  • 최종 Journal of Econometrics VOR의 미국 대형주 표본에서 realized semicovariance 기반 continuous asymmetry가 다변량 fit과 여러 OOS covariance losses를 개선했다.

금지 주장

  • 일별 negative WML squared return은 realized negative semicovariance다.

    이유: 원형에는 두 자산 이상의 동시 15분 부호 outer products가 필요하다. · 교정: daily-sign downside proxy로 부른다. · 근거: p20_components · p20_models · p20_data

  • crBG-S는 모든 OOS loss에서 최저다.

    이유: bivariate QLIKE 최저는 tBG였다. · 교정: Frobenius와 QLIKE 결과를 함께 제시한다. · 근거: p20_table4

  • covariance forecast 개선은 한국 WML Sharpe 개선을 뜻한다.

    이유: 논문은 portfolio allocation·trading cost·economic value를 평가하지 않는다. · 교정: joint allocation 목적과 별도 economic gate를 새로 정의한다. · 근거: p20_table7

문헌에서 해결되지 않은 항목

  • Supplemental Appendix와 cleaned 15분 원자료·코드 기반 독립 재현은 이 레코드 범위에 포함되지 않는다.
  • 다른 sampling frequency와 microstructure-noise correction의 민감도는 본문 표만으로 비교되지 않는다.
  • Selection timing for the best univariate margin class used in the 24-dimensional rolling OOS is not fully specified; a nested origin-only selection cannot be assumed.
