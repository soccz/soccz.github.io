21

Downside Risk and the Performance of Volatility-Managed Portfolios

Feifei Wang · Xuemin Sterling Yan · 2021 · Journal of Banking & Finance

경제성 평가우선적응 필요검수 완료독립검수 완료

30초 판정

미래분산 forecast 모형이 아니라 총위험과 하방위험 scaling의 경제성과·메커니즘·실시간 구현을 비교하는 문헌으로, RW126 뒤의 하방위험 적응과 비용 gate에 사용한다.

사용할 때

  • 한국 WML 일별수익만으로 총실현분산과 하방 준분산 challenger를 만들 때
  • 성과를 return timing과 volatility timing으로 분해할 때
  • full-sample 정규화와 120개월 expanding 실시간 결합을 구별할 때

사용하지 말아야 할 때

  • 하방 준분산이 미래 WML 분산을 가장 정확히 예측한다고 주장할 때
  • 원문의 직전 1개월 역실현변동성 규칙과 한국 RW126·12% 목표변동성 적응을 같은 전략으로 부를 때
  • 낮은 overlay 비용 결과를 실제 종목·대차비용 전체로 확대할 때

한국 WML 변환기

고정

  • PIT KOSPI·12–2·월별 형성과 다음 달 보유의 6개 WML 및 BS15 RW126 경제성과 기준을 고정한다.
  • 모든 challenger에 같은 target vol·cap·평가월·비용 시나리오를 적용한다.
  • forecast loss와 return/volatility timing 및 경제성과를 별도 결과층으로 둔다.

교체

  • 원문의 직전 1개월 총·하방 실현변동성 역수 비중을 126일 총·하방 제곱수익합의 제곱근을 위험입력으로 쓰는 고정 BS15 scaling으로 적응한다.
  • 미국 103개 포트폴리오를 상관된 한국 6개 WML 공통표본으로 교체한다.

현재 입력

  • 6개 구성의 일별·월별 WML
  • 월말 PIT 형성원장
  • RW126·12% scaling과 공통 경제성과 함수

부족한 입력

  • 원문의 Internet Appendix 개별 표
  • 종목 수준 drifted holdings·spread·대차비용
  • 한국에서 검증된 하방위험 최소관측일 규칙

최소 구현 순서

  • 각 월말 같은 126일 창에서 RV126과 음수일 DSV126을 계산한다.
  • RW126-BS15와 DSV126-BS15만 먼저 비교하고 창·cap·target을 결과 뒤에 바꾸지 않는다.
  • QLIKE·MSE 예측표와 Sharpe·최악월·turnover·비용 후 표를 분리한다.
  • 6개별 방향과 월 단위 block bootstrap의 평균 차이를 함께 보고한다.

실패의 의미

DSV126이 RW126보다 forecast loss 또는 비용 후 Sharpe를 개선하지 못하면 한국 6-WML의 고정 BS15 구조에서 하방위험 적응의 증분가치가 없다고 기록하며, 미국 원형 전체를 반박하지 않는다.

구현 단위검사

  • 모든 위험입력이 비중 적용월 시작 전에 끝나는 prefix-invariance test
  • RV126과 DSV126이 같은 관측 mask·연율단위를 쓰는 test
  • 레버리지 cap과 비용차감 산식 test
  • 6개 전략의 공통 평가월 row-hash test

주장 방화벽

허용 주장

  • 미국 요인·이상현상 표본에서 하방위험 관리는 총위험 관리보다 더 넓은 경제성과를 보였고 return timing의 역할이 컸다.

    이유: Tables 1–6의 spanning·분해 결과가 같은 방향을 보인다. · 교정: 항상 미국 표본, 경제성과 결과, 비용·실시간 조건을 함께 적는다. · 근거: p21_method · p21_cross_section · p21_decomposition

  • 한국에서는 하방위험을 고정 BS15 scaling 안의 적응 challenger로 시험할 수 있다.

    이유: 현재 일별 WML로 같은 시점의 총제곱수익과 음수일 제곱수익을 계산할 수 있다. · 교정: 원문의 직전 1개월 역실현변동성 원형과 RW126 적응을 이름으로 분리한다. · 근거: p21_method

금지 주장

  • 하방 준분산은 미래 WML 분산을 가장 정확하게 예측한다.

    이유: 논문의 주평가는 spanning alpha·Sharpe·효용이지 QLIKE·MSE horse race가 아니다. · 교정: 한국에서 별도 forecast loss를 계산한 뒤 경제성과와 분리 보고한다. · 근거: p21_method · p21_direct_metrics

  • 하방관리의 비용 후 우위는 실제 종목 거래비용을 완전히 통과했다.

    이유: Table 4는 overlay 비중변화에 단순 bp를 적용하며 종목 재구성·대차·시장충격을 포함하지 않는다. · 교정: weight-change cost proxy로 표기하고 종목자료가 있을 때 별도 비용 gate를 둔다. · 근거: p21_cost
