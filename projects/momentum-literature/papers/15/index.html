Realized Semicovariances

Tim Bollerslev · Jia Li · Andrew J. Patton · Rogier Quaedvlieg · 2020 · Econometrica

방법 확장후속 확장추가자료 필요검수 완료독립검수 완료
이 페이지에서30초 판정문제와 답논증수식표 읽기한국 실험자가점검원문 위치

30초 판정

종목들의 동시 일중 부호로 공분산을 분해하는 이론·예측 원전이며, 현재 합성 일별 WML만으로는 원형을 계산할 수 없는 후속확장 문헌이다.

사용할 때

  • positive-positive·negative-negative·mixed covariance 정보를 정의할 때
  • portfolio variance의 signed component가 정확히 합계로 복원되는지 확인할 때
  • 고차원 부호분해에 parsimonious restriction이 필요한 이유를 설명할 때

사용하지 말아야 할 때

  • WML 한 개의 음의 일별 제곱수익을 realized semicovariance라고 부를 때
  • 구성종목의 동시 일중수익 없이 P·N·M matrix를 계산했다고 할 때
  • 평균 loss ratio 차이를 모두 통계적으로 유의하다고 말할 때

문제

단일 포트폴리오 수익의 양·음 제곱만 보면 구성종목들이 같은 방향으로 움직였는지 서로 엇갈렸는지 사라진다. 이 논문은 covariance를 일중수익 부호쌍으로 정확히 분해해 비대칭 위험의 정보가 어디서 오는지 보여 준다.

중심 질문

realized covariance의 positive·negative·mixed semicovariance가 directional co-jump와 서로 다른 동학을 보이며, 이를 제한적으로 HAR에 넣으면 portfolio variance 예측이 개선되는가?

기존 문헌의 빈틈

realized semivariance는 한 자산의 상승·하락 variation을 나누지만 다변량 포트폴리오에서 동시 부호정보를 보존하지 못한다. 모든 성분을 자유롭게 넣으면 과적합되기 쉬워 이론적 분해와 parsimonious forecast restriction이 함께 필요했다.

논문의 답

저자들은 동기화된 일중 벡터수익을 positive-positive P, negative-negative N, mixed M으로 나누고 C=P+N+M 항등식을 만든다. Theorem 1은 P와 N의 연속부분 1차 극한이 같고 방향성 co-jump가 차이를 만들 수 있음을 보인다. 이어 DJIA pair 결과와 S&P random-portfolio forecast를 연결한다. unrestricted SCHAR는 QLIKE가 악화되지만 Table 2 동학을 제한한 SCHAR-r는 특히 큰 portfolio와 22일 horizon에서 HAR보다 낮은 loss를 보인다. 한국에서는 종목별 동기화 일중자료 없이는 원형을 구현할 수 없으며 WML factor의 일별 양·음 제곱은 더 거친 SHAR adaptation일 뿐이다.

핵심 개념을 내 말로 바꾸기

realized semicovariance

쉽게 말하면
두 자산이 같은 일중시각에 각각 오르고 내린 부호조합별로 공분산 기여를 나눈 값이다.

논문 안의 역할
positive·negative concordant와 mixed discordant 움직임을 covariance 안에서 보존한다.

흔한 오독
한 WML 수익의 양·음 제곱인 semivariance와 같은 객체가 아니다.

mixed component M

쉽게 말하면
한 자산은 오르고 다른 자산은 내린 일중수익쌍의 공분산 기여다.

논문 안의 역할
P+N만으로 설명되지 않는 반대부호 동시움직임을 채워 C=P+N+M을 성립시킨다.

흔한 오독
M은 대각이 0이고 indefinite일 수 있어 독립된 variance matrix처럼 읽으면 안 된다.

수식과 의사결정 규칙 해부 저자 방법 · 검토자 해설

수식은 암기 대상이 아니라 입력·출력·시점·실패 조건을 고정하는 계약입니다.

semicovariance identity · 각 동시 일중수익 벡터를 양의 부분과 음의 부분으로 쪼개 같은 부호 outer products와 반대부호 outer products를 모두 더하면 원 realized covariance가 정확히 복원된다.

직관: 포트폴리오 수익 하나로 합치기 전에 누가 누구와 같은 방향으로 움직였는지를 보존한다.

구현할 때: matrix symmetry, P/N PSD, M diagonal zero, C=P+N+M을 매일 unit test해야 한다.

표본과 입력

  • 이론·검정 실증은 DJIA 30종목 1분자료, 예측 실증은 S&P 500 종목 15분자료를 사용한다.
  • 500개씩 뽑은 동일가중 10·100종목 portfolio에서 intraday covariance와 components를 만든다.
  • 한국 원형에는 PIT 종목 weights와 동기화된 일중수익이 추가로 필요하다.

예측대상과 시점

  • 주 target은 다음날 portfolio realized variance이고 direct 5·22일 target도 본다.
  • HAR daily·weekly·monthly features는 서로 겹치지 않는 t, t-1:t-4, t-5:t-21 구간이다.
  • 1,000일 rolling estimation은 feature lookback과 별개다.

추정과 표본외 검증

  • 각 random portfolio에 최근 1,000일로 HAR·SHAR·SCHAR·SCHAR-r를 매일 재추정한다.
  • SCHAR-r restriction은 component dynamics 결과로 동기화돼 완전 독립 validation에서 고른 것은 아니다.
  • 한국에서는 restriction을 사전 고정하거나 inner training에서만 선택한다.

평가와 통과 기준

  • MSE·QLIKE의 평균 loss와 portfolio별 HAR relative-loss 평균을 구분한다.
  • 종목수 2–100의 dispersion과 1·5·22일 horizon을 함께 본다.
  • forecast loss 뒤에 formal block inference와 BS15 경제성과를 별도 추가한다.

왜 작동하는가: 메커니즘과 반증 저자 제안 · 검토자 진단

저자가 제안한 작동 경로

  • 동시 positive·negative·mixed 움직임은 방향성 co-jump 노출과 이후 persistence가 달라 total covariance 하나가 지우는 정보를 남길 수 있다.
  • 큰 portfolio에서는 합성수익 하나가 지우는 횡단면 부호정보의 가치가 커진다.
  • SCHAR-r는 유용한 recent negative와 persistent mixed 정보를 남기면서 분산을 줄인다.

그 경로를 지지하는 관찰

  • pair 검정과 Table 2 동학은 components가 같은 AR 구조를 갖지 않는다는 방향을 보인다.
  • Table 3·4에서 restricted 모형만 안정적으로 개선되고 portfolio size에 따라 이득이 커지는 패턴이 mechanism과 맞는다.

경쟁 설명

  • SCHAR-r restriction이 같은 표본의 full-sample 계수패턴을 보고 선택돼 성능이 낙관적일 수 있다.
  • 미국 대형주 intraday 동시성·positive correlation이 mixed component persistence를 만들었을 수 있다.

반증되려면 무엇이 보여야 하나

  • training-only restriction으로 재선택했을 때 SCHAR-r가 HAR·SHAR보다 OOS QLIKE를 낮추지 못하면 forecast channel을 기각한다.
  • portfolio size를 키워도 이득이 늘지 않거나 intraday identity 오류가 크면 횡단면 정보채널을 기각한다.

강건성·한계·빈칸 검토자 종합

버틴 결과

  • 이론, 사건검정, component dynamics와 500 random portfolios의 다중 horizon을 연결한다.
  • unrestricted 실패를 그대로 보여 과적합 반증을 포함한다.

약해지는 조건

  • 작은 portfolio와 일부 horizon에서 SCHAR-r 이득이 사라진다.
  • 저빈도 일별 예시는 저자 스스로 infill 해석이 흐려진다고 경고한다.

검증하지 않은 것

  • 한국 WML, 비용·portfolio utility와 formal DM/MCS를 forecast tables에 적용하지 않았다.
  • 온라인 Supplement·random seed·종목구성·optimizer 세칙을 현재 근거로 확인하지 못했다.

내부 긴장과 해석 주의

  • restriction 선택에 full-sample pattern이 사용돼 evaluation과 완전히 독립적이지 않다.
  • 고빈도 이론의 directional channels와 일별·월별 coarse adaptation을 같은 이름으로 부를 수 없다.

  • 현재 단계에서 각 WML daily positive·negative variance features를 causal하게 만든다.
  • RW126·HAR·SHAR를 동일 22일 target으로 비교한다.

채택 기준

  • intraday 원형은 C=P+N+M과 portfolio quadratic identity가 매일 tolerance 내 성립한다.
  • restriction은 outer target을 보지 않고 고정되며 동일 OOS mask를 유지한다.
  • SCHAR-r 또는 SHAR가 HAR 대비 QLIKE를 개선하고 비용 후 하방지표를 악화시키지 않는다.

  • 큰 portfolio에서만 성공하면 diversification·measurement noise channel을 별도 표시한다.

한국 WML 변환기

고정

  • PIT KOSPI·12–2·6개 WML·BS15 RW126 기준선을 고정한다.
  • forecast target과 economic mapping을 공통으로 유지한다.
  • unrestricted 확장보다 사전 restriction을 우선한다.

교체

  • 현재 단계의 일별 WML positive/negative variation은 daily factor-return adaptation으로만 표시한다.
  • 원형 단계에서는 월별 PIT weight와 구성종목 동시 일중수익으로 P·N·M을 계산한다.

현재 입력

  • 6개 일별 WML
  • 6개 월별 WML
  • WML별 positive·negative daily squared-return proxy

부족한 입력

  • 구성종목들의 동기화된 일중수익
  • 각 월의 PIT portfolio weight로 계산한 realized semicovariance matrices
  • overnight·stale-price·미시구조 잡음 처리자료

최소 구현 순서

  • 현재는 RW126·HAR·daily-sign SHAR만 동일 target·origin에서 비교한다.
  • 원형 확장은 intraday panel과 PIT weight가 확보된 뒤 P+N+M=C 항등식을 매일 검증한다.
  • 표본 대비 모수가 많은 unrestricted SCHAR는 배제하거나 shrinkage를 사전 고정한다.
  • forecast MSE·QLIKE와 BS15 경제성과를 분리 보고한다.

실패의 의미

daily-sign adaptation이 실패하면 coarse factor-return 부호정보가 약하다고만 해석하며, 종목 간 일중 semicovariance 채널 자체를 기각하지 않는다.

구현 단위검사

  • 일중 원형에서 P+N+M=RCOV 항등식 test
  • PIT weight와 component matrix 날짜가 같은 formation 정보집합을 쓰는 test
  • daily-sign proxy를 semicovariance로 라벨링하지 않는 schema test
  • 모수 수가 training 관측 대비 사전 한도를 넘지 않는 complexity test

허용 주장

  • 검증한 working paper에서는 intraday return signs로 realized covariance를 분해한 parsimonious SCHAR-r가 특히 큰 portfolio와 22일 horizon에서 HAR보다 낮은 평균 loss를 보였다.

금지 주장

  • 일별 WML의 negative squared return은 realized negative semicovariance다.

    이유: semicovariance는 여러 자산의 동시 일중 부호가 만든 outer-product component다. · 교정: daily factor-return downside proxy로 부른다. · 근거: p15_definition · p15_portfolio

  • 현재 데이터로 P·N·M matrix를 복원할 수 있다.

    이유: 구성종목별 동시 일중수익과 PIT weight가 필요하다. · 교정: 원형은 additional-data 단계로 분리한다. · 근거: p15_portfolio · p15_design

  • SCHAR는 component를 더 많이 넣을수록 항상 좋아진다.

    이유: unrestricted SCHAR의 QLIKE가 크게 악화된 반례가 있다. · 교정: SCHAR-r와 unrestricted 결과를 함께 제시한다. · 근거: p15_table3
