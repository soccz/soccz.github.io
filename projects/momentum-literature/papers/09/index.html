09

HARK the SHARK: Realized Volatility Modeling with Measurement Errors and Nonlinear Dependencies

Giuseppe Buccheri · Fulvio Corsi · 2021 · Journal of Financial Econometrics

기준선우선적응 필요검수 완료독립검수 완료
이 페이지에서30초 판정문제와 답논증수식표 읽기한국 실험자가점검원문 위치

30초 판정

일별 WML에는 시간가변 계수를 다루는 Score-HAR만 직접 challenger로 쓰고, realized quarticity가 필요한 HARK·SHARK는 일중자료가 생길 때까지 이름과 구현을 분리한다.

사용할 때

  • HAR의 측정오차·이분산·시간가변 계수 기여를 분해할 때
  • Score-HAR가 constant log-HAR보다 안정적인지 시험할 때
  • 일중 RV/RQ가 갖춰진 뒤 Kalman HARK와 결합 SHARK를 구현할 때

사용하지 말아야 할 때

  • quarticity 없는 일별 제곱수익 모형을 HARK 또는 SHARK라 부를 때
  • Score-HAR 약어 SHAR를 signed-semivariance HAR와 혼동할 때
  • 90% MCS 포함을 모든 loss·빈도의 유일한 승리로 표현할 때

DEEP DIVE · 검토자 종합

왜 이 논문이 필요한가

딥다이브 독립검수 완료 · 2026-08-16 · 전체 서술과 동일 논문 근거 위치를 재대조했습니다.

출처 구분: 수식·연구설계·“저자 보고” 결과는 원문 내용이고, 해석·한계·자가점검은 검토자 종합, 한국 실험실은 프로젝트 적용안입니다.

문제

HAR가 틀리는 이유를 한꺼번에 '비선형성'이라 부르면 어떤 추가복잡성이 필요한지 알 수 없다. 이 논문은 측정오차, 이분산, 시간가변 계수를 별도 채널로 분해한다.

중심 질문

실현변동성의 관측오차를 Kalman filter로, 시간가변 의존성을 likelihood score로 처리하면 HAR 예측이 각각 얼마나 개선되고 두 채널을 합치면 추가가치가 있는가?

기존 문헌의 빈틈

HARQ 같은 보정은 측정오차와 비선형성을 섞을 수 있어, 어느 misspecification이 예측개선을 만드는지 구조적으로 분리할 기준모형이 필요했다.

논문의 답

저자 증거는 HARK의 측정오차 채널과 Score-HAR의 시간가변 계수 채널을 결합한 SHARK가 여러 일·주·월 OOS에서 강하다는 것이다. 다만 모든 빈도·loss에서 유일한 winner는 아니고 측정오차 이득은 sampling frequency에 따라 약해진다. 연구자 해석은 한국 일별 WML에서 quarticity 없이 구현 가능한 것은 Score-HAR뿐이라는 것이다. HARK·SHARK는 동기화된 일중 WML RV와 RQ가 확보될 때까지 data gate로 막고, constant log-HAR 대비 Score-HAR의 증분을 먼저 시험한다.

핵심 개념을 내 말로 바꾸기

measurement error

쉽게 말하면
일중수익으로 계산한 실현분산이 보이지 않는 진짜 적분분산을 정확히 재지 못하는 오차다.

논문 안의 역할
HARK 관측방정식의 날짜별 noise variance를 결정한다.

흔한 오독
일별 제곱수익만으로 원문의 quarticity 기반 오차분산을 만들 수 없다.

p09_hark · PDF 9쪽 · Equations 14–19, HARK state-space model

Kalman gain

쉽게 말하면
새 관측값을 잠재위험 추정에 얼마나 믿고 반영할지를 정하는 가중치다.

논문 안의 역할
quarticity가 큰 noisy day의 RV 영향을 낮춘다.

흔한 오독
항상 낮을수록 좋은 상수가 아니라 날짜별 관측신뢰도의 결과다.

p09_hark · PDF 9쪽 · Equations 14–19, HARK state-space model

Score-HAR

쉽게 말하면
최근 관측이 현재 likelihood에서 예상 밖인 방향만큼 HAR 계수를 갱신하는 모형이다.

논문 안의 역할
quarticity 없이도 시간가변 계수와 이분산에 적응한다.

흔한 오독
이 논문의 SHAR는 signed-semivariance HAR가 아니다.

p09_scorehar · PDF 12쪽 · Equations 22–26, Score-HAR update

SHARK

쉽게 말하면
HARK의 측정오차 필터와 Score-HAR의 시간가변 계수를 한 state-space 안에 합친 모형이다.

논문 안의 역할
두 misspecification channel의 결합 이득을 측정한다.

흔한 오독
quarticity 입력 없이 이름만 SHARK로 쓰면 원형이 아니다.

수식은 암기 대상이 아니라 입력·출력·시점·실패 조건을 고정하는 계약입니다.

연구설계 따라가기 저자 보고

표본과 입력

  • 미국 지수선물과 유동 주식의 일중 가격으로 RV·RQ를 여러 sampling frequency에서 계산한다.
  • HAR의 단기·주간·월간 state와 log likelihood score를 사용한다.

예측대상과 시점

  • 다음 일·주·월 집계 실현분산을 예측한다.
  • 긴 horizon에서 일부 모형은 recursion, 일부는 simulation 또는 direct forecast를 쓴다.

추정과 표본외 검증

  • 고정길이 rolling과 최초추정 뒤 static parameter를 비교한다.
  • Score state는 초기구간 뒤 매 관측에서 갱신하며 OOS를 regime별로 나눈다.

평가와 통과 기준

  • MSE·QLIKE·MCS와 component loss ratios를 본다.
  • 다중 horizon 공동검정과 관측오차 scaling robustness를 추가한다.

왜 작동하는가: 메커니즘과 반증 저자 제안 · 검토자 진단

저자가 제안한 작동 경로

  • HARK는 noisy RV를 덜 믿고 Score-HAR는 변하는 persistence를 따라가며 SHARK는 두 오차원이 서로를 잘못 흡수하는 것을 막는다.

그 경로를 지지하는 관찰

  • sampling frequency별 측정오차 gain, Score channel의 넓은 gain과 결합모형의 일·주·월 loss가 메커니즘에 부합한다.

경쟁 설명

  • 특정 liquid sample, crisis split, optimizer·simulation·fallback과 후보모형 선택이 결과를 만들었을 수 있다.

반증되려면 무엇이 보여야 하나

  • 한국 daily branch에서 Score-HAR가 constant log-HAR의 QLIKE와 비용 후 WML 효용을 못 이기면 time-varying 계수 채택을 기각한다.

강건성·한계·빈칸 검토자 종합

버틴 결과

  • simulation, 자산군, sampling frequency, static·rolling, crisis split, horizon과 observation-noise scaling을 교차한다.

약해지는 조건

  • 측정오차 gain은 촘촘한 sampling에서 줄고 결합모형이 모든 cell의 유일 최저는 아니다.

검증하지 않은 것

  • 한국 WML의 일중 RV·RQ와 동일 BS15 비용 후 경제성과는 직접 시험하지 않는다.

내부 긴장과 해석 주의

  • 강한 결합모형 결과에도 일부 표기 모호성, simulation·optimizer·bootstrap 재현세칙의 공백이 남는다.

실험 순서

  • 비중첩 단기·주간·월간 WML risk component를 검산한다.
  • constant log-HAR를 공통 outer origin에 복제한다.
  • diagonal Score-HAR를 finite-difference score test 뒤 추가한다.
  • origin별 optimizer·state·fallback·convergence를 저장한다.
  • MSE·QLIKE와 coefficient stability를 평가한다.
  • 같은 forecast를 BS15 mapping에 넣어 비용 후 성과를 계산한다.
  • RV·RQ가 없으면 HARK·SHARK run을 자동 차단한다.

채택 기준

  • analytic score와 수치 gradient가 허용오차 내 일치한다.
  • Score-HAR가 log-HAR의 공통 OOS loss를 안정적으로 개선한다.
  • 예측개선이 비용 후 Sharpe·CER에도 이어지고 convergence 실패에 의존하지 않는다.

실패 진단

  • state 폭주·미수렴은 수치안정성 실패로 분류한다.
  • loss만 좋으면 경제적 전이 실패로 분류한다.
  • quarticity 없는 HARK 요청은 데이터요건 실패로 즉시 중단한다.

남길 산출물

  • HAR lag·score·state 단위시험 보고서
  • constant 대 Score-HAR OOS loss·안정성표
  • data gate와 동일 BS15 비용 후 경제성과표

Q1. 왜 daily WML 제곱수익만으로 HARK를 부를 수 없는가?

정답: HARK의 날짜별 관측오차 분산은 동기화된 일중 RV와 realized quarticity에서 오기 때문이다.

Q2. Score-HAR가 signed-semivariance HAR와 다른 점은?

정답: 수익 부호를 나누는 모형이 아니라 likelihood score로 HAR 계수를 갱신하는 모형이다.

왜: 모형 정의가 time-varying coefficient update에 있다.

한국 WML 변환기

고정

  • PIT KOSPI·12–2·6개 WML·월말 형성·다음달 보유와 BS15 mapping을 고정한다.
  • constant log-HAR를 Score-HAR 앞의 필수 benchmark로 둔다.
  • 동일 OOS에서 loss와 경제성과를 별도 평가한다.

교체

  • 미국 intraday RV target을 6개 WML의 next-month daily-squares target으로 교체한다.
  • Score-HAR는 명칭을 SHAR-S로 써 signed-semivariance SHAR와 구분한다.
  • 2,000일 창을 기계적으로 복사하지 않고 expanding/rolling 후보를 inner validation에서 고정한다.

현재 입력

  • 6개 WML의 일별수익
  • 1·5·22일 log-risk components
  • RW126·HAR·LogHAR forecasts

부족한 입력

  • WML 포트폴리오의 동기화 intraday returns
  • realized quarticity와 microstructure/jump-robust measurement-error variance
  • predictive-simulation code와 seed 세칙

최소 구현 순서

  • 비중첩 1+4+17 components의 constant log-HAR를 복제한다.
  • diagonal Score-HAR를 같은 outer origins에 추가한다.
  • MSE·QLIKE와 coefficient stability를 본 뒤 동일 BS15 cap·cost로 경제성과를 계산한다.
  • intraday RV/RQ가 없으면 HARK·SHARK 실행을 차단한다.

실패의 의미

Score-HAR가 log-HAR의 common OOS QLIKE와 비용 후 BS15 utility를 모두 못 이기면 시간가변 계수의 추가복잡성을 채택하지 않는다.

구현 단위검사

  • HAR 1+4+17 비중첩 lag identity test
  • analytic score와 finite-difference gradient test
  • 미래수익 변형에 대한 state·forecast prefix test
  • optimizer convergence·fallback 기록 test
  • intraday RV/RQ 없는 HARK data gate test

주장 방화벽

허용 주장

  • accepted manuscript에서 measurement error와 time-varying dependence를 결합한 SHARK는 다수 일·주·월 OOS 비교에서 강했다.

    이유: Tables 4·5·10·12가 여러 빈도와 horizon의 강점을 보여 준다. · 교정: 모든 cell의 유일한 winner가 아니라 다수 비교에서 강했다고 표현한다. · 근거: p09_sp500 · p09_nyse · p09_long · p09_joint

  • 한국 일별 WML에는 constant log-HAR 대비 Score-HAR를 직접 challenger로 시험할 수 있다.

    이유: Score-HAR의 time-varying coefficient channel은 quarticity 없이 정의되지만 HARK channel은 그렇지 않다. · 교정: HARK·SHARK 원형과 분리한다. · 근거: p09_scorehar · p09_hark

금지 주장

  • quarticity 없는 daily squared returns 모형은 HARK 또는 SHARK 원형이다.

    이유: HARK observation variance는 intraday RV와 RQ의 asymptotic measurement error를 사용한다. · 교정: daily branch는 Score-HAR로 한정한다. · 근거: p09_hark · p09_shark

  • SHARK는 모든 빈도·loss·기간의 유일한 winner다.

    이유: S&P M=390 rolling MSE에서는 Score-HAR가 근소하게 낮은 반례가 있다. · 교정: sample·frequency·loss별 결과를 함께 쓴다. · 근거: p09_sp500

문헌에서 해결되지 않은 항목

  • static-window freeze date·optimizer tolerance·multi-step simulation draws와 MCS block 세칙은 accepted manuscript에서 완전히 닫히지 않는다.
  • Table 8의 M=78 MSE 두 행이 모두 RW로 인쇄돼 두 번째 SW 해석은 caption과 주변 패턴에 의존한다.
