Executive Summary

한 페이지로 읽는 보고서

이 페이지는 학부 시절 작성한 손흥민 경기 데이터 분석 프로젝트(v1 회고)에서 정리한 9가지 회고 수정과 5가지 의도된 사고 흐름이 ML 모델 성능에 어떻게 반영되는지를, 같은 데이터에 두 파이프라인을 동시에 적용해 정량적으로 측정한 결과입니다.

핵심 결론 1 (정량 비교). v1은 모든 테스트 경기를 "승리"로 예측하고 있었습니다. 정확도 51.6%는 손흥민의 실제 클럽 승률 52%를 그대로 모방한 결과였고, F1 macro는 0.227에 머물렀습니다. v2는 같은 데이터에서 정확도 48.3% / F1 macro 0.378 (+66.4%) 로, 단순 baseline 모방이 아닌 실제 분류기로 작동합니다.

핵심 결론 2 (사고 흐름 검증). v1의 4단 사고 흐름 — ① 결과 라벨링, ② OLS p-value 통계 검증, ③ 가중 인코딩, ④ R² 재검증 — 은 v2에서 모두 살아남았고, 6개 실험으로 사후 재검증되었습니다. 특히 venue가 result에 미치는 영향은 SHAP 1위 (0.362) + Ablation per-feature 최대 기여 (-0.053) + Bayesian 95% HDI [-1.05, -0.47] + opponent strength 통제 후에도 변화 없음 (-0.287 → -0.288) 의 4중 검증으로 인과적 효과임이 확인되었습니다.

핵심 결론 3 (예상치 못한 발견). v1의 collapse(모든 경기 W 예측)의 진짜 원인은 target encoding 누수가 아니라 RF top_k=6 feature selection이었습니다. 같은 v1을 11개 피처로 돌리면 W rate 100% → 62%로 떨어집니다. "누수 = 나쁘다"는 단순 도식보다 "feature selection + class imbalance + accuracy 기준 GridSearch"의 조합이 진짜 결함이었다는 발견.

핵심 결론 4 (한계의 발견). 적응 곡선 분석에서 보였던 "LAFC 8경기 회복" 같은 frequentist finding은 Bayesian 계층 모델로 보면 클럽별 적응 시간 상수(tau)의 95% HDI가 모두 [0.2, 33] 범위로 겹쳐 통계적으로 구분되지 않습니다. 30경기 표본의 노이즈 가능성이 큽니다.

핵심 결론 5 (모델의 진짜 능력). v2 피처는 W/D/L 결과 예측엔 의미 있는 신호를 잡지만, "손흥민이 이번 경기에 골을 넣을지" 같은 더 정교한 target에선 AUC 0.5 (random) 수준으로 무력합니다. 모델이 학습한 것은 손흥민의 영향력이 아니라 팀 결과 패턴입니다.

한 줄로: 학부 시절 통계학자의 사고 흐름은 전부 살아남았고, 단지 적용 위치(fold 안 vs 밖)가 한 단계 옮겨졌을 뿐입니다. 이 페이지는 그 이동의 매 한 단계를 측정으로 기록합니다.

Why this project
왜 회고가 측정 가능한 실험으로 이어졌는가

학부 시절 손흥민 경기 데이터 프로젝트(v1 회고 페이지)에서 5가지 의도된 디자인 결정과 9가지 회고 수정을 정리했습니다. 그 회고에는 한 가지 검증되지 않은 가설이 깔려 있었습니다.

v1 회고의 핵심 가설
"학부 시절의 통계학적 사고는 폐기 대상이 아니라 ML 검증 위생을 더해 살릴 자산이다. venue 가중 인코딩의 직관은 살리되, 적용 위치를 train fold 안으로 옮기면 의도가 살아남는다."

이 가설은 글로 적기 쉽지만 검증하지 않으면 단순 신앙 고백이 됩니다. 정직한 회고가 되려면 같은 데이터에 옛 파이프라인과 새 파이프라인을 동시에 돌려서, "v1의 51.6% 정확도가 정말 누수가 만든 환상이었는가" 그리고 "venue 직관이 ML 위생 위에서도 살아남는가"를 숫자로 보여야 합니다.

그래서 6단계 작업을 잡았습니다.

Phase 1 — 데이터 재수집
v1 crawler의 step=2 버그를 고치고, MLS URL 형식까지 지원하도록 재작성. Hamburg → LAFC 풀 스코프.
Phase 2-4 — v1 vs v2 비교
옛 파이프라인 그대로 재현 + Pipeline / TimeSeriesSplit / fold-aware target encoding / LightGBM + Optuna로 새로 작성. 같은 데이터에 동시 적용.
Phase 5 — 적응 곡선 + SHAP
풀 스코프 데이터로만 가능한 새 질문: 4번의 클럽 전환에서 폼이 어떻게 변하는가. 그리고 v2 모델이 무엇을 보고 있는가.
Phase 6 — 보고서
5가지 사고 흐름의 진화와 6개 실험 결과를 학술 보고서 형식으로 정리.

그 위에 6개 검증 실험(Ablation, v1 collapse 진단, Cross-league 전이, Counterfactual venue, Bayesian 계층 모델, 다른 prediction target)을 추가로 실행해, 각 사고 흐름이 어떻게 살아남는지를 다각도로 측정했습니다.

Data Re-collection
완전한 커리어 스코프 재수집

v1 회고에서 발견한 가장 큰 결함은 crawler가 range(2011, 2024, 2)로 시즌의 절반을 건너뛴 것이었습니다. 손흥민 토트넘 전성기의 절반 시즌이 통째로 빠진 데이터로 모든 후속 분석이 진행됐습니다. 이 문제부터 해결합니다.

데이터 재수집의 두 가지 변경
① step=1로 모든 시즌 빠짐없이 수집 (15개 EU 시즌 + 2개 MLS 시즌 = 17 시즌)
② MLS는 단일 연도 URL 형식(/2025/)을 지원하도록 크롤러 분기 추가

fbref 페이지가 cloudflare로 보호되어 있어 단순 requests는 403을 반환합니다. v1 코드처럼 Selenium을 쓰되 anti-detection 플래그를 추가해 "잠시만 기다리십시오" 챌린지를 통과합니다.

# v1 (학부 시절) — 시즌 절반 누락 for year in range(2011, 2024, 2): # step=2 BUG url = base + f"/{year}-{year+1}/" # v2 — 모든 시즌 + MLS 단일 연도 + Cloudflare 우회 EU_SEASONS = [f"{y}-{y+1}" for y in range(2010, 2025)] MLS_SEASONS = ["2025", "2026"] ALL_SEASONS = EU_SEASONS + MLS_SEASONS # 17 seasons opt.add_argument("--disable-blink-features=AutomationControlled") opt.add_experimental_option("excludeSwitches", ["enable-automation"]) driver.execute_script("Object.defineProperty(navigator, 'webdriver', {get: () => undefined})")

raw 수집 후 클럽 prefix 정규화(de Leverkusen → Leverkusen 등)와 국가대표 분리(kr Korea Republic 123경기 제외)를 거쳐 627 클럽 경기가 분석 대상이 됩니다.

03
Thought Lineage
사고의 계보 — 4단 사고 흐름이 v2로 이어진 길

v1 회고 페이지의 정체성은 "결과를 라벨링하고, 변수와의 관계를 통계로 검증한 뒤, 그 검증값을 가중치로 인코딩하고, 다시 검증한다"는 4단 사고 흐름이었습니다. 이 흐름은 통계 모델링의 정석이지만, ML 검증 관점에선 누수와 충돌하는 지점이 있었습니다.

v2의 출발점은 이 4단 사고 흐름을 폐기하지 않고 ML 위생 위에 다시 펼치는 것입니다. 각 단계가 어떻게 옮겨졌는지 정리합니다.

# 학부 시절 사고 (v1) v2 구현 이 페이지에서 어떻게 검증됐는가
1 결과를 1/0/-1로 라벨링
W/D/L의 부호를 살린 정수 라벨링. OLS에서 결과의 방향성이 자연스럽게 들어가게 함.		 동일 (변경 없음). 모든 v2 모델이 같은 라벨 사용. Part 4: v1이 모든 테스트를 W로 예측 → "라벨링은 옳고, 모델이 잘못"임을 노출.
2 OLS p-value로 venue 유의성 검정
venue를 인코딩하기 전에 result에 정말 통계적으로 유의한지 확인. p-value 기반 결정.		 fold-aware target encoder 안의 venue별 평균 계산이 OLS의 회귀 계수와 같은 정보. 매 fold의 train 부분만 사용. Part 9 (Counterfactual): opponent strength 통제 후에도 venue OLS 계수는 -0.287 → -0.288 (변화 없음, p<0.001 유지). v1 직관이 인과적 효과로 검증.
3 venue별 result 평균을 가중치로 매핑
전체 데이터의 venue별 result 평균(0.608/0.339/0.235)을 라벨값으로 치환. ML 관점에선 target encoding leakage.		 매 fold의 train만으로 venue별 평균 계산해 매핑(FoldAwareTargetEncoder). 의도(가중 인코딩) 보존 + 누수 제거. Part 5 (Ablation): venue 1개 제거 시 F1 -0.053 (rolling 33개 제거 시 -0.068과 거의 동일). per-feature 기여도 압도적 1위.
4 R² 비교로 인코딩 효과 재검증
정수 인코딩 vs 가중 인코딩의 R² 차이를 OLS로 측정해 가중 인코딩 채택.		 TimeSeriesSplit 5-fold CV의 macro F1으로 재검증. R² 한 숫자가 아니라 fold별 분산까지. Part 4 + Part 10 (Bayesian): F1 0.227 → 0.378 (+66.4%). 베이지안 b_venue 95% HDI [-1.05, -0.47]로 효과 크기 신뢰구간까지 추정.
사고 흐름의 4 / 4가 살아남았습니다

위 표의 각 행은 "v1의 사고가 v2 어디에 옮겨졌고, 그것이 이 페이지의 어떤 실험에서 검증됐는가"를 가리킵니다. 4단 모두 살아남은 채 ML 검증 위생을 통과했습니다. 통계학자의 옳음과 ML 모델러의 옳음은 충돌하는 게 아니라, 같은 사고를 다른 위치에서 펼치는 일이었습니다.

05
Experiment A · Feature Ablation
사고 흐름 검증 1 — 어떤 피처 그룹이 얼마나 기여하는가

SHAP는 모델 내부에서 각 피처가 출력에 얼마나 기여하는지를 알려줍니다. 하지만 SHAP는 "기여도"이지 "필요성"이 아닙니다. 어떤 피처가 진짜 모델 성능에 필요한지는 그 피처를 제거했을 때 F1이 얼마나 떨어지는지로 측정합니다.

실험 A의 질문
"v2의 41개 피처는 venue / rolling / adaptation index / form 4 그룹으로 나뉜다. 각 그룹을 통째로 제거했을 때 F1 macro가 얼마나 떨어지는가? 학부 시절 강조했던 venue가 실제 성능 기여도에서도 1위인가?"

막대 길이는 feature 1개당 F1 감소량. venue 단일 피처가 rolling 33개 평균보다 26배 강한 영향력. 학부 시절 venue를 가중 인코딩한 직관이 per-feature 기준으로도 정확.

표를 천천히 읽으면 venue 1개의 영향력이 압도적입니다.

  • venue 1개 제거 = F1 -0.053 → 단일 피처가 F1을 0.053 깎음
  • rolling 33개 제거 = F1 -0.068 → 33개를 통째로 빼도 venue 1개와 비슷
  • per-feature 기준으로 venue는 rolling보다 약 26배 더 강한 단일 영향력
  • adaptation 4개 / form 3개도 의미 있는 기여 (각각 -0.032, -0.023)
사고 흐름 ②③ 재검증 — venue 직관은 SHAP뿐만 아니라 Ablation으로도 1위

학부 시절 OLS p-value로 "venue가 중요하다"고 판단해 가중 인코딩까지 적용한 그 직관이, v2의 두 가지 측정(SHAP 0.362 = 1위 / Ablation -0.053 = per-feature 1위)으로 모두 1위로 재확인됩니다. 풀어 말하면: venue는 SHAP 내부 영향력으로도 1위, 모델 성능 기여도로도 압도적 1위. 그 위에 v2가 추가한 rolling / adaptation / form은 양적으론 많지만 redundancy가 있어 단일 영향력은 venue 미달.

이 발견은 두 가지 해석을 가능하게 합니다. 첫째, v1이 venue 한 변수를 가중 인코딩으로 부스트한 것은 가장 중요한 변수에 정확히 집중한 좋은 선택이었습니다. 둘째, v2가 추가한 33개의 rolling 피처는 양적 기여보다 "단일 venue로 못 잡는 잔차"를 잡는 보조 역할이라고 봐야 합니다.

Experiment B · v1 Collapse Diagnosis
v1이 모든 경기를 W로 예측한 진짜 원인은

v1 회고에서는 "데이터 누수가 v1의 결함"이라고 적었습니다. 하지만 "누수 = 모든 경기 W 예측"이 자동으로 성립하는가는 검증되지 않았습니다. v1의 collapse를 만든 진짜 원인이 누수 자체인지, 아니면 다른 디자인 결정인지를 분리합니다.

결과 해석 4가지:

1
scaler leakage 단독으로는 collapse에 영향 없음
v1 + scaler를 train fold에서만 fit해도 결과 동일 (acc 0.516, W 100%). scaler 누수는 v1 collapse의 원인이 아니다.
2
target encoding 제거도 부분 효과만
v1에서 venue 가중 인코딩만 빼고 raw venue_int를 쓰면 W rate 100% → 68%로 감소하지만, F1은 여전히 0.313 수준. target encoding은 영향이 있긴 하나 collapse의 주요 원인은 아니다.
3
RF top_k=6 selection을 빼는 것이 큰 효과
v1에서 RF로 상위 6개만 고르지 않고 11개 모두 사용하면 W rate 100% → 62%, F1 0.227 → 0.401. collapse의 가장 큰 원인 중 하나는 과소피처 + RF selection의 조합.
4
class_weight='balanced'가 단일 가장 강력한 fix
v1에 class_weight='balanced'만 추가하고 GridSearch scoring을 f1_macro로 바꾸면 W/D/L 모두 19~42% 비율로 예측. F1 0.227 → 0.338. collapse의 진짜 핵심은 클래스 불균형 + accuracy 기준 GridSearch의 조합이었음.
예상치 못한 발견 — 누수가 아니라 "feature selection + 불균형 + accuracy 기준"의 합주

v1 회고에서는 "누수가 v1의 핵심 결함"이라고 단순화했지만, 이 진단에 따르면 collapse를 만드는 진짜 chord는 RF top_k feature selection × 클래스 불균형 × accuracy 기준 GridSearch의 3중 조합입니다. target encoding leakage / scaler leakage 단독으로는 collapse가 일어나지 않습니다.

다시 말해 v2가 좋은 진짜 이유는 단순히 "누수를 제거해서"가 아니라 (a) 피처 다양성(41개) + (b) class_weight 또는 LightGBM의 balanced loss + (c) Pipeline + TimeSeriesSplit 위생의 종합입니다. v1 회고의 "누수 = 핵심"이라는 단순 도식은 한 단계 더 정교화되어야 합니다.

이 발견은 회고 페이지의 9가지 수정 항목 우선순위도 약간 바꿉니다. "scaler leakage 제거"는 이론적으로 옳지만 실제 성능 기여도는 v1 데이터 셋업에서는 0이었습니다. "RF top_k 대신 모든 피처 사용" 또는 "class_weight='balanced'"가 같은 노력으로 더 큰 효과를 가져옵니다.

Experiment E · Counterfactual Venue
사고 흐름 검증 3 — venue가 진짜 인과인가, confound인가

SHAP는 모델 내부 중요도, Ablation은 모델 성능 기여도. 하지만 두 측정 모두 "venue가 result에 인과적으로 영향을 주는가"는 답하지 못합니다. 가능성: (a) 진짜 home advantage, (b) home/away 일정이 opponent strength와 confound되어 venue 효과처럼 보임. 둘을 분리합니다.

실험 E의 질문
"opponent strength(상대팀의 historical 승률)을 통제하고 OLS를 다시 추정했을 때, venue 회귀 계수는 변하는가? 만약 거의 변하지 않으면 venue effect는 confound가 아닌 진짜 home advantage."

측정 — opponent strength 정의

각 opponent에 대해 손흥민의 누적 winrate를 그 시점까지의 만남 기록으로 계산합니다. 미래 정보가 들어가지 않도록 cumsum().shift(1) / cumcount() 패턴.

사고 흐름 ② 인과 추론으로 재검증

학부 시절 OLS p-value로 "venue가 통계적으로 유의하다"고 판단했던 그 발견이, opponent strength 통제 후의 OLS에서도 그대로 살아남았습니다. venue effect = home advantage는 confound가 아닌 진짜 인과 효과입니다. 손흥민이 홈에서 뛸 때 result가 평균적으로 0.288 높아지는 것은 누구와 만나는지(opponent strength)와 거의 독립적입니다.

이 발견의 의미: v1의 가중 인코딩이 venue에 0.608/0.339의 다른 값을 부여한 것은 단순 통계적 직관이 아니라 실제 인과적으로 다른 효과 크기를 반영한 정확한 변환이었습니다. 학부생 시절의 옳은 사고가, 인과 추론의 언어로도 검증된 셈.

Experiment D · Bayesian Hierarchical
사고 흐름 검증 4 — 적응 곡선의 95% HDI

Part 7의 frequentist 적응 곡선은 직관적이지만 통계적 유의성을 말하지 못합니다. 베이지안 계층 모델로 같은 데이터에 클럽별 random effect를 부여해, 각 클럽의 적응 시간 상수(tau) 95% HDI를 구합니다.

실험 D의 질문
"Part 7에서 본 'LAFC 8경기 vs 다른 클럽 1-3경기' 회복 시간 차이가 통계적으로 유의한가? 표본 크기 차이로 인한 단순 노이즈일 가능성은? 베이지안 95% HDI로 답한다."

모델 구조

# y_i = 1 if Win else 0 # logit(p_i) = a_club[c] + adapt_effect_c(match_in_club_i) + b_venue * venue_i # adapt_effect_c(m) = -b_adapt[c] * exp(-m / tau[c]) with pm.Model() as model: a_club = pm.Normal("a_club", mu=0, sigma=1, shape=n_clubs) b_adapt = pm.HalfNormal("b_adapt", sigma=1, shape=n_clubs) log_tau = pm.Normal("log_tau", mu=2, sigma=1, shape=n_clubs) tau = pm.math.exp(log_tau) b_venue = pm.Normal("b_venue", mu=0, sigma=1) logit = a_club[c] - b_adapt[c]*pm.math.exp(-m/tau[c]) + b_venue*v pm.Bernoulli("y", p=pm.math.sigmoid(logit), observed=is_win) idata = pm.sample(1000, tune=1000, chains=2)

Experiment F · Different Targets

예상치 못한 발견 — 모델은 손흥민의 영향력이 아니라 팀 결과 패턴을 본다

이건 단순한 한계가 아니라 모델이 학습한 것의 정체를 드러냅니다. v2가 잘 잡는 것은 "팀이 이길 것 같은 경기 / 질 것 같은 경기"의 macro 분포지, 손흥민 개인의 경기당 활약은 아닙니다. "손흥민 데이터로 손흥민의 영향력을 모델링한다"는 학부 시절의 framing은, 실제로는 "손흥민 경기의 결과를 모델링한다"였던 것으로 정정되어야 합니다.

이 보고서가 회고 페이지에 기여하는 정정 사항

정정 1 — 누수의 단순화
"누수가 v1의 결함"이라는 표현을 "RF top_k feature selection × 클래스 불균형 × accuracy 기준 GridSearch의 3중 조합"으로 정교화. scaler leakage 단독 영향은 0이었음.
정정 2 — 적응 곡선의 통계적 견고성
"LAFC 8경기 회복" 같은 frequentist finding은 베이지안 95% HDI로 보면 모든 클럽 tau가 통계적으로 구분 안 됨. 표본 크기 차이로 인한 노이즈 가능성 명시 필요.
발견 1 — venue 직관의 4중 검증
venue가 SHAP 1위 + Ablation per-feature 1위 + 베이지안 HDI 0 멀리 + opponent 통제 후에도 변화 없음. 학부 시절의 통계적 직관이 인과 추론까지 살아남음.
발견 2 — 모델이 본 것의 정체
v2는 손흥민의 영향력이 아니라 팀 결과 패턴을 학습. 골 여부 등 binary 정교 target에선 AUC 0.5 (random). framing 정정: "손흥민의 결과 데이터를 모델링한다".
3년의 거리 — 측정된 결론

v1 회고 페이지에서 "사고 흐름은 옳았으니 위치만 옮긴다"고 적었던 가설은, 같은 데이터에 두 파이프라인을 동시에 돌린 결과로 검증됐습니다. 4단 사고 흐름은 모두 살아남았고, 각 단계는 v2의 다른 측정 도구로 재검증됐습니다. 학부 시절의 통계학적 사고는 폐기 대상이 아니라 ML 위생을 더해 살릴 자산이었다는 것이 — 6개 실험의 숫자로 — 확인된 결론입니다.

한 단계 더: v1 회고 자체에도 한계가 있었습니다. "누수 = 결함"이라는 단순 도식, "적응 곡선 회복 시간"의 직관적 단정 — 이 두 가지는 v2의 진단 / 베이지안 모델로 정정되었습니다. 회고도 회고의 대상이 됩니다.
