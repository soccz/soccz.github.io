Overview

회고를 가설로, 가설을 실험으로

v1 회고 페이지에서 정리한 9가지 수정 사항이 실제로 모델 성능에 어떤 영향을 주는지 측정하기 위해, 같은 데이터에 v1과 v2 파이프라인을 동시에 적용했습니다. 결과는 예상보다 더 명확했습니다.

가설
"v1의 정확도(약 50%)는 데이터 누수가 만든 환상이며, 누수를 제거하면 정확도는 떨어지더라도 실제 분류 능력(macro F1)은 향상될 것이다."
측정 방법
v1 파이프라인(target encoding 누수, 무작위 split, scaler leakage 모두 그대로)과 v2 파이프라인(sklearn Pipeline, TimeSeriesSplit, fold-aware target encoding, LGBM + Optuna)을 동일한 627경기에 적용. 같은 metric(accuracy, macro F1)으로 비교.
발견
v1의 정확도 51.6%는 사실상 majority class baseline(승률 52%) 그대로였고, 모든 테스트 경기를 "승리"로 예측하고 있었습니다. v2는 정확도가 48%로 비슷하지만 macro F1이 0.227 → 0.378로 +66.4% 개선되며 진짜 분류기가 되었습니다.
한 줄 요약

v1이 보여준 "그럴듯한 정확도"는 손흥민의 승률 자체를 모방한 것이었고, 누수를 제거한 v2가 비로소 분류를 시작했습니다. 같은 데이터, 같은 metric으로 측정된 정직한 회고.

왜 정확도는 떨어지고 F1은 올라갔는가

v1의 정확도 0.5159는 손흥민 클럽 경기의 승률(326/627 = 0.5199)과 거의 동일합니다. 이게 "단순히 모든 경기를 승리로 예측"하는 자명한 baseline의 점수예요. v1은 사실상 분류를 하지 않고 있었습니다. v2는 진짜로 패배/무승부/승리를 구분하기 시작했고, 그 결과 정확도는 비슷하지만 macro F1이 0.227 → 0.378로 1.66배 좋아졌습니다.

The Big Finding

v1은 모든 경기를 "승리"로 예측하고 있었다

v1의 51.6% 정확도가 분류 능력이 아니라는 가설을 검증하기 위해, v1 모델의 테스트셋(126경기) 예측 분포를 확인했습니다.

왜 v1은 이렇게 됐는가

SVM(rbf)이 클래스 불균형 + target encoding 누수 + 무작위 split의 조합 안에서 "다 W로 예측"하는 게 손실 함수상 최적이었던 것으로 보입니다. class_weight='balanced'도 없었고, GridSearch도 accuracy 기준이라 majority class를 그대로 따라가는 모델이 best로 선정됨. v1의 장점이라고 믿었던 정확도 51.6%는, 사실 손흥민 본인의 승률을 그대로 출력한 것이었습니다.

New Question

리그 적응 곡선 — 4번의 전환

데이터를 풀 스코프로 다시 모은 정당화. 손흥민의 4번 클럽 전환(Hamburg → Leverkusen → Tottenham → LAFC)에서 폼이 어떻게 변했는지를 측정합니다. 같은 리그 내 이적과 다른 리그 이적의 차이가 보입니다.

Finding 01
LAFC 데뷔는 골 폭발
"첫 10경기 골/경기 0.90 — 다른 모든 클럽 데뷔 시기 압도. 그러나 그 후 baseline은 0.25로 빠르게 정상화."
+0.65 above baseline
Finding 02
Tottenham은 즉시 적응
"첫 10경기에 승률 70% + 골 0.30 동시 달성. Bundesliga → EPL 전환에도 폼 손실 거의 없음. 손흥민 전성기의 시작점."
3경기 회복
Finding 03
MLS 적응은 4-5배 더 걸림
"회복까지 8경기. EPL 데뷔(3경기), Leverkusen 이적(2경기), Hamburg 데뷔(1경기) 대비 명확히 더 오래. 골은 빠르지만 폼 안정화는 느림."
8경기 회복
왜 LAFC만 다른가 (가설)

표 자체로는 인과를 단정할 수 없지만, 가능한 설명: (1) MLS의 경기 강도 분포가 EPL과 매우 달라 폼 안정화 패턴이 다름, (2) LAFC가 손흥민에게 더 많은 공격 기회를 부여(Tottenham 시기 평균 0.10 골/경기 baseline과 LAFC 0.25 baseline 차이가 시사), (3) 적응 윈도우가 작아(30경기) 통계적 노이즈가 큼. 이 질문은 풀 스코프 데이터(2026까지)가 없었으면 답할 수 없었습니다.

SHAP 01
venue 1위 — v1 직관 검증됨
"옛 v1이 OLS p-value로 venue가 유의하다고 판단해 가중 인코딩까지 적용한 그 직관이, v2의 SHAP 분석으로도 가장 중요한 피처로 재확인됨. 통계학자의 옳음은 살아남았다."
SHAP 02
적응 인덱스 3, 4위
"league_match_idx, club_match_idx 두 피처는 v2에서 새로 만든 것. 모델이 '이 리그에서 몇 번째 경기인가'를 결과 예측의 핵심 정보로 사용한다는 발견. 적응 곡선 분석과 직접 연결됨."
SHAP 03
Rolling 폼 피처 강세
"roll3/5/10_minutes, roll5_shots, form5_meanres 등 모든 rolling 피처가 상위. v1의 'goal feature leakage' 대신 '직전 N경기 평균'으로 폼을 표현한 것이 모델에 의미 있는 신호로 작동."
Lessons

통계학자의 옳음은 살아남았다

v1의 5가지 의도된 결정 중 venue 가중 인코딩의 직관은 v2의 SHAP 분석으로 재검증됐고, 새로 추가된 적응 인덱스/rolling 폼 피처는 그 위에 ML 검증 위생을 더한 결과입니다.

살아남은 것
venue가 result에 강한 영향을 준다는 v1의 OLS 검증 결과는 v2의 SHAP에서 1위로 재확인. 통계학적 사고로 옳았던 부분.
바뀐 것
v1의 venue 가중 인코딩(target encoding)은 fold-aware 버전으로 옮겨졌습니다. 의도는 같지만 누수 없이. v1의 raw goal 피처는 rolling 평균으로 대체되어 leakage 제거.
새로 추가된 것
league_match_idx, club_match_idx 같은 적응 인덱스 피처. 풀 스코프 데이터(4 클럽 14.7년)가 있어야만 의미 있는 새 피처. 학부 시절 데이터로는 만들 수 없었던 분석.
3년의 거리 — 측정된 결론

v1 회고 페이지에서 "사고 흐름은 옳았으니 위치만 옮긴다"고 적었던 가설은, 같은 데이터에 두 파이프라인을 동시에 돌린 결과로 검증됐습니다. venue 직관은 SHAP 1위로 살아남았고, 누수 제거는 macro F1을 +66.4% 끌어올렸습니다. 학부 시절의 통계학적 사고는 폐기 대상이 아니라 ML 위생을 더해 살릴 자산이었다는 것이, 숫자로 확인된 결론입니다.

남은 작업

v2는 회고를 측정으로 만든 1차 결과입니다. 그 위에 다음이 가능합니다.

Causal Inference
SHAP는 모델 내부 중요도일 뿐. "venue가 정말 result를 인과적으로 얼마나 끌어올리는가"는 이중 차분 / propensity score matching으로 측정 가능.
베이지안 계층 모델
손흥민의 "참 능력치 + 경기별 변동성"을 PyMC 계층 모델로 분리. 클럽/리그별 random effect를 통해 적응 곡선의 통계적 유의성 검정.
Match-level Event 통합
v1 시절에 만들었던 매치별 이벤트(분 단위 골/어시) 크롤링을 v2 폼 피처에 통합. 시간대별 영향력까지 분석 가능해짐.
