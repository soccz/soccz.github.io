Executive Summary

한 페이지로 읽는 v3

v2 보고서 검토에서 한 가지 정직한 지적이 나왔습니다: "v2는 통계 분석보다는 그냥 ML 아닌가?" 맞는 말이었습니다. v2의 본체는 ML 파이프라인이고, 통계 추론은 venue effect 한 가지를 4중 검증하는 데만 쓰였습니다. v3는 그 비중을 뒤집습니다 — 모델링 자체가 통계 추론입니다.

핵심 결정. v1 시절 직접 구축한 분 단위 이벤트 크롤러를 v2 인프라(step=1, Cloudflare 우회, retry)로 재작성해 17 시즌 626 클럽 경기의 Son 이벤트 661개를 모았습니다. 이를 (경기 × 6 시간대) = 3780 셀로 펼쳐 PyMC 계층 Poisson에 넣었습니다.

v3가 답하는 5가지 질문
① 시간대별 hazard ratio는?
② 클럽별 baseline 골 빈도는 통계적으로 다른가?
③ Home advantage가 골 hazard에도 영향을 주는가?
④ 좋은 폼이 골 hazard를 올리는가?
⑤ 약한 상대일수록 골이 늘어나는가?

핵심 결과. 시간대별 hazard ratio가 후반으로 갈수록 단조 증가합니다 — 76+분에서 1.78x로 1차 시간대(0-15분) 대비 거의 두 배. 그러나 venue, form, opponent strength 모든 fixed effect의 95% HDI가 0을 포함합니다. 클럽별 baseline도 4 클럽 모두 [-3.4, -2.3] 영역에서 겹쳐 통계적으로 구분되지 않습니다.

v2와의 결정적 차이. v2에서 venue는 result에 강한 인과 효과 (HDI [-1.05, -0.47], 0에서 멀리)였습니다. v3에서 venue는 goal hazard에 약한 효과 (HDI [-0.36, +0.13], 0 포함). 같은 변수가 W/D/L 결과는 좌우하지만 손흥민 본인의 골 시점에는 영향이 적다는 발견.

한 줄로: 손흥민의 골은 경기 후반에 몰린다는 사실 외에는 통계적으로 견고한 클럽/venue/form/opponent 효과가 없습니다. 시간 자체가 가장 강한 신호.

01
Why v3
통계 분석으로 격상하는 이유

v2 보고서를 다시 읽어보면 명백합니다. 본체는 LightGBM + Optuna + TimeSeriesSplit + SHAP — 모두 ML 도구. 통계 추론은 Part 9 (OLS counterfactual venue) + Part 10 (Bayesian tau) 두 곳에만 등장하고, 그것도 venue effect 한 변수를 검증하는 데만 쓰였습니다.

v2의 정직한 정체
"학부 시절 통계학적 사고로 만든 모델(v1)을, ML 검증 위생으로 다시 만들어(v2) 두 결과를 비교하고, 그 비교의 핵심 finding(venue effect)을 OLS / Bayesian으로 사후 검증한 보고서." → ML이 본체, 통계는 검증 도구.

v3는 비중을 뒤집습니다. 모델링 자체가 베이지안 계층 추론이고, ML은 데이터 정제에만 쓰입니다. ML 모델의 결과를 "사후 검증"하는 게 아니라, 처음부터 통계 모델을 세워 posterior를 추출합니다.

03
Bayesian Model
PyMC 계층 Poisson — non-centered

3,780 셀에 대한 Son 골 카운트를 Poisson 회귀로 모델링. log-rate에 클럽별 random intercept + 시간대 fixed effect + 3 covariates 추가:

y_i ~ Poisson(λ_i) log(λ_i) = α_club[c]club_idx + β_bin[t]bin_idx + β_venue · venue_i + β_form · form5_i + β_opp · opp_strength_i # Priors μ_α ~ Normal(-3, 1) # 전체 평균 log-rate (사전: 매우 낮은 빈도) σ_α ~ HalfNormal(1) # 클럽 간 분산 α_club_offset ~ Normal(0, 1) # non-centered for hierarchy α_club = μ_α + σ_α · α_club_offset β_bin ~ Normal(0, 0.5) # 시간대 효과 (6 빈) β_venue, β_form, β_opp ~ Normal(0, 0.5)

Non-centered parameterization (수렴 트릭)

처음 fit한 centered 모델에서 153 divergences가 발생했습니다. 계층 모델의 funnel geometry — sigma가 작을 때 alpha가 좁은 영역에 집중되며 sampler가 빠져나오기 어려운 현상 — 이 원인. 표준 fix는 non-centered:

# Centered (불안정) α_club ~ Normal(μ, σ) # Non-centered (안정) α_offset ~ Normal(0, 1) α_club = μ + σ · α_offset

동일한 수학적 모델이지만 sampler가 보는 geometry가 달라져 divergence가 153 → 4로 줄어듭니다.

개별 빈 HDI는 0 포함이지만, *상대 ratio*는 강함

각 β_bin의 절대 HDI가 0을 포함하는 것은 mu_alpha와의 trade-off 때문입니다. 중요한 건 빈 *간* 차이: 76+ 평균(+0.358) - 0-15 평균(-0.221) = +0.579 log scale 차이 = 1.78x hazard ratio. 이게 단조 증가 패턴이며 골 분포의 주요 신호.

시각화 1 — 시간대별 HR + 95% HDI

posterior에서 직접 추출한 contrast (β_bin[i] - β_bin[0])의 HR. 점=평균, 가로선=95% HDI. 76+의 HDI [1.16, 2.76]가 1을 포함하지 않아 통계적으로 유의.

시각화 2 — β_bin posterior density

6 시간대의 posterior 분포 overlap. 각 곡선은 KDE. 76+(빨강) 분포가 오른쪽에 가장 많이 위치.

시각화 3 — Headline contrast (76+ vs 0-15)

두 시간대 차이의 직접 posterior 추출. HR mean = 1.78x, 95% HDI [1.16, 2.76]로 1보다 크게 떨어져 — p_positive = 99.7%로 매우 강한 통계적 증거.

핵심 contrast — 첫 통계적으로 유의한 효과

이전 분석에서 개별 β_bin HDI는 0을 포함했지만 contrast posterior를 직접 뽑으면 76+ vs 0-15가 0(즉 HR=1)을 95% HDI 안에 포함하지 않습니다. p(HR > 1) = 99.7%. v3에서 처음으로 통계적으로 유의한 효과입니다.

왜 후반에 더 많을까 — 가능한 가설들

상대 체력 저하
상대팀 수비수가 후반에 지치며 손흥민의 cutting in 기회 증가. 일반 축구 통설.
교체 시점 timing
손흥민이 76+분에 교체되거나 들어오는 경기가 많음. 들어온 직후엔 fresh.
경기 상황 변화
후반 진영이 열림(승부 결정 시점) → carry 기회 증가 → 골 hazard 상승.

v3 모델은 *어느* 가설이 맞는지는 답하지 못합니다 — minute-level fitness, possession context 같은 추가 covariate 없이는. 하지만 *후반 hazard 증가가 통계적으로 견고한 패턴이라는 사실 자체는* 이 모델로 확인됩니다.

막대 = 95% HDI, 점 = posterior mean. 4 클럽 HDI가 거의 완전히 겹침 → 통계적으로 baseline 골 hazard가 같다고 봐야.

해석

  • 모든 클럽 mean: -2.78 ~ -2.93 (log-rate 단위, 약 5-6% 시간대당 골 확률)
  • HDI 폭: 0.85 ~ 1.07 — 표본 적은 LAFC가 가장 넓음
  • 4 클럽 모두 [-3.4, -2.3] 영역 안에서 거의 평행 → "손흥민의 클럽 별 base 골 빈도는 같다"가 통계적 결론
  • Tottenham이 약간 높지만 (mean -2.78), Hamburg 95% HDI 안에 들어감
v2의 a_club 발견과 일관

v2 Bayesian (Part 10)에서도 클럽별 a_club는 mean이 다르지만 HDI가 겹쳤습니다. v3에서는 더 많은 sample(3000 draws)로 동일한 결론 — "클럽이 손흥민의 base 골 hazard에 통계적으로 의미 있는 차이를 만들지 못한다." Hamburg 약체 시기와 Tottenham 전성기를 baseline에서 구분 못 함은 직관과 다르지만 데이터가 그렇게 말함.

개별 해석

A
β_venue: home advantage가 골에는 영향 없음
venue_int이 0(Home) → 1(Away) → 2(Neutral)로 갈수록 β_venue가 음수면 home에서 골 hazard 더 높음을 의미. mean -0.113은 home 편중 약한 경향이지만 HDI [-0.360, +0.127]가 0 포함이라 통계적으로 무의미. P(β < 0) = 0.82로 방향성은 home 쪽이지만 견고하지 않음.
B
β_form: 좋은 폼이 골 hazard에 영향 거의 없음
form5_meanres = +1이면 직전 5경기 모두 승리. mean +0.032는 거의 0. HDI도 [-0.297, +0.342]로 0 중심에 대칭. "폼 좋다고 골 더 들어가는 게 아니다"가 통계적 결론. 직관과 다른 흥미로운 결과 — 폼이 좋아도 *팀이 이길 가능성*은 올라가지만 *손흥민이 직접 골 넣을 가능성*은 그대로.
C
β_opp: 약한 상대일수록 약간의 양수 경향
opponent_relative_strength가 양수면 상대가 평균보다 강함. mean +0.067은 약간의 양수 — 하지만 P(β > 0) = 0.849로 방향성은 좀 강하지만 HDI가 0 포함. 강팀 상대로 더 골이 들어간다는 약한 경향이지만 통계적으로 견고하지 않음. (이건 좀 의외 — 보통 약팀 상대로 골 더 많을 거라고 직관하지만 데이터는 그 반대 방향)

v2 vs v3
venue가 result는 좌우하지만 goal hazard는 그렇지 않다

v2와 v3는 동일한 venue 변수를 다른 target에 대해 추정했습니다. 결과의 차이가 흥미로운 finding을 만듭니다.

유의성 강한 인과 효과 통계적 유의성 약함
결정적 finding — 같은 변수, 다른 target, 다른 결론

venue는 경기 결과(W/D/L)를 좌우하지만 (v2 finding) 손흥민 본인의 골 시점에는 영향이 약합니다 (v3 finding). 이건 단순한 차이가 아니라 의미 있는 분해입니다.

해석: home advantage는 팀 차원의 변수 — 홈 관중, 익숙한 그라운드, 심판 편향 등 — 가 result에 누적 효과를 주지만, 손흥민 본인의 분당 골 가능성은 그것에 좀 덜 의존. 그의 골 hazard는 경기 시간대(76+ → 1.78x)에 더 강하게 결정됨.

v3가 v1/v2와 다른 점

v1 — 통계 직관, ML 위생 부족
OLS p-value, t-test, 가중 인코딩 — 통계 사고는 강했으나 누수 + 불균형 + 과소피처로 모델이 collapse.
v2 — ML audit, 통계는 검증 도구
LightGBM + Optuna가 본체. OLS counterfactual + Bayesian tau는 venue effect 한 변수 검증용 부속.
v3 — 베이지안 추론이 본체
PyMC 계층 Poisson이 메인 모델. ML은 데이터 정제만. 모든 효과가 posterior + HDI로 정량화.
08
Caveats
v3가 답하지 못하는 것들

v3는 통계 추론으로 격상했지만 여전히 한계가 있습니다.

단일 선수
손흥민 한 명의 데이터만. "1.78x 후반 ratio"가 손흥민 특이인지 elite winger의 일반 패턴인지 모름. v4에서 다른 선수 추가 비교가 답할 질문.
시간대 6 빈은 거친 분해
15분 단위 빈으로 묶었기 때문에 60-75와 75-90 사이의 미세 패턴은 묻혔습니다. 분 단위 hazard regression(spline)이 더 정밀.
교체 시간 미보정
손흥민이 65분에 교체되면 65-75 빈에서 hazard가 0이어야 하지만 현재 모델은 모든 빈을 동등하게 봄. exposure(분 단위 출전 시간) offset 추가가 필요.
매치 컨텍스트 부족
현재 score, 카드, 점유율 같은 match-state covariate 없음. "팀이 지고 있을 때 더 많이 시도"와 "그래서 후반 hazard 높음"을 구분 못 함.
개별 빈 HDI 0 포함
β_bin 절대 HDI는 0 포함. 빈 *간* 차이만 강함. 더 엄밀한 통계는 contrasts (예: β_bin[5] - β_bin[0])의 posterior를 직접 추출.
2 chains, ESS 일부 낮음
권장은 4 chains. 일부 파라미터 ESS가 100 이하인 경우 있음. r-hat은 1.01 수준이라 OK지만 개선 가능.

v4가 답할 수 있는 질문

  • 다중 선수 비교: Salah, Mbappé 등 추가 → "76+ 후반 ratio가 손흥민 특이인가, elite winger 일반인가?"
  • 분 단위 hazard regression: 6 빈 대신 spline (B-spline 또는 GP). 미세 패턴 검출.
  • Survival analysis: time-to-first-goal (Cox PH). 교체/카드를 censoring으로.
  • Match-state DAG: 점수 차이, 시간 남은 정도, 점유율 같은 dynamic covariate.
  • Causal mediation analysis: venue → match-state → goal hazard로 분해.
09
Closing
한 문단으로 닫기

v3는 v2 보고서에 대한 사용자의 정직한 지적 — "v2는 통계 분석보다 그냥 ML 아닌가" — 에 대한 응답입니다. 같은 데이터에 처음부터 베이지안 계층 모델을 세워 626 클럽 경기 × 6 시간대 = 3,780 셀에 대한 손흥민의 골 hazard를 추정했습니다. 가장 견고한 패턴은 시간대별 단조 증가 — 76+분에서 0-15분 대비 1.78x. venue, form, opponent strength는 모두 95% HDI가 0을 포함하며, 4 클럽 baseline도 통계적으로 동등합니다. 같은 venue 변수가 v2의 result에는 강한 인과 효과(HDI 0 멀리)였지만 v3의 goal hazard에는 약한 효과(HDI 0 포함)였다는 사실이, "venue는 팀 차원에서 result를 좌우하지만 손흥민 본인의 골 시점에는 영향 약하다"는 분해를 만듭니다. 회고가 회고를 회고하고, audit이 통계 추론으로 격상되었습니다. v4는 다른 선수와의 비교 + 분 단위 hazard regression으로 갑니다.
