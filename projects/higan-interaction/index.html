01 / METHOD

개별 효과의 합이 설명하지 못하는 변화

한 방향만 바꾼 반응을 A, 다른 방향만 바꾼 반응을 B라고 하면, 가장 단순한 설명은 A + B입니다. 함께 바꾼 실제 반응에서 이 합을 빼면 비선형 상호작용 C가 남습니다. 개별 반응의 중첩이나 상쇄와는 구분해서 측정했습니다.

혼합 반응 C = 공동 출력 − 단독 출력 A − 단독 출력 B + 기준 출력

이 분해 자체는 알려진 항등식입니다. 이번 질문은 목표 크기의 공동 출력을 아직 보지 않고도, 이 가산 설명이 허용 오차 안에 있는지 판단할 수 있는가였습니다. 목표 크기의 두 단독 반응은 알고 있는 조건입니다.

  1. 가까운 개입 관측

    작은 크기 0.03에서 두 방향을 함께 바꾸고 혼합 반응을 측정합니다.

  2. 위험 크기 예측

    작은 혼합 반응과 목표 단독 반응의 크기·중첩으로 위험을 회귀 예측합니다.

  3. 설명 채택 또는 보류

    별도 자료에서 고정한 임계값 0.094 이하이면 채택하고, 초과하면 보류합니다.

위험의 정의와 평가 자료 분리

위험은 RMS(C) / (RMS(A) + RMS(B))입니다. 실제 허용 기준은 RMS(C) ≤ 10⁻⁶ + 0.1 × (RMS(A) + RMS(B))로 고정했습니다. 예측 임계값과 실제 허용 기준은 구분합니다.

학습 24개, 임계값 보정 16개, 새 평가 64개 기준점을 사용했습니다. 8방향의 28개 쌍 × 4개 부호 × 3개 목표 크기를 평가했습니다. 각 기준점의 예측을 저장한 뒤 정답인 목표 공동 출력을 생성했습니다. 출력은 clamp 전 fp32, 측정 연산은 fp64입니다.

계산 비용과 비교 범위

기본 방법은 177회 호출로 336개 판단을 만듭니다. 목표 공동 출력은 조회하지 않습니다. 모든 목표를 직접 측정하는 385회 대비 호출 54.03% 절감이며, 공유 단독 출력을 포함한 전체 격자 기준입니다. 학습·보정 비용은 별도이고 전체 실행 시간 절감률을 뜻하지 않습니다.

표의 고정 임계값 판단과 각 기준점·목표 크기에서 절반을 뽑는 순위 비교는 서로 다른 과제입니다. 후자는 어려운 집단에서도 절반을 반드시 채택하므로 오판율을 직접 섞어 비교하지 않습니다.

03 / RESEARCH PATH

벡터 예측의 한계에서 설명의 적용 범위로

  1. 상호작용을 먼저 구별했습니다. 중첩·상쇄와 비선형 혼합 반응을 분리하고, 해석해와 반례로 구현을 검사했습니다.
  2. 가산 설명이 성립하는 크기를 찾았습니다. 첫 파일럿의 큰 개입에서는 8,064건 중 9건만 허용 기준을 통과했습니다. 개발 자료에서 더 작은 개입 범위를 조사했습니다.
  3. 보정한 벡터 외삽의 추가 이득은 작았습니다. 단순 선형 외삽 대비 오차 감소는 0.39%였고 신뢰구간이 0을 포함했습니다. 개입이 커질 때 반응 방향도 달라졌습니다.
  4. 설명을 채택할지 판단하는 문제로 좁혔습니다. 학습·보정·새 평가를 분리해 위험 크기를 예측했습니다. 가까운 관측 한 번과 보류가 검증 범위에서 기본 방법으로 남았습니다.

04 / CONCLUSION

검증한 결과와 재현 기록으로 마무리

이번 연구는 한 모델에서 설명의 적용 범위를 판단하는 경험적 방법을 확보했습니다. 복잡한 곡률·방향 정보의 보편적 우위는 확인하지 못했고, 다른 모델로의 일반화나 새로운 학술 기여도 입증하지 못했습니다.

같은 조건의 실험을 반복하기보다 결과와 한계를 공개하는 것으로 이번 연구를 종료했습니다. 추가 관측의 사전 실용 효과 경계가 구분되어, 예약한 추가 평가 기준점 64개는 사용하지 않았습니다.

  • 확인한 것: 고정한 모델·8방향·세 목표 크기에서 위험 예측과 설명 보류가 작동했다는 결과.
  • 남은 것: 다른 모델·개입으로의 일반화, 의미 정확도, 개별 사례의 무오판 보장, 기존 문헌과 구별되는 학술 기여.
  • 재개 기준: 기존 연구가 답하지 못한 질문과 그 주장을 기각할 수 있는 평가 기준을 먼저 정하고, 별도 프로토콜로 검증할 것.

상호작용 해석에는 Integrated Hessians, 설명 평가에는 충실도 연구, 보류에는 선택적 예측 연구가 있습니다. 관련 선행연구이며, 이번 실험의 같은 조건에서 직접 비교한 기준선은 아닙니다.
