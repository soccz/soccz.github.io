# 9. 사고 확장 (a) — 자문 질문 5개

각 질문 뒤에 "왜 이 질문이 중요한가"를 2~3줄로 붙인다.

## Q1. SAE 특징은 **재학습마다 같은 특징**을 되찾는가? (특징 동일성/seed 안정성)

본 논문은 특징을 되찾았다고 주장하지만, ground-truth 가 없어 "같은 사전을 다시 학습하면 같은 특징이 나오는지"를 직접 보이지 않는다. 만약 seed 마다 특징이 크게 달라진다면, "우리가 발견한 특징 = 모델의 진짜 특징"이라는 해석이 흔들린다. → 이건 내 Grokking-in-TS 회로 분석에서 **"grokking 전이에서 창발한 특징이 실재인가 우연인가"** 를 판정하는 것과 같은 문제다.

## Q2. **위치 기반 특징**은 SAE 로 안 보이는가? (§3.2 사각지대의 경계)

저자는 채점관(LLM)이 next/previous-token 패턴을 잘 설명 못 한다고 했다. 그런데 이게 **채점의 한계**인지 **SAE 가 위치 특징을 애초에 방향으로 못 담는 것**인지 구분되지 않았다. 전자면 채점만 고치면 되고, 후자면 attention 기하(APF 의 영역)는 SAE 좌표계 밖이다. → APF 의 존재 이유를 가르는 질문.

## Q3. 재구성 목적 대신 **예측-KL 목적**으로 학습하면 특징이 달라지는가?

저자 스스로 §6.2 에서 던진 질문. "재구성 잘 되는 특징"과 "출력을 바꾸는 특징"이 다르다면, 해석의 목표에 따라 특징 집합 자체가 바뀐다. → 예측이 본질인 TS 모델에서 이 차이는 더 커질 수 있어(8.4 반면교사), 내 연구의 핵심 설계 결정.

## Q4. MLP 에서 SAE 가 실패하는 이유는 **정보 구조** 때문인가 **최적화** 때문인가?

MLP 중간층에서 dead feature 가 많고 과완비 학습이 안 된다(§6.2). 이게 (a) MLP 활성이 애초에 희소-선형 구조가 아니라서인지, (b) 단지 학습 트릭(resampling·초기화)이 부족해서인지 모른다. → TS 트랜스포머의 어느 지점(잔차 vs FFN vs patch-embedding)에 SAE 를 붙일지 결정하는 데 직결.

## Q5. 특징의 **인과 우위(Fig.3)가 IOI 특수성**인가, 일반 성질인가?

IOI 는 회로가 잘 알려진 "깨끗한" 과제다. 더 분산된 능력(산술·계절성 예측 등)에서도 SAE 특징이 PCA 보다 적은 개입으로 인과를 재현하는지는 미검증. → 시계열의 "계절성·regime 전환" 같은 분산된 능력에 SAE 인과 국소화가 통할지가 내 적용 가능성의 전제.
