# 4. 방법론 해부 (b) — 희소 오토인코더의 수식 (§2)

> **배경 사다리** — ① 벡터의 "내적/행렬곱"은 "여러 방향에 얼마씩 걸쳐 있나"를 재는 연산이다. ② `ReLU(z)=max(0,z)` 는 음수를 0으로 자르는 함수. ③ "L1 노름 $\lVert c\rVert_1=\sum_i|c_i|$"은 성분 절댓값의 합으로, 이걸 줄이면 성분들이 **0으로 몰린다**(희소해진다). 이 셋을 쓰면 아래 세 수식이 열린다.

## 4.0 데이터 모델 (가정하는 세계관)

저자들은 활성 벡터가 다음처럼 생성된다고 가정한다:

$$x_i = \sum_j a_{i,j}\, g_j$$

**① 기호 뜻**: $x_i$ = $i$번째 토큰의 잔차 활성 벡터(관측되는 것). $g_j$ = 알 수 없는 **ground-truth 특징 방향**(모델이 실제 쓰는 것). $a_{i,j}$ = 그 특징이 이 토큰에서 켜진 정도(대부분 0, **희소**). 
**② 일상 비유**: 완성된 요리($x_i$)는 소수의 재료($g_j$)를 정해진 양($a_{i,j}$)만큼 섞은 것이다. 우리는 요리만 보고 재료 목록과 양을 역추정하려 한다. 
**③ 왜 이 형태**: "특징들의 **희소 선형결합**"이라는 가정이 있어야 사전 학습이 정당화된다. 비선형 결합이면 선형 사전으로 못 되찾는다. 
**④ 조심할 점**: 이건 **가정**이지 증명된 사실이 아니다. 실제 모델이 이 형태를 따르지 않으면(비선형·문맥의존 특징) 되찾은 방향은 근사에 불과하다. Ground-truth $g_j$ 는 관측 불가 → 검증의 근본 한계(07_limits).

## 4.1 인코더 — Equation 1

$$c = \mathrm{ReLU}(Mx + b)$$

**① 기호 뜻**: $x\in\mathbb{R}^{d_\text{in}}$ = 입력 활성(예: 512차원). $M\in\mathbb{R}^{d_\text{hid}\times d_\text{in}}$ = 사전 행렬(특징 검출기, 행이 특징 방향). $b$ = 편향. $c\in\mathbb{R}^{d_\text{hid}}$ = **특징 활성 계수**(예: 1024차원, 대부분 0). 
**② 일상 비유**: $Mx$ 는 "이 활성이 각 특징 방향과 얼마나 정렬됐나"를 재는 1024개의 점수판이고, `ReLU` 로 음수 점수를 버려 "켜졌다/안 켜졌다"만 남긴다. 
**③ 왜 이 형태**: `ReLU` 가 음수를 자르므로 특징 활성은 **비음(0 이상)** — "특징이 있으면 양수 강도, 없으면 0"이라는 자연스러운 의미를 준다. 선형(ReLU 없이)이면 음의 활성이 생겨 "특징의 부재"를 표현할 수 없다. 
**④ 조심할 점**: `ReLU` 문턱 때문에 약하게 켜지는 특징이 0으로 죽을 수 있다(dead feature 문제, 특히 MLP). 편향 $b$ 가 이 문턱을 좌우한다.

## 4.2 디코더 — Equation 2 (tied weights)

$$\hat{x} = M^\top c = \sum_{i=0}^{d_\text{hid}-1} c_i\, f_i$$

**① 기호 뜻**: $\hat{x}$ = 복원된 활성. $M^\top$ = 인코더 행렬의 전치(디코더로 재사용 = **tied weights**). $f_i$ = $M$ 의 $i$번째 행(특징 방향), $c_i$ = 그 특징의 활성 강도. 즉 복원값은 "켜진 특징 방향들을 강도만큼 더한 것". 
**② 일상 비유**: 켜진 색연필들을 각자의 강도만큼 칠해 원본 그림을 재현한다. 
**③ 왜 tied weights(인코더=디코더 전치)인가**: 원문 §2 는 세 근거를 든다 — (a) "특징을 **검출하는 방향**과 **정의하는 방향**은 같거나 매우 비슷해야 한다"는 기대를 부호화, (b) 메모리 절반, (c) 인코더/디코더 방향 모호성 제거. 
**④ 조심할 점**: tied weights 는 표현력을 제약한다(검출≠재구성 방향인 특징을 못 담음). 후속 연구(예: Gao et al. 2024)는 오히려 tie 를 풀거나 다른 제약을 쓰기도 한다 — 즉 이건 설계 선택이지 필연이 아니다. 또 $M$ 의 **행은 정규화(row-normalized)** 되는데, 이는 모델이 "특징 방향을 키워서 손쉽게 $\lVert c\rVert_1$ 을 줄이는" 꼼수를 막기 위함이다.

## 4.3 손실 — Equation 4 (재구성 + 희소)

$$\mathcal{L}(x) = \lVert x - \hat{x}\rVert_2^2 + \alpha\lVert c\rVert_1$$

**① 기호 뜻**: 첫 항 $\lVert x-\hat{x}\rVert_2^2$ = 재구성 오차(원본과 복원의 제곱거리). 둘째 항 $\alpha\lVert c\rVert_1$ = 희소 벌점($\lVert c\rVert_1=\sum_i|c_i|$, $\alpha$ = 그 세기). 
**② 일상 비유**: "원본과 똑같이(첫 항) + 색연필은 조금만 써서(둘째 항)". $\alpha$ 는 이 둘 사이 **환율**이다. 
**③ 왜 L1 인가**: L1 벌점은 계수를 정확히 0으로 몰아 **진짜 희소**(대부분 성분이 0)를 만든다. L2($\sum c_i^2$)를 쓰면 계수가 작아지긴 해도 0이 되진 않아 "소수만 켜짐"이 안 된다. Wright & Ma 2022 는 적절한 조건에서 L1 이 ground-truth 특징을 **복원**함을 이론적으로 뒷받침. 
**④ 조심할 점**: $\alpha$ 를 키우면 더 희소(해석 쉬움)하지만 재구성이 나빠지고, 줄이면 반대다. 원문 §6.2 는 이 tradeoff 곡선에 **뚜렷한 knee 가 없다** — 즉 "정답 $\alpha$"가 유일하지 않고 여러 유효 분해가 공존함을 인정한다. (이 knee 부재를 우회하려고 후속 TopK-SAE 는 L1 대신 "정확히 $k$개만 켜라"로 희소를 **직접 강제**한다.)

## 4.4 이 부분의 핵심 한 문장

> **세 수식은 "관측 활성 = 소수 특징의 선형합"이라는 가정(§4.0) 위에, ReLU 인코더(§4.1)로 켜짐을 읽고, tied 디코더(§4.2)로 되살리며, L1 손실(§4.3)로 '적게 켜라'를 강제하는** — 딱 그만큼의 최소 장치다. 복잡한 트릭이 없다는 점이 이 논문의 재현성과 확장성의 근거다.
