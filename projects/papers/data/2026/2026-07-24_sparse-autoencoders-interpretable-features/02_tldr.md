# 1. 3층 TL;DR

## 🧒 초등학생 수준

머릿속에 색연필이 512자루 들어 있는 로봇이 있다고 하자. 그림을 그릴 때 로봇은 색연필 몇 개를 동시에 쥔다. 그런데 이상하다. 어떤 색연필 하나가 "강아지"도 칠하고 "축구공"도 칠하고 "화요일"도 칠한다. 색연필 하나가 여러 뜻을 섞어 쓰니, 우리는 로봇이 무슨 생각을 하는지 도무지 알 수가 없다.

이 논문의 발상 전환은 이렇다. "색연필이 512자루뿐이라서 하나가 여러 뜻을 겸하는 거다. 그럼 우리가 **더 많은(예: 1024자루) 새 색연필 상자**를 만들고, 로봇이 실제로 칠한 그림을 보고 '이 그림은 새 상자의 어떤 색연필 몇 개로 다시 칠할 수 있을까?'를 맞혀보자. 단, **한 번에 아주 적은 수의 색연필만 쓰도록 강제**하면, 새 색연필 하나하나는 결국 '강아지 전용', '축구공 전용'처럼 뜻이 하나로 깔끔해질 것이다."

놀랍게도 이게 통했다. 새로 만든 색연필들은 사람이 봐도 "아, 이건 성경 인용을 칠하는 색연필", "이건 특정 이름을 칠하는 색연필"처럼 뜻이 또렷했다. 게다가 그 색연필 하나를 **살짝 바꿔치기**했더니 로봇의 대답이 예측한 대로 바뀌었다 — 색연필이 정말로 로봇의 판단을 **일으키는(원인)** 조각임을 보인 것이다.

## 🎓 학부생 수준

**문제.** 트랜스포머 언어모델의 내부 뉴런은 **다의적(polysemantic)** 이다 — 뉴런 하나가 의미상 서로 다른 여러 맥락에서 켜진다. 원인 가설은 **중첩(superposition)**: 모델이 뉴런 수보다 많은 "특징(feature)"을 표현하려고, 각 특징을 개별 뉴런이 아니라 **활성 공간의 과완비(overcomplete) 방향들**에 나눠 싣는다는 것이다. 그래서 "뉴런 = 개념"이라는 소박한 해석이 무너진다.

**아이디어.** 특징이 곧 방향이라면, 그 방향들을 **비지도로 복원**하면 된다. 저자들은 언어모델의 잔차 스트림(residual stream) 활성 벡터 $x$ 를 입력받아, 은닉 차원이 입력보다 큰(과완비) **희소 오토인코더**로 재구성한다. 인코더 $c=\mathrm{ReLU}(Mx+b)$ (각 기호: $M$ = 사전 행렬, $c$ = 특징 활성 계수, $b$ = 편향), 디코더 $\hat{x}=M^\top c$, 손실 $\mathcal{L}=\lVert x-\hat{x}\rVert_2^2+\alpha\lVert c\rVert_1$. 뒤의 $\alpha\lVert c\rVert_1$ 이 **한 번에 소수의 계수만 켜지도록(희소)** 압박하는 벌점이다.

**결과.** 이렇게 얻은 "사전 특징"은 (i) 자동 해석가능성 점수(큰 LLM이 특징을 설명·재현하는 상관도)에서 뉴런·PCA·ICA보다 높고, (ii) 간접목적어 식별(IOI) 과제에서 **활성 패칭(activation patching)** 으로 특징 몇 개만 바꿔치기해도 모델 출력의 반사실적(counterfactual) 변화를 이전 분해법보다 **더 정밀하게** 짚어낸다. 즉 특징이 상관이 아니라 **인과**의 단위임을 보였다.

## 🔬 전문가 수준

**Contribution (원문 초록·§1·§6 기준, 서술형으로 제시됨 — 번호는 해체자 정리):**

1. **비지도 중첩 해소.** 잔차 스트림 활성을 과완비 사전($d_\text{hid}=R\cdot d_\text{in}$, 주 결과 $R=2$)으로 재구성하는 L1-희소 오토인코더(tied weights)를 학습하면, 개별 뉴런·PCA·ICA보다 **더 단의미적이고 해석 가능한** 방향 집합을 얻는다. 해석가능성은 Bills et al. 2023 식 자동 해석(GPT-4 설명 생성 → GPT-3.5 시뮬레이션 → 상관) 으로 측정 (§3, Table 1, Figure 2).

2. **인과적 특징 국소화.** IOI 과제에서 사전 특징에 대한 활성 패칭 + ACDC(Conmy 2023) 기반 특징 선택으로, PCA 분해보다 **더 적은 패치 수로 목표 KL 발산**에 도달하고 편집의 정밀도–범위(Pareto) 프론티어를 개선한다. 비희소($\alpha=0$) 사전은 더 나쁘다 (§4~5, Figure 3; Pythia-410M layer 11).

3. **확장성·비지도성.** 단일 A40 GPU 1시간 이내, The Pile 활성 5–50M개, 1–3 epoch 로 학습. 라벨·과제 특화 없이 순수 재구성+희소 목적만으로 특징이 창발 → *"scalable, unsupervised method"*.

4. **정직한 자기-유보.** 재구성은 불완전하다(Pythia-70M layer 2 재구성 대입 시 Pile perplexity 25→40, §6.2). MLP 중간층에서는 과완비 사전을 강건하게 학습하지 못하고 dead feature 가 많다. Ground-truth 특징이 없어 "특징이 진짜인가"를 직접 검증 불가하며, $\alpha$ 선택에 뚜렷한 knee 가 없어 **여러 유효 분해**가 공존한다.

**방어 가능한 핵심 주장 한 줄**: "polysemanticity 는 뉴런 기저가 잘못된 좌표계이기 때문이며, 올바른 좌표계(희소 과완비 사전)로 옮기면 해석가능성과 인과 개입가능성이 **동시에** 회복된다." 이론적 기여는 중첩 가설(Elhage 2022)을 **실제 대형 모델에서 조작 가능한 방법론**으로 승격시킨 점.
