# 4. 방법론 해부 (z) — 구현 디테일

## 이 부분이 왜 필요한가

ALiBi가 실전에서 매력적인 이유의 절반은 "성능"이고 나머지 절반은 **"거의 공짜로 붙는다"** 이다. 이 파일은 그 공짜성의 근거 — 파라미터 0개, 위치 임베딩 제거, value 미오염, 계산 비용 무시 가능 — 를 구현 관점에서 정리한다.

## 구현 핵심 목록

1. **위치 임베딩 완전 제거**: 저자는 "ALiBi를 쓸 때 네트워크 어느 지점에도 위치 임베딩을 더하지 않는다"고 명시한다. 입력은 순수 단어 임베딩. 위치 처리는 오직 어텐션 로짓의 편향으로만 존재.

2. **학습 파라미터 0개 추가**: head별 기울기 $m$은 학습 전에 고정(§05_c). 편향 벡터 $m\cdot[-(i-1),\dots,0]$는 위치·head만으로 결정되는 상수라 gradient가 필요 없다. 모델 파라미터 수가 baseline과 사실상 동일.

3. **value에 위치 정보 미주입**: 편향은 softmax 안 로짓에만 더해지고, 가중합되는 value 벡터에는 위치가 섞이지 않는다. 저자는 관련연구(§5)에서 rotary와 대비하며 "value에 위치 정보를 넣지 않으므로 각 트랜스포머 층의 출력에는 명시적 위치 정보가 없다"는 취지로 이 성질을 강조한다. 이는 "위치는 *주목의 방식*에만 영향을 주고 *내용의 표현*은 오염시키지 않는다"는 설계 철학이다.

4. **계산·메모리 비용 무시 가능**: 편향 행렬은 미리 만들어 두면 되는 정적 하삼각(causal) 패턴이다. 저자는 자신들의 방법과 sinusoidal의 **속도 차이가 학습 시 1% 이내, 추론 시 3% 이내**라고 보고한다. 추가 메모리도 구성에 따라 수십~수백 MB 수준(예: 일부 설정 100MB)으로, 대신 **짧은 길이 학습이 가능해져 수 GB를 절약**한다.

5. **대규모 효율 실측**: 461GB 코퍼스의 1.3B 모델(25층·16 head·차원 2048·hidden 8192)을 L=1024로 학습해 L=2048로 외삽하면 L=2048 sinusoidal과 동일 perplexity를 **학습 11% 빠르게·메모리 11% 적게** 달성.

## 의사코드 (개념 수준)

```
# n_head개 head, 시퀀스 길이 L, causal mask
slopes = [ (2**(-8/n_head))**h  for h in 1..n_head ]     # 학습 안 함, 고정
# 상대거리 편향(하삼각): bias[h, i, j] = slopes[h] * -(i - j)   (j <= i)
for each head h:
    logits[h] = q[h] @ k[h].T           # 기존 어텐션 점수
    logits[h] = logits[h] + bias[h]     # 거리 벌점 더하기 (핵심 한 줄)
    attn[h]   = softmax(logits[h] + causal_mask)
    out[h]    = attn[h] @ v[h]           # value에는 위치 개입 없음
```

핵심은 **"logits += bias" 한 줄**이다. 기존 트랜스포머 코드에 위치 임베딩을 지우고 이 한 줄을 넣으면 ALiBi가 된다. 저자 공식 저장소(`github.com/ofirpress/attention_with_linear_biases`)는 Fairseq 기반 구현을 공개한다.

## 실험 재현 관련 (정직성)

- **단일 seed**: 저자는 "위치 방법과 학습 서브시퀀스 길이 외에 무작위 seed를 포함한 다른 하이퍼파라미터를 바꾸지 않았다"는 취지로 통제를 명시한다. 즉 **대부분 결과는 단일 실행**이며, 표준편차는 sinusoidal baseline에 대해서만(±0.24) 보고된다. 분산의 폭넓은 보고는 이 논문의 약점이다(§07).

## 이 부분의 핵심 한 문장

ALiBi는 **위치 임베딩을 지우고 어텐션 로짓에 정적 거리 편향 한 줄을 더하는 것**으로 끝나며, 파라미터도 계산도 사실상 공짜로 붙기에 "적용 장벽이 거의 0"이라는 실용적 장점이 방법 자체의 단순함에서 직접 나온다.
