# 4. 방법론 해부 (c) — head별 기울기 m의 설계

## 이 부분이 왜 필요한가

편향 식 $m\cdot(-(i-j))$에서 남은 유일한 자유도는 기울기 $m$이다. 만약 모든 head가 같은 $m$을 쓰면, 모델은 단 하나의 "감쇠 속도"만 갖게 되어 "가까운 것만 보는" 극단으로 치우친다. ALiBi의 실전 성능은 **$m$을 head마다 다르게 두어 여러 시간 스케일을 동시에 커버**하는 데서 나온다. 이 파일은 그 $m$ 수열의 구체적 정체를 뜯는다.

## 수식 제시 — head별 기울기 수열

$n$개의 head가 있을 때, 각 head의 기울기 $m$은 다음 기하수열(geometric sequence)로 고정된다:

$$m_h = \left(2^{-8/n}\right)^{h}, \qquad h = 1, 2, \dots, n$$

즉 **첫 항이 $2^{-8/n}$이고 공비(ratio)도 $2^{-8/n}$인 기하수열**이다. 원문 표기로:

- **8개 head**: $\dfrac{1}{2^1},\ \dfrac{1}{2^2},\ \dfrac{1}{2^3},\ \dots,\ \dfrac{1}{2^8}$
- **16개 head**(보간): $\dfrac{1}{2^{0.5}},\ \dfrac{1}{2^{1}},\ \dfrac{1}{2^{1.5}},\ \dots,\ \dfrac{1}{2^{8}}$

### 4줄 해석

1. **기호 뜻**: $n$ = head 개수. $h$ = head 인덱스(몇 번째 head인가). $m_h$ = 그 head의 감쇠 기울기. 8-head라면 첫 head는 $1/2$(느리게 깎임 → 먼 곳도 꽤 봄), 마지막 head는 $1/256$… 아니 — 주의: 8-head에서 $2^{-8/8}=2^{-1}=1/2$가 첫 항, 공비도 $1/2$이므로 $m_h = (1/2)^h$가 되어 $1/2, 1/4, 1/8, \dots, 1/256$. **작은 $m$일수록 천천히 깎여 먼 토큰까지 본다.**
2. **일상 비유**: 라디오 여러 대를 서로 다른 감도로 맞춰 둔 것과 같다. 어떤 head는 "근처 소리만 크게"(큰 $m$), 어떤 head는 "멀리 소리도 어느 정도"(작은 $m$). 여러 감도의 귀를 동시에 두어 다양한 거리 스케일의 신호를 한꺼번에 잡는다.
3. **왜 이 형태(기하수열)인가**: 감쇠 스케일을 **선형이 아니라 배수로(로그 스케일)** 펼쳐야 짧은 의존성부터 긴 의존성까지 균형 있게 덮인다. 만약 $m$을 등차로 두면 대부분의 head가 비슷한 중간 스케일에 몰린다. $2^{-8/n}$을 공비로 두면 $n$이 커질수록 같은 $[1/2^1, 1/2^8]$ 범위를 더 촘촘히 채우는 방식으로 자연스럽게 보간된다(16-head가 8-head 사이사이를 메움).
4. **조심할 점**: (a) 이 수열은 **학습되지 않는 하이퍼파라미터**다 — 저자는 이 특정 기하수열이 잘 작동함을 실험으로 찾았고, "학습 가능하게 만들어도 큰 이득이 없었다"는 취지의 논의를 한다(§05_z에서 다룸). (b) 범위 $[1/2^1, 1/2^8]$의 상·하한 자체는 언어 실험에 맞춰 튜닝된 선택이라, **다른 도메인에서 최적 범위가 다를 수 있다.**

## 다른 접근으로 했다면 (대안 비교)

- **대안 1 — 단일 $m$ 공유**: 모든 head가 같은 감쇠. 구현은 더 단순하나 다중 스케일을 못 잡아 성능 저하. 다중 head의 존재 이유(서로 다른 관계 포착)를 살리지 못한다.
- **대안 2 — $m$을 학습**: 각 head의 기울기를 gradient로 배우게 하기. 유연하지만 파라미터가 늘고, 저자 보고상 고정값 대비 뚜렷한 이득이 없었다 — "고정 기하수열"이 이미 좋은 사전(prior)이라는 뜻.
- **대안 3 — 등차수열/균등 분포**: 스케일이 한쪽에 몰려 짧거나 긴 의존성 한쪽을 놓친다.

## 이 부분의 핵심 한 문장

**head마다 기울기 $m$을 $2^{-8/n}$ 공비의 기하수열로 고정**함으로써, 하나의 모델이 "근거리만 보는 head"부터 "원거리까지 보는 head"까지 **여러 recency 스케일을 동시에** 갖게 되고, 이것이 다중 head의 감쇠 다양성을 통해 실전 성능을 끌어올린다.
