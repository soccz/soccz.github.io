# 4-a. 방법론 — 직관 (큰 그림)

> **배경 사다리**: 이 파일은 수식을 최소로 두고 전체 흐름만 그린다. 뒤의 b~e 파일이 각 부품을 수식으로 뜯는다. 여기선 ① 트랜스포머가 "각 시점이 다른 시점을 얼마나 볼지"를 정하는 어텐션 행렬을 만든다는 것, ② 그 행렬을 만들기 전에 "마스크(가림막)"를 덧씌울 수 있다는 것만 잡으면 된다.

## 한 문장 요약

**표준 어텐션 점수 행렬에 "미래를 막는 마스크(인과)"와 "멀수록 깎는 마스크(최근성)"를 더한 뒤 소프트맥스를 취한다 — 그게 전부다.**

## 파이프라인 4단계

```
입력 시계열 X
   │
   ▼  ① 표준 유사도 점수  S_h = K_h Q_h^T / √D_k     (각 시점 쌍이 얼마나 닮았나)
   │
   ▼  ② 인과 마스크 더하기  + M^(C)   (미래 위치는 -∞ → 소프트맥스 후 0)
   │
   ▼  ③ 최근성 마스크 더하기  + M^(L)  (과거는 거리 t_i - t_j 만큼 점수 깎기)
   │
   ▼  ④ 소프트맥스  C_h = Softmax(S_h + M^(C) + M^(L))   (Eq. 6)
   │
   ▼  가중합  X̃_h = C_h V_h  →  다음 층으로
```

## 왜 이 구조인가 — 세 개의 발상

**발상 1: 위치 표식이 아니라 거리 편향을 심는다.**
Sinusoidal/learned PE 는 "너는 3번째 시점이다"라는 **표식**을 붙였다. RBCA 는 표식 대신 "3칸 떨어진 것은 점수 $f(3)$ 만큼 깎아라"라는 **선호**를 어텐션 점수에 직접 준다. 표식은 모델이 해석해야 하지만, 선호는 이미 방향이 정해져 있다.

**발상 2: 감쇠의 형태가 관건이다.**
"멀수록 깎는다"는 방향은 ALiBi 가 이미 했다. Powerformer 의 새로움은 **깎는 곡선의 모양**이다. 지수($-\alpha t$)는 급강하 후 0, 거듭제곱($-\alpha\log t$ → 가중치 $t^{-\alpha}$)은 급강하 후 **두꺼운 꼬리**. 시계열은 "대부분 최근이 중요하지만 가끔 먼 과거도 필요"하므로 두꺼운 꼬리가 맞다는 것이 이 논문의 베팅.

**발상 3: 마스크는 값(내용)이 아니라 위치에만 의존한다.**
$M^{(L)}$ 은 어텐션 내용 $S_h$ 와 독립적으로 **거리만** 보고 계산된다. 그래서 (i) 학습 파라미터가 거의 없고(감쇠 지수 $\alpha$ 정도), (ii) 계산이 싸고, (iii) "이 모델이 왜 이렇게 보는가"를 거리 곡선 하나로 설명할 수 있다(→ 해석 가능성, e 파일).

## 큰 그림에서의 주의점

- 이 방법은 **인코더 어텐션의 국소성 편향**을 심는 것이지, 예측 헤드나 손실함수를 바꾸는 게 아니다. 확률 예측·분위수 예측은 별도 문제로 남는다.
- 최근성 편향이 **항상** 이득은 아니다. 강한 주기성(먼 과거가 정확히 반복되는 데이터)에서는 "멀수록 깎기"가 오히려 유용한 먼 신호를 죽인다(→ §4 Traffic·Electricity 열세, 07_limits 참조).
