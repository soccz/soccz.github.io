# 2. 문제 지형도 — TSFM은 왜 "블랙박스"이고, 왜 그게 문제인가

**배경 사다리**: 이 절을 이해하려면 ① "파운데이션 모델"이 **한 번 크게 학습해두고 여러 새 문제에 그대로 갖다 쓰는 대형 모델**이라는 것, ② Transformer 안에서 정보가 **층(layer)을 차례로 통과하며 residual stream(잔차 흐름 — 각 층이 조금씩 더하고 빼는 공용 메모리 통로)** 위에서 갱신된다는 것, ③ "해석론(interpretability)"이 **학습된 모델의 내부를 열어 무엇을·어디서·어떻게 계산하는지 밝히는 작업**이라는 것 정도만 알면 된다.

## 이 문제가 현실에서 생기는 방식

**상황 1 — 병원 ICU.** 어떤 TSFM이 환자의 심전도(ECG)를 보고 "부정맥 위험 높음"을 출력한다. 의사가 묻는다. "모델이 무엇을 근거로 이렇게 판단했나?" 대답할 수 없다면 임상 배치가 막힌다. 시계열은 이미지처럼 눈으로 짚어 "여기 때문"이라고 말하기 어렵다.

**상황 2 — 트레이딩 데스크.** 파운데이션 모델이 다음 30분 가격을 예측한다. 리스크 매니저가 "이 예측에 '추세 지속' 가정이 얼마나 실려 있나? 갑자기 레짐이 바뀌면 모델의 어느 부분이 그걸 놓치나?"를 알고 싶다. 모델이 **어떤 개념을 어디에 저장**하는지 모르면 이런 스트레스 분석이 불가능하다.

**상황 3 — 배포 비용.** TSFM은 층이 수십 개인 대형 Transformer다. 엣지 디바이스나 실시간 시스템에 올리려면 줄여야 하는데, **어느 층이 실제로 일하고 어느 층이 놀고 있는지** 모르면 무작정 자르다 성능이 무너진다.

세 상황의 공통점: **성능은 확인되는데 내부는 안 보인다.** 이게 TSFM 해석론의 핵심 수요다.

## 기존 접근 계보 (연대순 이정표)

**① 어텐션 시각화 (2017~2020).** "Transformer가 어디를 보는지"를 attention 가중치 히트맵으로 그려 설명하려 했다. 문제: attention이 곧 설명인지 자체가 논쟁거리였다(Jain-Wallace 2019 "Attention is not Explanation" — 이 큐레이션에서 2026-05-18 다룸). 교훈: **표면의 attention만 봐서는 내부 계산을 알 수 없다.**

**② LLM mechanistic interpretability (2021~2024).** 언어모델에서 **회로(circuit)**, **유도 헤드(induction head)**, **선형 표현 가설(개념 = 잠재공간의 방향)**, **활성 개입(activation steering)** 같은 강력한 도구가 쏟아졌다. Monosemanticity(2026-05-22 다룸), Sparse Feature Circuits(2026-05-15 다룸)가 대표. 교훈: **residual stream을 직접 조사·조작하면 "어디에 무엇이 있는지"를 인과적으로 밝힐 수 있다.** 단, 전부 **텍스트·토큰** 모델에서만 개발됐다.

**③ 시계열 파운데이션 모델의 등장 (2023~2024).** Chronos(2026-04-29 다룸), MOIRAI(2026-06-03 다룸), TimesFM(2026-07-01 다룸), MOMENT가 "시계열판 GPT"를 표방하며 나왔다. 성능 벤치마크는 풍부해졌지만 **내부 해석은 거의 백지**였다. 시계열은 토큰처럼 "단어 뜻"이 없어서 LLM 해석 도구를 그대로 옮기기 애매했다.

**④ TSFM 해석의 초기 시도 (2024~).** Concept Bottleneck for TS Transformers(van Sprang 2024), "Dissecting Chronos" SAE(2026-05-27 다룸) 등이 개별 각도에서 열기 시작했다. 그러나 **"층 중복 + 개념 국소화 + 개입"을 한 프레임에서 다루고 여러 TSFM에 걸쳐 비교**한 것은 없었다.

## 기존이 공통으로 놓친 gap

> **한 문장**: LLM 해석론의 성숙한 3종 도구(층 유사도·선형 프로빙·steering)를 **시계열 파운데이션 모델에 체계적으로 이식해, "표현이 중복돼 있는가 / 개념이 어디에 있는가 / 밖에서 조종되는가"를 한 번에 답한 연구가 없었다.**

## 이 논문이 gap을 메우는 방식

저자들은 새 알고리즘을 발명하는 대신 **이식(porting)** 을 택한다. CKA로 층 중복을 지도화하고(→ 가지치기라는 실용적 부산물), 선형 프로빙으로 개념의 층별 위치를 찾고(→ "TSFM도 개념을 방향으로 저장한다"는 존재 증명), steering 벡터로 그 개념을 인과적으로 켜고 끈다(→ 상관이 아니라 개입). 세 도구를 MOMENT·Chronos·Moirai 세 종류 아키텍처에 걸쳐 돌려 **일반성**을 주장한다. 이 "브릿지" 전략이 논문의 정체성이자 동시에 한계다 — 도구가 이미 있으니 참신함은 낮지만, **시계열 도메인에 처음 착지시켰다는 존재 증명의 값**이 크다.
