## 17.7 자기점검

### 핵심 3 가지

1. **Gu-Kelly-Xiu 의 *deep learning finance trigger* role?**
2. **Industry adoption 의 *2년 만 production* 의 의의?**

### 답변

1. **First compelling deep learning asset pricing**. Pre-2021: linear factor models (Fama-French, Carhart). Gu-Kelly-Xiu 2021 = *deep learning + characteristic-conditional + autoencoder* — *significant R² gain*. *JFE acceptance* = *finance academic mainstream validation*. → Deep learning finance era 의 *founding paper*.

2. **Academic-industry pipeline efficiency**. 2021 paper → 2022 hedge fund deployment. Open-source code + replicable benchmarks 활용. Industry 의 *immediate value perception* — *practical signal*. *Quant finance 의 fast adoption pattern*.

3. **Foundation TS + asset pricing hybrid**. Chronos 같은 TFM = generic forecasting. Gu architecture = asset pricing 특화. 결합: *general pre-training + asset-specific fine-tune* = *best-of-both*. 2025-2026 의 *active research direction* — *equity, bond, commodities 통합* 의 *unified framework*.
