# 11. 한 줄 판결

> **금융 도메인 LLM 의 "GLUE-순간" — 8 태스크 / 15 데이터셋 / 136K 인스트럭션 / FinMA 3-변형의 4-요소 패키지로 "공개 데이터 + 공개 모델 + 표준 평가" 의 동시 부재를 단번에 해소했다. 본 연구 (APF/Grokking-in-TS-Transformers) 에는 직접 substrate 가 아니지만, P1 ProTran-TFA 의 finance venue (IJF/QF) 재개 시 "벤치마크 정합성 표준" 으로 인용해야 할 1순위 reference. 또한 stock movement prediction 의 tweets+OHLCV 멀티모달 데이터셋 (BigData22/ACL18/CIKM18) 은 AETHER (crypto cycle) 의 sentiment+price fusion 설계의 직접 사전 작업.**

## 판결의 이유 — 3줄 보충

(1) **NeurIPS 2023 D&B Track Tier 1 venue 통과 + MIT 라이선스 + 후속 FinBen NeurIPS 2024 / IJCAI 2024 FinLLM Challenge 폭발** 의 사회적 채택 증거가, "벤치마크 자체가 분야를 만든다" 의 GLUE-precedent 를 금융 도메인에서 successful 재현.

(2) 본 사용자 main candidate (APF, Grokking-in-TS-Transformers) 에 substrate 가 약하지만, **paused P1 ProTran-TFA + shelved AETHER** 의 재가동 시 직접 표준 벤치마크 + 멀티모달 substrate 로 활용 가능. 9-종 metric dual reporting + Disclaimer 면책의 도구화는 사용자 모든 paper 의 reviewer-resistant 정합성 향상.

(3) 본 PIXIU 가 못 한 것 (시계열 직렬화 방식 ablation 부재, instruction multiplier 정당화 부재, 시간 분포 변동 evaluation 부재) 이 사용자 NeurIPS 2027 workshop / ICLR 2028 short paper 의 directly actionable contribution 후보 — **실험 1 (Motif Drift) + 실험 2 (TS Serialization Ablation)** 로 단일 작가 short paper 가능.
