# 5.A 방법론 ① 큰 그림 — TS 를 2D 이미지로 들어 올리는 3-경로 + 1-학습기

## 5.A.1 배경 사다리

이 절을 이해하려면 ① **Gram 행렬** 이 "여러 벡터들의 모든 쌍의 내적을 모은 정사각 행렬" 이라는 것, ② **마코프 체인** 이 "현재 상태만으로 다음 상태의 확률이 정해지는 시퀀스 모델" 이라는 것, 그리고 ③ **Tiled CNN** 이 "보통 CNN 처럼 *모든 위치에서 같은 가중치를 공유* 하는 대신, *작은 타일 안에서만 공유* 하는 부분 공유 CNN" 이라는 것 — 이 3 가지만 알면 충분하다.

## 5.A.2 큰 그림 — 3 인코딩 + 1 학습기

본 논문의 방법은 *데이터 → 표상 → 학습기* 의 3-층 파이프라인이다.

```
                   ┌─────────────────────────────────────┐
                   │  TS X = (x_1, …, x_n)               │
                   │   1D 시퀀스, 길이 n                │
                   └────────────┬────────────────────────┘
                                │
            ┌───────────────────┼───────────────────┐
            │                   │                   │
     ┌──────▼──────┐    ┌───────▼──────┐    ┌──────▼──────┐
     │   GASF      │    │   GADF       │    │   MTF       │
     │ n×n cosine  │    │ n×n sine     │    │ n×n quantile│
     │ summation   │    │ difference   │    │ transition  │
     │  Gram matrix│    │  Gram matrix │    │   matrix    │
     └──────┬──────┘    └──────┬───────┘    └──────┬──────┘
            │                  │                   │
            └─────── RGB stack (compound image) ───┘
                                │
                    ┌───────────▼────────────┐
                    │   Tiled CNN (Le 2010)   │
                    │   부분 공유 conv +     │
                    │   pool + FC + softmax  │
                    └───────────┬────────────┘
                                │
                       ┌────────▼───────┐
                       │  Classification │
                       │   (TSC label)   │
                       └─────────────────┘
```

여기에 imputation 분기가 별도로 붙는다:

```
   X (결측 포함) ─► GASF 변환 (결측은 NaN 또는 mask)
              ─► Denoising Auto-encoder (DA) 로 image inpainting
              ─► GASF 역변환 (bijection on [0,1] rescale)
              ─► X̂ (보간된 시계열)
```

## 5.A.3 각 모듈의 *왜* 한 줄 정당화

| 모듈 | 왜 필요한가 (한 줄) |
|---|---|
| GASF | *Symmetric* + 대각선이 각 시점의 *자기 정보* 를 그대로 인코딩 → CNN 이 *시간 짝의 유사도* 패턴을 잡기 좋음 |
| GADF | *Antisymmetric* + 대각선이 0 → CNN 이 *시간 방향의 변화 (gradient-like)* 신호를 잡기 좋음 |
| MTF | *비대칭* 전이 정보 → GAF 가 못 잡는 *마코프 short-range probabilistic structure* 보충 |
| Compound RGB | 3 채널 (GASF, GADF, MTF) 의 *상보성* 을 한 텐서로 결합 → vision CNN 의 RGB-친화적 API 에 그대로 투입 |
| Tiled CNN | 시계열의 *위치-의존 패턴* (같은 모양이 시작/끝에서 다른 의미) 을 *완전 공유 conv* 보다 잘 잡음 |
| Denoising AE | 이미지 inpainting 의 표준 도구를 *시계열 보간* 으로 무료 재활용 |

## 5.A.4 한 문장 정리

> "본 논문의 방법은 *시계열 → 2D 이미지 (3 채널) → vision CNN* 의 직선 파이프라인이고, 각 단계는 *수학적으로 정의된 결정론적 변환* 이거나 *비전에서 검증된 기성 학습기* 다 — 즉 본 논문의 **기여는 *학습기* 가 아니라 *표상* 에 있다**."
