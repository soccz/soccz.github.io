## 18.7 자기점검

### 핵심 3 가지

1. **Chen-Pelger-Zhu 의 *founding role* 의 의의?**
2. **GAN moment selection 의 *paradigm novelty*?**
3. **Industry adoption 의 *speed* 의 enabler?**

### 답변

1. **First compelling deep learning SDF**. Pre-2020: SDF = linear factor combination. Chen-Pelger-Zhu = *FFN + LSTM + GAN* 의 *first integrated framework*. *Macroeconomic state conditioning* + *moment GAN* = *novel mechanism*. Gu-Kelly-Xiu와 함께 *deep learning asset pricing 의 founding triangle*.

2. **Adversarial moment selection**. Classical: pre-specified sample moments. GAN moment selection = *learn which moments matter via adversarial game*. → *Optimal moment selection* 의 *data-driven approach*. *Generator vs Discriminator* 의 *minimax* → SDF + adversarial moments = *robust SDF estimation*.

3. **Open-source + replicable + clear ROI**. Paper의 *replicable code*, *clear performance gain* (Sharpe 1.5+), *immediate hedge fund value* 인식. *Academic-industry pipeline efficiency*. 2년 만에 *production strategy* 로 변환. *Quant 산업의 fast adoption pattern*.
