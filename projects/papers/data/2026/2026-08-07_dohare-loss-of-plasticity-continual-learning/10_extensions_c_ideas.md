# 9-c. 실험해볼 후속 아이디어 2개

> **설계 원칙**: 둘 다 ① 프로필에 명시된 자산만 쓰고, ② 결과가 어느 쪽으로 나와도 논문에 쓸 수 있으며, ③ 반증 조건을 미리 못 박았다. "이미 돌고 있는 것에 계측을 붙인다"를 1번, "새로 돌린다"를 2번에 두었다.

## 아이디어 1 — **Plasticity Probe on Grokking Runs**: 진행 중인 실행에 계측만 붙이기

### 가설
시계열 트랜스포머에서 **grokking 이 일어나는 순간과 유효 랭크의 변곡점이 시간적으로 정렬한다.** 구체적으로: 정상 데이터에서는 일반화가 도래할 때 유효 랭크가 **감소**(표현 압축)하고, 비정상 데이터에서는 같은 감소가 회복 없이 **단조 진행**되어 가소성 상실로 이어진다.

### 데이터 (프로필 명시 자산만)
**logistic map**(프로필 status 가 *"P2 logistic 4-layer 실험 background 진행 중"* 이라 **이미 돌고 있다**) / **sin/periodic synthetic**(정상 대조군) / **regime-switching synthetic**(비정상 조건).

### 방법
진행 중인 run 의 체크포인트에 세 계측을 **사후(post-hoc) 적용** — 추가 학습 비용 0. ① 죽은 유닛 비율 ② 층별 평균 가중치 절댓값 ③ **유효 랭크** 식 (2) $\text{erank}(\Phi)=\exp\{H(p_1,\dots,p_q)\}$ (+ stable rank 병기로 임계값 의존성 배제).

$\Phi$ 는 각 은닉층의 활성 행렬(행=검증 배치 예제, 열=유닛)로 고정하고 **층별 값과 층 평균을 모두** 기록한다 — 원 논문이 *"average effective rank of the network"* 라고만 하고 층별 분포를 보고하지 않은 공백을 메우는 지점이다.

### 비교 조건
| 조건 | 데이터 | 기대 |
|---|---|---|
| A | sin/periodic (정상) | grokking 시점 ↔ erank 변곡 정렬 여부 |
| B | logistic map (정상·혼돈) | 동일, 단 혼돈성이 정렬을 흐리는지 |
| C | regime-switching (비정상) | erank 단조 감소 + 회복 없음 |

### 예상 결과
A·B 에서는 erank 가 **감소 후 안정**(압축 완료), C 에서는 **감소가 멈추지 않음**. 이 대비가 나오면 "다양성 감소 자체가 나쁜 게 아니라, **회복 없는 단조 감소가 나쁘다**"는 정밀화된 주장이 성립한다 — 원 논문의 "다양성 = 좋음" 프레임을 흡수하면서 반박하는 위치다.

### 반증 조건 (미리 못 박음)
- **반증 1**: 세 조건 모두에서 erank 궤적이 구분되지 않으면 → 유효 랭크는 TS 트랜스포머에서 정보가 없는 지표다. 이 축을 버리고 죽은 유닛/노름 축만 남긴다.
- **반증 2**: grokking 시점과 erank 변곡이 **무관**하면 → §8.2 흡수 2 의 통합 가설이 기각된다. 아픈 결과지만 **보고할 가치가 있는 음성 결과**다 (프로필의 *"TMAO method falsified at n=12"* 처럼 음성 결과를 기록해 온 관행과 일관).

### 비용 추정
사후 계측이므로 **학습 비용 0**, 체크포인트당 SVD 한 번이면 된다. 구현 + 3 조건 분석 + 그림 **2~4일**. **이 목록에서 압도적으로 가성비가 좋고, 오늘 논문을 읽은 직후 바로 착수 가능한 유일한 항목이다.**

## 아이디어 2 — **Intervention Unit Test**: 트랜스포머에서 무엇을 리셋해야 하는가

### 가설
연속 역전파의 유닛 단위 개입은 **트랜스포머에서 효율이 떨어지며**, 개입 단위를 어텐션 패턴(motif) 수준으로 올리면 같은 개입 예산에서 더 큰 가소성 회복이 나온다. 즉 **"무엇을 리셋하는가"가 "얼마나 리셋하는가"보다 트랜스포머에서 더 중요하다.**

(이 가설은 `07_limits.md` 암묵 가정 ③ + `10_extensions_a_questions.md` Q3·Q4 를 하나의 실험으로 합친 것이며, 프로필 명시 APF 프레임 *"PE → 2D attention motif → CNN probe → causal intervention"* 의 마지막 단계를 새 목적함수에 재사용한다.)

### 데이터
- **regime-switching synthetic** (프로필 명시) — 지평을 길게: regime 전환 O(10³) 회. 원 논문의 교훈(*"may not occur at all for small numbers of tasks"*)을 프로토콜로 반영.
- **APF synthetic motif benchmark** (프로필 명시: trend/seasonal/regime/anomaly/freq drift) — motif 라벨이 있으므로 개입 단위를 motif 로 정의할 수 있는 유일한 자산.

### 비교 조건 (개입 예산을 동일하게 고정)
같은 "재초기화되는 파라미터 수"를 예산으로 묶고, **선택 규칙만** 바꾼다.

| 조건 | 개입 단위 | 선택 규칙 |
|---|---|---|
| 0 | — | 무개입 (대조) |
| 1 | 유닛 | 식 (1) 효용 최하위 (원 논문 재현) |
| 2 | 유닛 | **무작위** ← Q3 의 결정적 대조군 |
| 3 | 유닛 | 효용 **최상위** (음성 대조군) |
| 4 | 어텐션 헤드 | 헤드 단위 효용 최하위 |
| 5 | motif | motif 활성도 최하위 (APF 프레임) |

**조건 2 와 3 이 이 실험의 핵심이다.** 원 논문에 없는 두 대조군이고, 둘 없이는 식 (1)의 필요성을 아무도 주장할 수 없다.

### 예상 결과
**조건 1 ≈ 조건 2** 일 가능성이 실제로 꽤 있다고 본다(교체율이 극도로 낮으므로) — 그렇다면 효용 척도의 기여가 재규정돼야 하고 그 자체가 발표 가치가 있다. **조건 3 < 조건 0** 이면 척도가 최소한 의미 있는 순위는 만든다는 확인. **조건 4 < 조건 1** 이면 트랜스포머에서 헤드가 유닛보다 나쁜 단위라는 뜻(LayerNorm·잔차로 헤드 출력 크기가 중요도를 대리하지 못한다는 예측과 일치). **조건 5 > 조건 1** 이면 APF 핵심 주장의 첫 정량 증거다.

### 반증 조건
- 조건 5 가 조건 1·2 와 구분되지 않으면 → **motif 단위 개입 가설 기각.** APF 는 개입 단위 주장을 접고 "해석 단위"로만 포지셔닝해야 한다 (억지로 살리지 않는다).
- 조건 0 에서 애초에 가소성 상실이 관측되지 않으면 → 지평을 10배 늘려 재확인하고, 그래도 없으면 **"TS 트랜스포머는 가소성 상실에 강건하다"는 음성 결과로 보고한다** — 이것도 "0 papers found" 교차점의 유효한 답이다.

### 비용 추정
6 조건 × 3 seed 이상 × 긴 지평(regime 전환 10³ 회) = 합성 데이터 + 소형 트랜스포머 기준 **GPU 1~2대로 1~2주**. 아이디어 1 을 먼저 봐야 한다 — 그것이 반증 1 로 끝나면 이 실험의 종속변수 설계도 바뀌기 때문이다.

## 두 아이디어의 관계

```
아이디어 1 (계측만, 2~4일, 비용 0)
   │  "어느 지표가 TS 트랜스포머에서 정보가 있는가?"
   │
   ├── 정보 있음 ──▶ 아이디어 2 착수 (개입 단위 비교, 1~2주)
   │                    └─▶ APF motif 개입 단위 주장의 첫 정량 증거
   │
   └── 정보 없음 ──▶ 지표 축 폐기, 노름 축만 유지 (음성 결과로 보고)
```

**순서를 지킬 것.** 2번을 먼저 돌리면 종속변수가 정해지지 않은 채 GPU 를 태우게 된다.
