# 05_method_a — 방법론 전체 흐름: 큰 그림

**배경 사다리**: 이 절을 이해하려면 ① 오토인코더(입력을 압축했다가 복원하는 신경망)의 기본 개념, ② Transformer 계층 구조(입력 → 여러 층을 거쳐 → 출력)가 무엇인지, ③ "특징(feature)"이 신경망 내부에서 어떤 의미를 갖는지만 알면 된다. 수식보다 흐름 중심으로 설명한다.

---

## 전체 파이프라인: 3단계 요약

```
[1단계] 데이터 수집
Chronos-T5-Large에 시계열 윈도우를 입력 →
6개 추출 지점에서 내부 활성화(activation) 추출

     ↓

[2단계] SAE 훈련
추출된 활성화로 TopK Sparse Autoencoder 훈련 →
8,192차원 희소 특징 공간으로 분해

     ↓

[3단계] 인과 검증
개별 SAE 특징 하나씩 제거(ablation) →
CRPS 변화 측정 → 인과 지도 구성
```

---

## 1단계: 무엇을 해부할 것인가 — Chronos-T5-Large

Chronos-T5-Large는 Amazon에서 공개한 시계열 파운데이션 모델이다. 핵심 구조:
- **기반 아키텍처**: T5 (Text-to-Text Transfer Transformer) — 원래 NLP용으로 설계
- **파라미터 수**: 710M (약 7억 1천만)
- **구조**: 24개 인코더 블록 + 24개 디코더 블록
- **히든 차원**: d_model = 1,024
- **입력 방식**: 시계열 값을 이산 토큰으로 양자화(quantize)하여 T5 인코더에 입력. 디코더는 미래 토큰 시퀀스를 자기회귀 방식으로 생성

Chronos는 9개 도메인, 270억(27B) 관측치로 사전학습된 뒤 다양한 시계열에서 제로샷 예측이 가능하다.

**왜 Chronos를 선택했나**: NLP 아키텍처(T5)를 그대로 사용하기 때문에 NLP SAE 연구와의 비교 기준이 명확하다. 또한 공개 모델이고, 이전 논문(Ansari et al. TMLR 2024, 우리가 2026-04-29에 해체)에서 이미 성능이 검증됐다.

---

## 2단계: 어디를 추출하는가 — 6개 추출 지점

전체 48개 블록(24 인코더 + 24 디코더) 중 6개를 선택했다. 선택 원칙: 파이프라인 전체를 고르게 커버.

| 추출 지점 | 설명 |
|-----------|------|
| 인코더 block 5 (early) | 초기 인코더 — 저수준 특징 |
| 인코더 block 11 (mid) | 중간 인코더 — 핵심 처리 |
| 인코더 block 23 (final) | 최종 인코더 — 고수준 의미 |
| 디코더 block 11 | 중간 디코더 |
| 디코더 block 23 | 최종 디코더 |
| 크로스-어텐션 block 11 출력 | 인코더-디코더 정보 전달 지점 |

각 추출점에서 "잔차 스트림(residual stream)" 활성화를 추출한다.

> **잔차 스트림(residual stream)**: Transformer는 각 블록이 이전 층의 출력에 "덧붙이는(residual)" 방식으로 정보를 변환한다. 잔차 스트림은 이 덧붙임들이 누적된 중간 표현이다. NLP mechanistic interpretability에서 "정보가 흐르는 강"에 비유된다.

---

## 3단계: 어떻게 분해하는가 — TopK Sparse Autoencoder

**왜 SAE인가?**

Transformer의 내부 활성화는 d_model=1,024 차원의 밀집 벡터(dense vector)다. 이 벡터 하나에 여러 개념이 혼재되어 있다(다형성/polysemanticity). 개별 뉴런을 분석해도 "이 뉴런이 무엇을 인코딩하는가"를 말하기 어렵다.

SAE는 이 문제를 우회한다: 입력 벡터(1,024차원)를 고차원(8,192차원)의 *희소한* 표현으로 변환하되, 한 번에 소수(k=64)의 특징만 활성화된다. 이로써 각 특징이 단일 개념에 대응할 가능성이 높아진다.

**비유**: 음악 신호(복잡한 밀집 벡터)를 악기별 트랙으로 분리(희소 표현)하는 것과 비슷하다. 원본 신호에는 바이올린, 피아노, 드럼이 뒤섞여 있지만, 분리하면 각 악기를 독립적으로 다룰 수 있다.

**훈련 파이프라인 요약** (자세한 수식은 `05_method_b_sae_architecture.md` 참조):
1. 각 추출 지점마다 독립적으로 SAE를 훈련
2. 훈련 데이터: ~100,000개 시계열 윈도우에서 추출한 활성화
3. SAE 훈련 완료 후, 각 특징의 의미를 분석하고 레이블 부여

---

## 4단계: 인과성을 어떻게 확인하는가 — Ablation 실험

SAE 특징 하나를 "제거"한다는 것은:
1. 원본 활성화를 SAE로 인코딩
2. 특정 특징의 계수를 0으로 설정(ablation)
3. SAE로 디코딩하여 수정된 활성화 생성
4. 수정된 활성화를 모델 나머지 파이프라인에 주입
5. 출력 예측 분포 계산 → CRPS 측정

ΔCRPS = CRPS(ablated) - CRPS(original) > 0이면 그 특징이 예측에 기여한다 (큰 ΔCRPS = 중요한 특징).

**왜 이 방법인가**: 단순 상관 분석이 아니라 **개입(intervention)**이다. 특징 하나를 직접 조작하여 출력 변화를 측정하므로 Simpson의 역설(교란 변수 문제) 등으로 인한 오해가 줄어든다.

**실험 규모**: 392회 단일 특징 절제 — 전수 조사(49,152개)의 약 0.8%. 따라서 이 실험은 **샘플링된 인과 검증**이다.

## 방법론 전체의 강점과 핵심 선택

이 논문의 방법론적 선택에서 핵심 결정이 세 가지 있다:

1. **TopK vs. L1-penalty SAE**: L1 penalty(기존 방법)는 희소성이 적응적으로 변하지만, TopK는 항상 정확히 k개 특징이 활성화되므로 실험 재현성이 높다.

2. **잔차 스트림 추출**: 어텐션 출력, MLP 출력 등 여러 중간 표현 중 잔차 스트림을 선택한 것은 NLP mechanistic interpretability의 표준 프로토콜을 따른 것이다.

3. **단일 특징 절제 (vs. 집합 절제)**: 특징 하나씩 제거하여 개별 인과 기여를 독립적으로 측정. 집합 절제는 특징 간 상호작용을 포착할 수 있지만 계산 비용이 지수적으로 증가한다.
