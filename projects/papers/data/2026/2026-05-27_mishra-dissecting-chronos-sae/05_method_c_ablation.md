# 05_method_c — 방법론: 인과 절제 실험 (Causal Ablation)

**배경 사다리**: 이 절은 ① "인과성" vs "상관성"의 차이 (A가 B와 함께 변한다 ≠ A가 B를 유발한다), ② "절제(ablation)"가 무엇인지(특정 부분을 제거하고 결과를 관찰하는 실험), ③ CRPS가 "예측 분포"의 품질 지표라는 것(낮을수록 좋음)을 알면 충분하다.

---

## 왜 인과 절제가 필요한가

SAE가 8,192개의 특징을 발굴한다고 해서, 그 특징들이 모두 *실제 예측에 쓰인다*는 보장이 없다. 예를 들어:
- "계절성(seasonality)" 특징이 많이 활성화되더라도, 그것을 제거했을 때 예측이 나빠지지 않는다면 — 그 특징은 기술적(descriptive) 레이블일 뿐, 인과적(causal)이지 않다.
- 반대로, 의미를 모르는 특징이더라도 제거했을 때 예측이 크게 나빠지면 — 그 특징은 인과적으로 중요하다.

따라서 SAE 특징의 "중요성"을 주장하려면 **개입(intervention)을 통한 인과적 검증**이 필수다.

---

## 단일 특징 절제 (Single-Feature Ablation)

### 프로토콜

```
1. Chronos-T5에 시계열 컨텍스트 입력
2. 목표 추출점(예: encoder.block.11)에서 활성화 추출
3. 활성화를 SAE로 인코딩 → 희소 특징 벡터 f
4. 특정 특징 j의 계수를 0으로 설정: f_j ← 0
5. 수정된 f를 SAE 디코더로 역변환 → 수정된 활성화 x̂_ablated
6. x̂_ablated를 Chronos 파이프라인에 주입 (원래 x 대신)
7. 예측 분포 생성 → CRPS 계산
8. ΔCRPS_j = CRPS_ablated - CRPS_original 측정
```

### 인과 기여도 공식

$$\Delta\text{CRPS}_j = \text{CRPS}_{\text{ablated}(j)} - \text{CRPS}_{\text{original}}$$

**기호 뜻**:
- $\text{CRPS}_{\text{ablated}(j)}$: 특징 $j$를 제거한 후 Chronos가 출력한 예측 분포의 CRPS
- $\text{CRPS}_{\text{original}}$: 변형 없이 원래 예측한 CRPS
- $\Delta\text{CRPS}_j > 0$: 특징 $j$를 제거하면 예측이 나빠짐 → $j$가 인과적으로 기여
- $\Delta\text{CRPS}_j < 0$: 특징 $j$를 제거하면 오히려 예측이 좋아짐 → $j$가 방해하고 있었음

**일상 비유**: 오케스트라에서 악기 하나를 소거(mute)했을 때 음악이 더 좋아지면 그 악기는 잡음을 내고 있었던 것이다.

**왜 이 형태인가**: 단순히 "큰 SAE 계수 = 중요한 특징"이라고 가정할 수도 있지만, 이는 상관성을 인과성으로 혼동하는 오류다. ΔCRPS는 직접 개입으로 측정하므로 교란 변수 문제가 없다.

**조심할 점**: ΔCRPS는 하나의 특징을 독립적으로 제거할 때의 효과다. 여러 특징 사이에 상호작용이 있다면(하나를 제거해도 다른 특징이 보완), 단일 절제가 과소평가될 수 있다.

## 특징 선택: 디코더 노름(Decoder-Norm) 랭킹

392회의 절제 실험에서 어떤 특징을 선택했는가? 전체 8,192개 특징을 모두 절제하는 것은 계산 비용이 너무 크므로, **디코더 노름**으로 상위 64개를 선택했다.

$$\text{rank}(j) = \|\mathbf{w}_{\text{dec},j}\|_2$$

**기호 뜻**:
- $\mathbf{w}_{\text{dec},j} \in \mathbb{R}^{d_{\text{model}}}$: SAE 디코더 행렬의 $j$번째 열 벡터 (이 특징이 활성화될 때 원본 공간에 얼마나 큰 방향을 추가하는가)
- $\|\cdot\|_2$: 유클리드 노름 (벡터의 "크기")

**직관**: 디코더 노름이 큰 특징은 모델 내부 표현에 큰 영향을 줄 가능성이 높다. 이것은 인과 중요도의 proxy다. 단, proxy이므로 중요하지 않은 특징이 선택되거나, 중요한 특징이 누락될 수 있다.

**결과**: 레이어당 64개 × 6개 추출점 × (일부 중복 제거) = 392회

## 점진적 절제 (Progressive Ablation)

단일 특징 절제 외에, **점진적으로 여러 특징을 쌓아가며 제거**하는 실험도 수행했다.

### 프로토콜

디코더 노름 순서(내림차순)로 특징들을 순차적으로 제거하며 CRPS를 체크포인트에서 측정:

체크포인트: n ∈ {1, 2, 4, 8, 16, 32, 64} 개 제거

### 실제 결과 (GitHub raw data에서 확인)

**encoder.block.11 (중간 인코더):**

| 절제 수 | CRPS | MAE | MSE |
|---------|------|-----|-----|
| 0 (baseline) | 1.392 | — | — |
| 1 | 2.606 | 2.915 | 29.006 |
| 2 | 5.641 | 8.216 | 126.034 |
| 4 | 7.602 | 10.837 | 199.581 |
| 8 | 9.735 | 10.976 | 263.006 |
| 16 | 10.311 | 12.846 | 254.834 |
| 32 | 25.172 | 25.478 | 1,524.652 |
| 64 | 25.315 | 25.621 | 1,553.365 |

→ CRPS 1.392 → 25.315 (+ 22.71배 악화). **1개만 제거해도 CRPS가 2배 이상 증가.** 중간 인코더의 치명적 역할 확인.

**encoder.block.23 (최종 인코더):**

| 절제 수 | CRPS | MAE | MSE |
|---------|------|-----|-----|
| 0 (baseline) | 1.372 | — | — |
| 1 | 3.620 | 4.005 | 48.021 |
| 2 | 3.090 | 3.914 | 35.547 |
| 4 | 3.004 | 3.725 | 36.123 |
| 8 | 2.866 | 3.272 | 33.093 |
| 16 | 2.980 | 3.398 | 35.864 |
| 32 | 2.849 | 3.180 | 33.227 |
| 64 | 2.734 | 3.156 | 30.338 |

→ 64개 제거 후 CRPS: 2.734 (원래 1.372보다 높지만, 32개 제거 후 2.849보다는 낮음). 단, **1개 제거할 때는 CRPS가 3.620으로 크게 오르지만 이후 제거하면서 계속 하락하여 64개 제거 시 2.734로 떨어짐** → 전반적 순 변화 = 1.372 → 2.734 (약 2배), 하지만 중간 인코더(22.71배)와 비교하면 훨씬 약함.

> 주목: 초기(1개) 제거 후 CRPS가 오르다가, 이후 계속 제거하면서 오히려 내려가는 비단조적(non-monotonic) 패턴 — 특징들 간 복잡한 상호작용 또는 노이즈 상쇄 효과를 시사.

**encoder.block.5 (초기 인코더):**

| 절제 수 | CRPS |
|---------|------|
| 0 | 1.336 |
| 1 | 7.055 |
| 4 | 15.415 |
| 8 | 10.226 |
| 64 | 21.541 |

→ 최초 1개 제거에서 급격한 악화 (1.336 → 7.055), 이후 변동성이 큼. 중간 인코더보다는 덜 치명적이나 상당한 영향.

## 실험 설정 상세

- **데이터**: ETT (Electricity Transformer Temperature) 벤치마크 — ETTh1, ETTh2, ETTm1, ETTm2
- **컨텍스트 윈도우**: stride = prediction_length, 최대 256 윈도우 (빠른 실행 모드)
- **예측 길이**: prediction_length = 64
- **샘플 수**: num_samples = 4 (Chronos의 확률적 예측)
- **배치 크기**: batch_size = 32

*주의: "ultra-fast ablation mode"(256 윈도우, 4 샘플)를 사용했으므로, 전체 ETT 데이터를 사용한 exhaustive 실험 결과와 다소 다를 수 있다. 이는 논문 자체에서 인정된 한계다.*
