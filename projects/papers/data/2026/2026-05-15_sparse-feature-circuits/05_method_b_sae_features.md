# 05b 방법론 — SAE 특징 추출

**배경 사다리**: ① "autoencoder"는 x → encoder → z → decoder → x'로, z가 x의 압축 표현이라는 것; ② "ReLU(x) = max(0, x)"는 음수를 전부 0으로 만드는 함수라는 것; ③ "L1 노름"은 벡터 성분의 절댓값 합으로, 희소성을 유도하는 정규화 항이라는 것만 알면 된다.

---

## SAE가 필요한 이유: 중첩(Superposition) 문제

신경망 레이어의 활성화 벡터 $\mathbf{x} \in \mathbb{R}^d$는 겉으로 보면 $d$차원 공간의 한 점이다. 그런데 Elhage et al. 2022의 중첩 이론은 이 $d$차원이 실제로 훨씬 많은 개념을 담고 있다고 말한다 — 비직교(non-orthogonal)하게 중첩되어 있어서. 뉴런 하나가 여러 개념을 동시에 표현하는 이유다.

SAE는 이 "중첩된 표현"을 **더 고차원의 희소 공간**으로 풀어내는 도구다. $d$차원 → $m$차원 ($m \gg d$)으로 확장하되, 어느 시점에서든 $m$개 성분 중 소수만 활성화(0이 아님)되도록 훈련한다. 이렇게 하면 각 비0 성분 = 하나의 모노시맨틱 개념이 된다.

---

## SAE 구조와 손실 함수

SAE는 인코더 $f$와 디코더 $\hat{x}$로 구성된다.

**인코더**:
$$\mathbf{f}(\mathbf{x}) = \text{ReLU}(W_e(\mathbf{x} - \mathbf{b}_d) + \mathbf{b}_e)$$

- $\mathbf{x} \in \mathbb{R}^d$: 원래 모델의 활성화 벡터 (입력)
- $W_e \in \mathbb{R}^{m \times d}$: 인코더 가중치 행렬
- $\mathbf{b}_e \in \mathbb{R}^m$: 인코더 편향
- $\mathbf{b}_d \in \mathbb{R}^d$: 디코더 편향 (사전 제거)
- $\mathbf{f}(\mathbf{x}) \in \mathbb{R}^m$: 특징 활성화 벡터 (대부분 0)

**기호 뜻**: $\mathbf{f}(\mathbf{x})$의 $i$번째 성분 $f_i(\mathbf{x})$는 "입력 $\mathbf{x}$에 $i$번째 특징이 얼마나 나타나는가"를 나타내는 실수. ReLU 때문에 음수는 0.

**일상 비유**: 음악 스펙트럼 분석과 같다. 복잡한 음악 신호(x)를 수천 개의 순음(특징) 강도로 분해하면, 어느 순간에는 몇 개 음만 동시에 울린다(희소). 각 순음은 "C4 주파수" 같은 식으로 이름 붙이기 쉽다.

**디코더**:
$$\hat{\mathbf{x}} = W_d \mathbf{f}(\mathbf{x}) + \mathbf{b}_d$$

- $W_d \in \mathbb{R}^{d \times m}$: 디코더 가중치 (각 열이 하나의 특징 방향 벡터)
- $\hat{\mathbf{x}} \in \mathbb{R}^d$: 복원된 활성화

**손실 함수**:
$$\mathcal{L}(\mathbf{x}) = \underbrace{\|\mathbf{x} - \hat{\mathbf{x}}\|_2^2}_{\text{재건 손실}} + \lambda \underbrace{\|\mathbf{f}(\mathbf{x})\|_1}_{\text{희소성 페널티}}$$

**기호 뜻**:
- 첫 항: 복원 오차의 제곱합 — SAE가 원래 신호를 잘 복원해야 함
- 둘째 항: 특징 활성화의 L1 노름 — 대부분의 특징을 0으로 유지하도록 강제
- $\lambda$: 두 항의 균형을 조절하는 하이퍼파라미터 (정규화 강도)

**왜 이 형태**: 재건 손실만 있으면 SAE는 그냥 항등(identity) 매핑을 학습한다. L1 페널티만 있으면 아무것도 활성화 안 하는 것이 최적이다. 둘을 같이 써야 "최소한으로 필요한 특징들만 써서 잘 복원하라"는 압력이 생긴다.

**조심할 점**: 이 구조에서 $W_d$의 각 열은 단위 벡터로 정규화된다 (norm=1). 그래야 $f_i$의 크기가 "그 특징의 존재 강도"를 의미 있게 나타낸다. 정규화하지 않으면 하나의 특징이 큰 가중치로 모든 것을 설명할 수 있다(degeneracy).

## SFC가 사용하는 SAE

SFC(Marks et al. 2024)는 Pythia-70M(약 7천만 파라미터 언어 모델)에 대해 사전 학습된 SAE를 사용한다.

- **모델**: Pythia-70M (EleutherAI — 공개 모델)
- **SAE**: Hugging Face에서 다운로드 가능한 체크포인트 (p70d-sm 시리즈)
- **확장 비율**: 정확한 m/d 비율은 원문에 수치 미보고
- **레이어 커버리지**: 각 Transformer 레이어의 residual stream / MLP 출력에 SAE 적용

**왜 Pythia-70M인가**: (1) 소형 모델이라 회로 발견 계산 비용이 낮다. (2) EleutherAI의 공개 모델로 재현 가능성이 높다. (3) 이미 커뮤니티에서 SAE가 학습되어 있었다.

## 특징 해석 가능성 확인

Bricken et al. 2023 (Towards Monosemanticity)에서 도입된 SAE가 실제로 모노시맨틱 특징을 추출한다는 증거가 있다. SFC는 이 사실을 전제로 사용한다. 주요 증거 방법(Bricken 기반):

1. **자동 해석가능성(Automated interpretability)**: 특징을 가장 강하게 활성화하는 텍스트 예시들을 클러스터링하여 설명 라벨 생성
2. **인간 판단**: 임의 표본의 특징을 인간이 직접 보고 "이게 무슨 개념인가" 라벨링

SFC에서는 특히 SVA 회로와 SHIFT 실험에서 인간이 각 특징을 확인하고 명명한다 — 예: "복수 명사 감지", "성별 관련 직업어", "관계절 시작" 등.

## 다른 접근이라면

| 대안 | 문제점 |
|------|--------|
| 뉴런 단위 그대로 회로 분석 (ACDC 방식) | 뉴런 다의미성 — 회로 노드가 여러 개념을 섞음 |
| Linear probes (선형 탐침) | 인과성 없음 — "정보가 있다"는 것과 "그 정보를 사용한다"는 것이 다름 |
| Dictionary learning without sparsity | 희소성 없이는 특징 분리 안 됨 (overcomplete basis가 너무 많은 자유도) |
| PCA/SVD 분해 | 직교 기저 → 음수 없음 → 희소성 달성 어려움 → 모노시맨틱 특징 X |

**이 섹션 핵심 요약**: SAE는 모델 활성화를 재건 손실 + L1 희소성 압력으로 모노시맨틱 특징 벡터로 분해한다. 이 특징들이 SFC 회로의 인간-해석-가능한 노드가 된다.
