# 05e 방법론 — SHIFT: 희소 특징 트리밍으로 모델 편집

**배경 사다리**: ① "ablation"은 특정 구성요소를 끄거나 0으로 고정하는 개입 실험이라는 것; ② "OOD(Out-of-Distribution)"는 훈련 데이터와 다른 분포의 테스트 데이터라는 것; ③ "편향(bias)"은 모델이 과제와 무관한 특징(예: 성별)을 사용해 예측하는 문제라는 것.

---

## SHIFT란 무엇인가

**SHIFT (Sparse Human-Interpretable Feature Trimming)**는 SFC의 응용 기법으로, 희소 특징 회로에서 인간이 "이것은 과제와 무관하다"고 판단한 특징들을 제거(ablation)하여 모델의 OOD 일반화를 개선하는 외과적 편집 방법이다.

"Trimming(트리밍)"이라는 이름이 핵심이다 — 가위치기처럼 특정 부분만 정밀하게 제거한다. 전체 파인튜닝이나 재학습 없이, 해석 가능한 특징 단위로 모델 동작을 수정한다.

---

## Bias in Bios: 실험 맥락

Bias in Bios (직업 분류 데이터셋):
- 입력: 개인 소개문(biography) 텍스트
- 출력: 직업 분류 (의사, 간호사, 교수 등)
- 문제: 텍스트 안의 이름이나 대명사가 성별 정보를 담고 있고, 사회적 편향으로 인해 일부 직업에서 특정 성별이 과대/과소 대표됨. 모델이 직업 예측 시 성별 단서를 사용할 수 있음.

**비편향 기준**: 이름을 바꿔도(남성 이름 → 여성 이름) 직업 예측이 바뀌지 않아야 한다. OOD 테스트: 훈련 시 성별 분포와 다른 테스트 세트에서 성별 의존도를 측정.

---

## SHIFT 절차

```
1. 직업 분류기 구축
   Pythia-70M 위에 선형 분류 헤드 추가
   → Bias in Bios 훈련 데이터로 파인튜닝

2. 희소 특징 회로 발견
   행동 B = "직업 분류 결정"에 대해 SFC 발견
   → 회로에 포함된 특징들 목록 획득

3. 성별 관련 특징 식별
   각 특징에 대해:
   - 어떤 입력에서 활성화되는가? (자동 해석가능성)
   - 성별 정보(이름, 대명사, he/she 등)와 상관되는가? (인간 판단)
   → 성별 관련 특징 집합 S 식별

4. SHIFT 적용 (ablation)
   추론 시 S에 속하는 특징들의 활성화를 0 또는 baseline으로 고정

5. OOD 일반화 측정
   성별 반전 테스트셋(이름을 바꾼 버전)에서 직업 분류 일관성 측정
   → 성별 의존도가 얼마나 감소했는가
```

---

## SHIFT의 핵심 수식

SHIFT에서 $t$번째 토큰에서의 특징 $f_i$ ablation은 다음과 같다:

$$f_i^{\text{SHIFT}}(\mathbf{x}) = \begin{cases} 0 & \text{if } i \in S \\ f_i(\mathbf{x}) & \text{if } i \notin S \end{cases}$$

**기호 뜻**:
- $S$: 인간이 "과제와 무관하다"고 표시한 특징 인덱스 집합
- $f_i(\mathbf{x})$: 원래 특징 활성화
- $f_i^{\text{SHIFT}}(\mathbf{x})$: 트리밍 후 특징 활성화

**일상 비유**: 카메라에서 색상 정보(빨강/파랑/초록 채널)를 분리해, "그림자 색상" 채널만 0으로 설정해 명도 왜곡을 없애는 것과 같다. 다른 채널(형태, 질감 등)은 그대로 유지.

**왜 ablation이 0인가**: 0은 "이 특징이 활성화되지 않은 상태"에 해당한다. SAE 특징은 ReLU를 통과하므로 비활성 상태가 자연스럽게 0이다. 다른 ablation 기준(랜덤 노이즈, 평균 활성화)을 쓸 수도 있지만 0이 가장 해석이 명확하다.

## SHIFT 결과 (검색 확인)

검색 스니펫에서 인용:
> "applying SHIFT on the model almost completely removes dependence on the unintended signal (gender) to make classifications."

이 결과의 의의:
1. **인과적 편향 제거**: 단순히 정보를 가리는 것(입력에서 이름 삭제)이 아니라, 모델 **내부**에서 성별 정보가 분류 결정에 영향을 주는 인과 경로를 차단.
2. **외과적 정밀도**: 전체 파인튜닝 대비 직업 분류 성능(정확도)의 손실이 최소화된다. 불필요한 부작용이 적다.
3. **해석 가능성의 실용적 가치**: 특징이 인간에게 해석 가능하기 때문에, "이 특징이 성별 관련"이라는 판단 자체가 가능하다. 뉴런 기반이었다면 이런 선택적 ablation은 불가능.

**정확한 수치 (정확도 변화, OOD 개선 폭)**: 원문에 수치 미보고 (원문 표/그림 직접 확인 불가).

---

## SHIFT vs 기존 편향 완화 방법 비교

| 방법 | 접근 | 장점 | 단점 |
|------|------|------|------|
| 재학습 (adversarial debiasing) | 훈련 목표 수정 | 강력한 편향 제거 | 계산 비용, 성능 손실 위험 |
| 입력 수정 (counterfactual augmentation) | 학습 데이터 수정 | 간단 | 모든 편향 패턴 커버 어려움 |
| 표현 적대적 학습 | 인코더 수준 제거 | 포괄적 | 의도치 않은 정보 손실 |
| **SHIFT** | 인과 특징 ablation | 해석 가능, 정밀, 무재학습 | SAE 품질 의존, 인간 판단 필요 |

---

## 범위와 한계

SHIFT는 강력하지만 다음을 요구한다:
1. **SAE의 특징이 실제로 해석 가능해야 한다** — SAE 품질이 낮으면 성별 특징을 정확히 식별할 수 없다.
2. **인간 판단 필요** — "어떤 특징이 과제 무관인가"는 자동화되지 않는다. 확장성 병목.
3. **모든 편향 경로를 커버했는가 보장 없음** — 식별한 특징 집합 S 밖에도 성별 정보가 숨어있을 수 있다.
4. **다른 과제로의 일반화 미검증** — Bias in Bios 특정 편향에 대한 결과이며, 다른 유형의 편향에도 효과적인지 불명확.

**이 섹션 핵심 요약**: SHIFT는 희소 특징 회로에서 인간이 "과제 무관"으로 판단한 특징들을 ablation하여 성별 편향 같은 원치 않는 신호 의존도를 거의 완전히 제거한다. 모델 재학습 없이 해석 가능한 특징 단위로 정밀하게 동작을 수정하는 실용적 응용이다.
