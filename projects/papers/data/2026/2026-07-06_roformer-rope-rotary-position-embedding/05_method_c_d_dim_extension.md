# 05.c 방법론 — d 차원 확장과 주파수 스펙트럼

## 왜 d 차원 확장이 필요한가

2 차원 유도 (`05_method_b`) 는 우아하지만 실제 트랜스포머의 query/key 는 보통 $d = 64$ 혹은 $d = 128$ (head 당). 2 차원 하나만으로는 표현력이 부족하고, 회전 주파수가 한 개뿐이라 다양한 상대거리 스케일 (짧은 거리, 중간 거리, 긴 거리) 을 동시에 담을 수 없다. 저자는 이를 **d 를 2 씩 쪼갠 d/2 개의 부분공간에 서로 다른 주파수의 회전을 부여**하는 방식으로 해결한다.

## 배경 사다리

- 블록대각 행렬은 대각선 방향으로 작은 정방 행렬 블록들이 붙어 있고 나머지는 모두 0 인 행렬. 각 블록은 서로 독립적으로 작용.
- 블록대각 행렬끼리의 곱과 전치는 블록별로 따로 이루어진다.
- 서로 다른 주파수의 사인·코사인 신호들을 겹쳐 놓으면 (푸리에 급수 감각) 다양한 파장 성분을 동시에 표현할 수 있다.

## d 차원 회전 행렬의 형태

$d$ 차원 벡터를 d/2 개의 2 차원 블록으로 나누고, 블록 $i$ 에 각도 $m\theta_i$ 회전을 부여:

$$R^d_{\Theta,m} = \begin{pmatrix}
R(m\theta_1) & 0 & \cdots & 0 \\
0 & R(m\theta_2) & \cdots & 0 \\
\vdots & \vdots & \ddots & \vdots \\
0 & 0 & \cdots & R(m\theta_{d/2})
\end{pmatrix} \tag{8}$$

- **기호 뜻**: $R(m\theta_i)$ 는 각도 $m\theta_i$ 의 2 차원 회전 행렬 (식 (5)). $\Theta = \{\theta_1, \theta_2, \ldots, \theta_{d/2}\}$ 는 주파수 스펙트럼.
- **일상 비유**: 한 벡터가 여러 층 (레이어) 으로 쪼개져 각 층마다 다른 속도의 회전 팽이가 도는 그림. 한 층은 매우 빠르게 (짧은 파장) 돌고, 다른 층은 느리게 (긴 파장) 돈다.
- **왜 이 형태**: 블록대각이 아닌 일반 orthogonal 이었다면 회전 각도의 가법성 (그리고 상대위치 항등식) 이 깨진다. 블록대각이면 각 블록이 독립적으로 상대각도 회전을 유지.
- **조심할 점**: 블록 간 정보 교류는 오직 이 회전 이전 단계 (embedding $x_m$ 이 원본 $d$ 차원인 채로 blending) 및 이후 단계 (FFN 등) 에서만 이루어진다. 회전 단계 자체는 블록별 독립.

## 주파수 스펙트럼의 선택

저자는 sinusoidal PE 의 유산을 그대로 따와:

$$\theta_i = 10000^{-2(i-1)/d}, \quad i = 1, 2, \ldots, d/2 \tag{9}$$

- **기호 뜻**: $i$ 가 커질수록 $\theta_i$ 는 지수적으로 작아진다. $i=1$ 이면 $\theta_1 = 10000^0 = 1$ 로 가장 빠른 회전 (짧은 파장), $i=d/2$ 면 $\theta_{d/2} = 10000^{-(d-2)/d} \approx 10^{-4}$ 로 가장 느린 회전 (긴 파장).
- **일상 비유**: 여러 크기의 시계태엽 — 초침, 분침, 시침이 겹쳐진 것. 초침은 빠르게 돌아 짧은 시간의 상대위치 정보를 담고, 시침은 느리게 돌아 긴 시간의 상대위치 정보를 담는다.
- **왜 이 형태**: 여러 스케일의 상대거리에 대해 감쇠 곡선이 서로 다른 주파수 감쇠를 하여, 전체 감쇠 곡선이 자연스럽게 나온다. sinusoidal PE 의 스펙트럼 선택이 그대로 물려받아진 것은 (i) 이론적 근거가 아니라 관례, (ii) 이 값이 실제로 잘 작동한다는 실험적 성공 때문.
- **조심할 점**: 이 값 자체가 **hyperparameter** 라 데이터에 맞춰 조정 안 됨. 최근 (2023-2025) 연구들 (NTK-aware scaling, YaRN, LongRoPE, Frontiers 2025 fixed-θ 분석, arXiv:2602.10959 phase modulation bounds) 은 이 스펙트럼을 늘리거나 학습 가능하게 만들어 성능을 크게 개선. 즉 원 논문의 이 선택은 **미완성된 결정**.

## d 차원 상대위치 항등식

식 (8) 을 attention 내적에 대입:

$$q_m^T k_n = (R^d_{\Theta,m} W_q x_m)^T (R^d_{\Theta,n} W_k x_n)$$

블록대각의 곱과 전치가 블록별 이므로:

$$q_m^T k_n = (W_q x_m)^T R^d_{\Theta,n-m} (W_k x_n) \tag{10}$$

- **기호 뜻**: 최종 attention 로짓이 원본 vec projection $W_q x_m, W_k x_n$ 과 **상대위치 회전** $R^d_{\Theta,n-m}$ 만으로 표현.
- **일상 비유**: "d 차원 벡터의 각 부분공간마다 별도로 상대각도 회전이 남음. 전체 로짓은 이 부분공간별 (블록별) 기여의 합" — 초침·분침·시침이 각각 상대 시간 차이를 담고 최종 합이 됨.
- **왜 이 형태**: 블록별 독립성이 없으면 (일반 회전) 이 항등식이 안 됨. RoPE 는 블록대각을 통해 항등식을 유지.
- **조심할 점**: 이 항등식은 이론적으로 완결이나, 실제 attention 은 softmax 후 정규화되므로 로짓 스케일이 감쇠 성질로 재해석될 필요.

## 감쇠 성질 (long-range decay) 의 이론적 근거

저자는 랜덤 벡터 가정 하 다음 상한을 유도:

$$\mathbb{E}[q_m^T k_n]| \leq \sum_{i=1}^{d/2} |S_{i,m-n}|,$$

여기서 $S_{i,\ell} = \sum_{j=0}^{\ell-1} h_i e^{i j \theta_i}$ 는 특정 부분합. Abel 변환·부분합 정리 (summation by parts) 를 통해 $|S_{i,\ell}| \leq \frac{2 \sup_j |h_i|}{|1 - e^{i\theta_i}|}$ 형태로 상한이 지어지고, 이 상한이 $|\ell|$ 에 대해 감쇠하는 패턴을 저자는 그래프로 시각화 (원문 Figure — 정확한 번호는 본문 PDF 차단으로 미확인).

- **직관**: 다양한 주파수 (다른 속도의 회전) 가 함께 걸리면, 상대거리 $|m-n|$ 이 커질수록 여러 파장이 서로 다른 위상에서 만나 상쇄 (destructive interference). 초침·분침·시침이 시간이 지나면 결국 서로 다른 곳을 가리켜 total 이 흐릿해지는 것과 유사.
- **한계**: 이 상한은 랜덤 벡터 가정에서만 성립. 실제 학습된 attention 은 특정 방향에 집중해 있을 수 있어 이 상한이 tight 하지 않음. 이는 §7 에서 자세히.

## 구현 상 트릭 — 실제로는 행렬 곱을 안 쓴다

식 (8) 의 회전 행렬 $R^d_{\Theta,m}$ 은 대부분 0 이라 sparse. 저자는 실제 구현에서 이를 회전 행렬 곱이 아니라 **element-wise multiplication + 짝수/홀수 index 스왑** 로 구현:

주어진 $x \in \mathbb{R}^d$ 에 대해:
```
x_rot[2i]     =  x[2i] * cos(m*θ_i) - x[2i+1] * sin(m*θ_i)
x_rot[2i+1]   =  x[2i] * sin(m*θ_i) + x[2i+1] * cos(m*θ_i)
```

이는 $O(d)$ 연산이며 GPU 에서 굉장히 효율적. HuggingFace `transformers` 의 `RoFormerModel`, LLaMA 의 `apply_rotary_pos_emb` 함수가 이 형태를 그대로 채택.

- **왜 이 형태**: 실제 계산에서 회전 행렬을 명시적으로 만들면 메모리·연산 낭비. Element-wise 로 쪼개면 sparse 구조를 그대로 활용.
- **조심할 점**: 코드에서 실수하기 쉬운 부분은 짝수/홀수 index 배치 규칙 (interleaved vs half-split). 원 논문은 interleaved ($x_0, x_1$ 이 한 쌍, $x_2, x_3$ 이 한 쌍), 이후 GPT-J·LLaMA 구현은 half-split (앞 반과 뒤 반이 한 쌍) 을 채택해 관례가 갈렸다. 두 방식은 수학적으로 동치이나 세부 index 매핑이 다르므로 checkpoint 이식 시 주의.

## d 차원 확장의 요약 한 문장

**"2 차원 회전의 우아함을 d 차원에서 유지하려면 블록대각으로 쪼갠 뒤 각 블록에 다른 주파수를 걸어라 — sinusoidal 스펙트럼 그대로. 결과는 element-wise 곱셈으로 O(d) 구현."**
