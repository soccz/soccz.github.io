# 4. 방법론 해부 (A) — 전체 흐름의 큰 그림

## 배경 사다리

이 절을 이해하려면 두 가지만 알면 된다. ① **"패널(panel) 모형"** 이란 모든 종목에 **하나의 동일한 파라미터 집합**을 적용하는 모형이다 — 종목별로 다른 모델을 학습하는 게 아니라, 1만 개 종목이 같은 함수를 공유한다. ② **"지도학습(supervised learning)"** 은 입력-정답 쌍을 보여 주며 함수를 맞춰 가는 것이고, 여기서 정답은 "다음 기간 수익률이 양수였나?"라는 O/X다.

---

## 파이프라인 다이어그램 (지문)

```
[1] 원시 데이터 (CRSP 일별)
    종목 i, 날짜 t의 시가·고가·저가·종가·거래량
              │
              │  ① 수익률로 가격 재구성 (§III.A)
              │     p_{t+1} = (1 + RET_{t+1}) p_t,  창 첫날 종가 = 1
              ▼
[2] 정규화된 가격 경로 (분할·배당 효과 제거)
              │
              │  ② 이미징 (§I) — 여기서 두 가지 일이 동시에 일어난다
              │     (a) 기하학화: OHLC 바 → 픽셀 (하루 = 가로 3px)
              │     (b) 재척도화: 창 내 max/min → 이미지 상/하단
              ▼
[3] 흑백 픽셀 행렬  (5일 → 15px 폭 / 20일 → 60px / 60일 → 180px)
    배경 = 검정(0,0,0),  객체 = 흰색
    하단 1/5 = 거래량 바,  상단 4/5 = OHLC + 이동평균선
              │
              │  ③ CNN (§II.A, Appendix)
              │     [합성곱(5×3) → 배치정규화 → leaky ReLU → 최대풀링(2×1)] × K
              │     K = 2 (5일) / 3 (20일) / 4 (60일)
              │     채널 64 → 128 → 256 → 512
              ▼
[4] 평탄화(flatten) → 완전연결층 → softmax
              │
              ▼
[5] ŷ = P(다음 h일 수익률 > 0),  h ∈ {5, 20, 60}
              │
              │  ④ 횡단면 10분위 정렬 (§III.A)
              ▼
[6] H-L 롱숏 포트폴리오 → 샤프 비율로 성능 측정
```

**모델이 9개인 이유**: 이미지 길이 3종(5·20·60일) × 예측 지평 3종(5·20·60일) = **9개 모델을 각각 독립적으로 학습**한다(§III.A, p.3206). 표기법은 `Ix/Ry` — x일 이미지로 y일 후속 보유기간 수익률을 예측. 그리고 CNN 최적화가 확률적이므로 **각 설정마다 5회 독립 재학습 후 예측을 평균**한다("for each model configuration we independently retrain the CNN five times and average the forecasts", p.3206 — Gu·Kelly·Xiu 2020의 관행을 따름).

## 이 설계의 핵심 발상 전환 세 가지

### 전환 1 — 회귀 문제를 분류 문제로 바꿨다

수익률 값을 직접 예측하지 않고 **부호만** 예측한다. $y = 1$ (후속 수익률 > 0), $y = 0$ (그 외). 왜 이게 유리한가?

- **금융 수익률은 신호대잡음비(SNR)가 극도로 낮다.** 일별 수익률의 예측 가능한 성분은 표준편차의 몇 %에 불과하다. 값을 맞히려는 회귀는 대부분의 학습 신호를 "예측 불가능한 잡음의 크기"를 맞히는 데 낭비한다.
- **부호는 두꺼운 꼬리(fat tail)에 강건하다.** 수익률 분포에는 극단값이 많다. MSE(평균제곱오차)를 쓰면 단 몇 개의 극단 관측치가 손실 전체를 지배해 모델이 그 몇 개에 맞춰진다. 부호 레이블은 극단값을 다른 관측치와 동일하게 취급한다.
- **출력이 확률이라 정렬(ranking)에 바로 쓰인다.** 포트폴리오 구성에 필요한 것은 수익률의 크기가 아니라 **종목 간 순서**다. 확률 출력은 순서 그대로 10분위 정렬에 투입된다.

**조심할 점**: 부호만 쓰면 **크기 정보를 버린다.** "확실히 +0.1% 오를 종목"과 "불확실하게 +5% 오를 종목"이 같은 레이블을 받는다. 실제로 이 대가가 Table I에 보인다 — 동일가중 샤프가 7.15인데 수익 자체는 주당 0.83%로, **작고 확실한 승리를 대량으로 쌓는** 프로필이다. 큰 수익을 노리는 전략과는 성격이 다르다.

### 전환 2 — 특성 공학(feature engineering)을 모델 내부로 밀어 넣었다

기존 자산가격 ML(Gu·Kelly·Xiu 2020 포함)의 입력은 **사람이 정의한 특성 벡터**였다 — 모멘텀, 장부가/시가 비율, 규모 등 수백 개. 본 논문의 입력은 **원시 픽셀 행렬**이다. 이 교체가 무엇을 바꾸는가:

- 사람이 상상하지 못한 조합이 발견 가능 영역에 들어온다.
- **동시에** 모델이 배운 것을 사람이 읽어낼 수 없게 된다 → 이 대가를 치르기 때문에 §IV 전체(해석 시도)가 필요해진다.

원문 §IV.B(p.3223)가 이 교환을 자각하고 있다: 로지스틱 근사를 하려면 "we must also decide how to transform not only close prices, but also intraday high and low prices, open prices, price moving averages, and volumes to make them comparable in the cross section" — 즉 **CNN을 해석하려는 순간 저자들 자신이 사람-특성공학의 부담으로 되돌아간다.** 이 자기-관찰이 논문에서 가장 지적으로 솔직한 대목 중 하나다.

### 전환 3 — 표현(representation)을 결과의 일부로 취급했다

이 논문이 다른 "TS를 2D로" 논문들과 갈라지는 지점이다. 대부분의 논문은 표현을 **주어진 것**으로 두고 모델을 비교한다. 본 논문은 §IV.B에서 **표현 자체를 실험 변수로 승격**시켜 모델 3종 × 척도 3종 격자(Table IX)를 돌린다. 그래서 "표현의 어느 성분이 이득의 원천인가"를 분해할 수 있었고, 그 결과 **자기 제목을 반박하는 발견**(척도 ≫ 2D 기하)에 도달했다.

## "왜 이미지인가"의 네 가지 논거 — 그리고 각각의 사후 평가

원문 §서론(p.3195–3196)과 §II.B가 네 개의 논거를 제시한다. Table IX를 읽은 뒤 각 논거를 재평가하면 이렇게 갈린다.

| # | 저자 논거 (원문 근거) | 사후 평가 |
|---|---|---|
| 1 | **CNN 아키텍처가 이미지용으로 정교화되어 있으니 이미지로 주면 그 이점을 누린다** (p.3195) | ⚠️ **약화됨.** Table IX에서 1D CNN이 동등 이상 → 2D 아키텍처의 성숙도가 이득의 원천이 아니다 |
| 2 | **2D 필터가 가격 곡선 간 비선형 공간 관계를 잡는다** (§II.B + Figure 4: 3×2 필터가 무변화/소폭상승/대폭상승을 별개 특성으로 binning) | ⚠️ **가장 약화됨.** 이론적으로 매력적이나 Table IX가 지지하지 않음. 게다가 이 binning 효과는 **픽셀 이산화**에 의존하므로 정보 손실과 표리관계 |
| 3 | **모든 자산의 데이터 이력을 비교 가능한 척도로 변환한다** (p.3195: "converts all assets' data histories into a comparable scale") | ✅ **결정적으로 확인됨.** Table IX 열 방향 분산이 이것을 지지. 저자 자신도 §서론(p.3196)에서 "A key component of image-based prediction is the implicit data scaling achieved by the image representation"라고 예고 |
| 4 | **기술적 트레이딩은 사람 인지가 시각적으로 정의·관찰하는 기하 형태에 의존하므로 그 매체를 재현해야 한다** (p.3196) | 🤔 **미검증.** 사람이 차트를 그렇게 읽는다는 것이 모델도 그렇게 읽어야 함을 함의하지는 않음. §IV.C(교과서 패턴 8/13이 역방향)는 오히려 **사람의 시각적 읽기가 틀렸다**는 방향의 증거 |

**주목할 점**: 저자들은 논거 3을 §서론에서 이미 "key component"라고 못 박았다. 즉 **저자들은 척도가 핵심임을 알고 있었다.** 다만 논문의 서사 구조(제목·초록·§I·§II가 모두 "이미지"를 앞세움)가 이 인식을 배경으로 밀어냈다. 이것은 은폐가 아니라 **프레이밍의 관성**이다.

## 핵심 한 문장 요약

> 이 논문의 방법론은 "가격 → 이미지 → CNN → 상승확률 → 10분위 롱숏"의 5단 파이프라인이지만, 성능을 만드는 실질적 연산은 두 번째 화살표 안에 숨어 있는 **min–max 재척도화** 한 줄이고, 나머지는 그 위에 얹힌 (교체 가능한) 함수 근사기다.
