# 10. 한 줄 판결

> **이 논문은 "시계열을 2D 이미지로 바꾸면 이긴다"의 결정적 증거가 아니라, 그 반대로 "이득의 대부분은 2D 기하가 아니라 이미지가 강제하는 min–max 재척도화에서 온다"는 것을 저자 자신의 Table IX로 폭로한 논문이다 — 그러므로 APF의 2D motif 축에는 '2D가 이긴다'의 근거가 아니라 1D 대조군을 반드시 세워야 한다는 반증 프로토콜로 핀을 꽂는다.**

---

## 판결의 근거 (3줄)

**첫째, 이 논문을 읽는 것과 인용만 하는 것의 결론이 정반대로 갈린다.** 제목·초록·서론이 전부 "이미지"를 앞세우지만, §IV.B Table IX는 동일한 min–max 척도만 먹인 1D CNN이 2D CNN과 동등하거나(5일 이미지 7.20 vs 7.15) **크게 우세함**(60일 이미지 7.85 vs 4.89, 시총가중 2.61 vs 1.44)을 보인다. 반면 모델을 고정하고 척도만 바꾸면 성능이 7.20에서 **−0.13으로 붕괴**한다. 저자들의 실제 결론 문장이 이를 정확히 인정한다 — "the key performance differentiator, be it for a 2D CNN, a 1D CNN, or a logistic model, is using an image representation"(p.3229).

**둘째, 그럼에도 이 논문은 방법론적으로 성실하다.** 회의론자(Sullivan·Timmermann·White)의 7,846개 룰 우주를 참조 분포로 재활용하고(주간 지평에서 0/7,846), 브라운 운동 플라시보를 세우고, 상위 500종목·거래비용·첫주 이후 분해로 반박을 선제 방어하고, **무엇보다 자기 헤드라인을 흔드는 대조 실험을 126개 셀의 가장 큰 표로 실었다.** 자기-유보도 정직하다 — 각주 7의 "LSTM이 더 나을 수 있고 이것은 예측 가능성의 하한이다", §IV의 "해석 시도는 인정하건대 불완전하다", §V.A의 "대형 시장에서는 전이 이득이 작거나 약간 음수다".

**셋째, 사용자에게 이 논문의 실질적 가치는 발견이 아니라 프로토콜이다.** `ts-as-2d` 계열 네 정거장(GAF/MTF·TimesNet·VisionTS·본 논문) 중 **1D 동일-척도 대조군을 세운 것은 본 논문뿐이고, 그 유일한 대조군이 2D의 우위를 지지하지 않았다.** APF가 "attention motif가 정보를 드러낸다"를 주장할 때 심사자가 던질 질문이 정확히 이것이므로, 이 논문의 Table IX 격자는 **APF가 선제적으로 통과해야 하는 관문의 설계도**다. 동시에 방어선도 함께 준다 — 본 논문의 2D는 가로=시간·세로=값인 **렌더링형(가짜 2D)** 이고, attention 행렬 $A[i,j]$ 는 위치 쌍을 담는 **관계형(진짜 2D)** 이므로 무손실 1D 환원이 불가능하다. 이 구분을 원고에 써 두면 "JKX가 2D 무용을 보였다"는 반박이 한 문장으로 차단된다.

## 지도 위의 핀 위치

```
`ts-as-2d` 태그 (주) + `fin-ts-dl` 태그 (보조)
   │
   ├─ [방법론 도구] Table IX 격자 → APF probe 실험의 필수 대조군 설계
   ├─ [방어 좌표]  렌더링형 2D vs 관계형 2D 구분 → APF novelty 방어
   ├─ [반면교사]   mechanistic 도구 전무 → APF의 causal intervention 단계가 곧 차별점
   ├─ [ML 학회 체크리스트] seed 분산·정확도·baseline 용량 미보고 → 내 원고에서 반드시 반대로
   └─ [필수 인용]  P1 ProTran-TFA의 finance venue 진출 시 방향예측 baseline
```

**한 줄 더**: 이 논문에서 가장 자주 오독되는 숫자는 샤프 7.15가 아니라 **OOS McFadden $R^2$ 0.73~1.39%** (Table VII·VIII)다. 샤프 7.15는 "잘 맞힌다"가 아니라 **거의 못 맞히지만 아주 약간의 우위를 수천 종목 × 950여 주에 걸쳐 반복 누적한 결과**다. 이 두 숫자를 함께 기억하는 것이 이 논문을 정확히 읽었다는 표시다.
