## 아이디어 1 — "2D 인코딩 이득의 성분 분해" (Representation Decomposition Audit)

### 동기 한 줄
본 논문은 **차트 렌더링**에 대해 "2D 기하 vs 척도 정규화"를 분해했고 후자가 주범임을 밝혔다([Claim 3](04_claims_b_claim3_5.md)). `ts-as-2d` 계열의 나머지 세 정거장 — GAF/MTF(2026-06-24 ✓), TimesNet(2026-05-13 ✓), VisionTS(2026-06-10 ✓) — 은 **아무도 이 분해를 하지 않았다**([08_lineage.md](08_lineage.md)의 계보 표). 그리고 그들의 2D는 본 논문의 2D와 **종류가 다르다**(관계형 vs 렌더링형). 이 실험은 그 격자를 채운다.

### 가설
**H1 (주가설)**: 2D 인코딩의 성능 이득은 인코딩 **종류**에 따라 다른 원천을 갖는다 — **렌더링형**(차트 이미지, VisionTS류 시각화)의 이득은 대부분 창내 정규화로 환원되어 1D 동일-척도 대조군이 동등 이상이지만, **관계형**(GAF/MTF, recurrence plot처럼 시점 쌍 $(i,j)$ 를 픽셀에 담는 것)의 이득은 1D 대조군을 유의하게 상회한다.

**H2 (부가설)**: min–max 창내 정규화의 이득은 두 성분 중 **변동성 정규화**(창 내 범위로 나누기)가 지배하고 **레벨 이동**(최소값 빼기)은 미미하다 — 배치정규화가 후자를 이미 흡수하므로.

### 데이터
`_profile.md` 기록 자산만 사용:
- **주 데이터**: UCR Archive (APF 자산으로 등재). 분류 태스크이므로 레이블이 깨끗하고, 다양한 도메인(모션·센서·심전도·이미지 윤곽 등)을 포함해 일반화 주장이 가능하다.
- **보조 데이터**: APF synthetic motif benchmark (trend/seasonal/regime/anomaly/freq drift) — **정답 구조를 아는 데이터**이므로 어느 인코딩이 어떤 구조를 잡는지 인과적으로 확인 가능.
- **금융 확인용**: GSPC/IXIC 2022-2024 (금융 backup 자산). 지수 수준이라 횡단면 정렬은 불가하고 방향 정확도만 나오지만, 본 논문 Table IX의 열 방향 패턴이 재현되는지 확인하는 최소 실증.

### 비교 조건 (2 × 3 × 3 격자 + 대조군)

**축 1 — 인코딩 종류 (2)**
| | 방식 | 2D의 성격 |
|---|---|---|
| R (렌더링형) | 시계열을 선/OHLC 바로 픽셀에 그림 (본 논문 방식) | 가로=시간, 세로=값 → **가짜 2D** |
| A (관계형) | GAF (Gramian Angular Field) 또는 recurrence plot — 시점 쌍 $(i,j)$ 를 픽셀에 인코딩 | **진짜 2D** |

**축 2 — 모델 (3)**: 2D CNN / 1D CNN / 로지스틱(선형 기준선)
- **핵심 통제**: 1D CNN의 파라미터 수를 2D CNN과 **±5% 이내로 일치**시킨다. 본 논문이 CNN1D 사양을 보고하지 않아 공정성이 검증 불가였던 공백([07_limits.md](07_limits.md))을 선제 해소.
- 관계형(A)에서 "1D 대조군"의 정의: 관계 행렬의 **행별 요약 벡터**($n$개 스칼라)를 1D CNN에 먹인다. 즉 "쌍 정보를 시점 정보로 압축했을 때 무엇이 사라지나"를 측정.

**축 3 — 정규화 (3 + H2용 2)**: 창내 min–max / 누적 척도(첫 값으로 나눔) / 탈변동성(EWMA 정규화) + **H2 전용 2조건**: 범위로만 나누기(레벨 이동 없음) / 최소값만 빼기(나누지 않음)

**추가 대조군 — Q1(해상도) 검증**: 렌더링형(R)에서 세로 해상도 32/64/128/256 스윕. 양자화 손실 가설의 직접 검정.

### 예상 결과
1. **R × 2D CNN ≈ R × 1D CNN** (동일 정규화 조건에서), 그리고 **긴 입력 길이에서 1D가 우세** — 본 논문 Table IX 패턴의 재현.
2. **A × 2D CNN > A × 1D CNN**, 격차가 통계적으로 유의 — 관계형 2D는 압축 불가능한 정보를 담으므로.
3. **정규화 축의 분산 > 모델 축의 분산** (R에서는 확실히, A에서는 약화) — 본 논문 발견의 일반화.
4. **해상도 스윕에서 R × 2D가 단조 증가해 1D 수준으로 수렴** — 양자화 손실 가설 지지.
5. **H2**: "범위로만 나누기" ≈ "완전 min–max" ≫ "최소값만 빼기".

### 반증 조건 (이 결과가 나오면 가설 폐기)
- **H1 반증**: 관계형(A)에서도 1D 요약 대조군이 2D와 동등하다 → "2D 인코딩은 종류를 불문하고 척도 효과였다"는 더 강한 결론. `ts-as-2d` 계열 전체가 재검토 대상이 되고, **APF의 2D motif 전제도 위험해진다.** (그래서 이 실험은 APF에 대한 실질적 위험 감수이며, 그 점이 실험의 가치다 — 프로필 기준 사용자는 이미 "TMAO method falsified at n=12"의 자기반증 이력이 있다.)
- **H1 반대 방향 반증**: 렌더링형(R)에서도 2D가 1D를 유의하게 상회한다 → 본 논문 Table IX가 CNN1D 튜닝 우연이었을 가능성. 이 경우 본 논문에 대한 실질적 반박 논문이 된다.
- **H2 반증**: "최소값만 빼기"가 "범위로 나누기"보다 좋다 → 레벨 이동이 본질이라는 뜻이고, 그러면 배치정규화와의 상호작용을 다시 봐야 한다.
- **해상도 반증**: 해상도를 올려도 R × 2D가 정체 → 양자화가 아니라 2D 합성곱의 귀납편향 자체가 부적합.

### 비용 추정
- **모델 규모**: UCR 데이터셋은 대부분 수백~수천 샘플. 본 논문 5일 모델이 파라미터 155K이므로 동급(100K~500K) 소형 모델로 충분. GPU 1장으로 실행 가능.
- **run 수**: 2(인코딩) × 3(모델) × 5(정규화, H2 포함) × 5(seed) = **150 run** per 데이터셋. UCR 대표 20개 데이터셋이면 3,000 run. 소형 모델이므로 run당 수 분 → **GPU 1장 × 3~5일**.
- 해상도 스윕: 4(해상도) × 3(모델) × 5(seed) × 20(데이터셋) = 1,200 run 추가 → **+2일**.
- **총 예상: GPU 1장, 5~7일** (전처리·분석 포함 2주 이내).
- **부수 산출물**: 인코딩 × 정규화 × 모델 격자 코드는 APF의 probe 실험 인프라로 재사용 가능. 즉 실험 자체가 APF 도구 개발이 된다.

### 왜 이 실험이 값진가
`ts-as-2d` 태그의 네 정거장(GAF/MTF·TimesNet·VisionTS·본 논문) 중 **1D 동일-척도 대조군을 세운 것은 본 논문뿐이고, 그 유일한 대조군이 2D의 우위를 지지하지 않았다.** 이 격자를 채우는 것은 계보의 빈 자리를 정확히 메우는 일이며, 결과가 어느 방향이든 **APF의 2D motif 전제에 대한 방어선 또는 조기 경보**가 된다. 그리고 실행 비용이 GPU 1장 수준이라 위험 대비 정보량이 매우 높다.

## 아이디어 2 — "정규화 범위가 지연 일반화 타이밍을 이동시키는가" (Normalization Scope × Grokking Timing)

### 동기 한 줄
본 논문 Table IX는 **정규화 범위**(창내 국소 vs 과거 전역)가 최종 성능을 지배함을 보였지만, **학습 동역학은 전혀 보지 않았다** — 에폭별 곡선·전이점·표현 형성 시점 중 아무것도 보고하지 않는다(early stopping patience 2만 명시). `_profile.md`의 Grokking track은 "Grokking × TS forecasting × non-stationarity × circuit analysis" 4-way 교차이고 **0편이 발견된 빈 영역**이다. 정규화 범위는 그 교차의 non-stationarity 축을 **입력 수준에서 직접 조작하는 손잡이**다.

### 가설
**H1 (주가설)**: 입력 정규화 범위가 지연 일반화(grokking) 발생 여부와 타이밍을 체계적으로 이동시킨다. 구체적으로 — **창내 국소 정규화는 레짐 전환 정보를 입력 수준에서 지워 버리므로 모델이 레짐 구조를 학습할 필요를 없애고, 따라서 grokking이 빨라지거나 아예 발생하지 않는다**(즉시 일반화). 반대로 **전역 정규화는 레짐 정보를 남기지만 척도 불일치로 학습을 어렵게 하므로 grokking이 늦게, 그러나 발생한다**.

**H2 (부가설)**: 국소 정규화로 학습한 모델은 레짐 전환에 대한 **표현을 갖지 않으므로**, 새로운 레짐(학습 중 미관측 파라미터 영역)으로의 외삽에서 전역 정규화 모델보다 나쁘다. 즉 **국소 정규화는 학습을 쉽게 하는 대가로 일반화의 범위를 좁힌다.**

### 데이터
`_profile.md` 기록 Grokking track 자산만 사용:
- **주 데이터**: **regime-switching synthetic** — 레짐 개수·전환 확률·레짐별 변동성을 완전히 통제할 수 있으므로 H1·H2 모두의 깨끗한 시험대. 국소 vs 전역 정규화의 차이가 **정의상 레짐 전환 지점에서만 발생**하므로 이 데이터가 필수.
- **보조**: **logistic map** — 프로필 기준 "P2 logistic 4-layer 실험 background 진행 중"이므로 **기존 실험 인프라와 직접 연결**된다. 결정론적 카오스이므로 grokking 문헌(Power 2022 계열의 알고리즘 데이터)과 가장 가까운 성질.
- **실데이터 확인**: **ETT-mini / Weather-mini / Traffic-mini** — 합성에서 발견한 패턴이 실데이터에서도 나타나는지. (본 논문이 §V에서 "합성 → 실세계"를 하지 않은 것과 대비되는 지점.)

### 비교 조건
**축 1 — 정규화 범위 (4)**
| 조건 | 정의 | 레짐 정보 |
|---|---|---|
| **L-mm** | 창내 min–max (본 논문 방식) | **지워짐** |
| **L-std** | 창내 평균·표준편차 표준화 | 지워짐 (2차 모멘트까지) |
| **G-ewma** | 과거 EWMA 변동성으로 정규화 (본 논문 탈변동성 척도) | 부분 보존 |
| **G-fixed** | 학습 데이터 전체 통계로 고정 정규화 | **완전 보존** |

**축 2 — 레짐 전환 강도 (3)**: 약(변동성 비 1.5배) / 중(3배) / 강(10배)

**축 3 — 모델 용량 (2)**: 프로필 기준 P2가 "logistic 4-layer"이므로 **4층 고정** + 폭 2조건(narrow/wide). grokking이 용량에 민감하다는 문헌 사실을 통제.

**측정 대상 (핵심)**: 최종 성능이 아니라 **학습 동역학**이다.
- 에폭별 학습/검증 손실 곡선 → **grokking 전이점 에폭** 특정
- 전이점 전후의 **표현 변화** — 프로필 기준 APF의 CNN probe 인프라를 재사용해 중간 표현을 프로빙
- **가중치 노름 궤적** (grokking 문헌의 표준 진행 척도)
- H2용: 학습 중 미관측 레짐 파라미터로의 **외삽 성능**

### 예상 결과
1. **L-mm / L-std에서 grokking이 발생하지 않거나 매우 이르다** — 검증 손실이 학습 손실과 거의 동시에 떨어진다. 레짐 구조를 배울 필요가 없으므로 태스크가 "쉬운 문제"로 변환된다.
2. **G-fixed에서 grokking이 가장 늦게, 가장 뚜렷하게 발생** — 전형적인 "학습 손실 먼저 붕괴, 검증 손실 오래 정체 후 급락" 패턴.
3. **레짐 전환 강도가 커질수록 국소 vs 전역의 격차가 확대** — 강한 전환에서 국소 정규화의 "정보 삭제"가 더 큰 효과를 갖는다.
4. **H2**: 미관측 레짐 외삽에서 순위가 **역전** — G-fixed > L-mm. 즉 grokking을 늦게 겪은 모델이 더 넓게 일반화한다.
5. 실데이터(ETT-mini 등)에서는 효과가 약화되지만 **부호는 유지**.

### 반증 조건
- **H1 반증**: 정규화 범위가 grokking 타이밍에 영향을 주지 않는다(전이점 에폭이 조건 간 통계적으로 구분되지 않음) → 정규화는 성능에만 영향을 주고 동역학과 무관하다는 결론. 이 경우 **본 논문 Table IX의 함의가 "성능 효과"로 국한**되고, non-stationarity 축의 손잡이로는 부적합.
- **H1 반대 방향 반증**: 국소 정규화에서 grokking이 **더 늦게** 발생 → 필자 가설의 메커니즘("정보 삭제 → 문제 단순화")이 틀렸다는 뜻. 대안 메커니즘(국소 정규화가 입력 분포를 창마다 바꿔 학습을 불안정하게 함)을 검토해야 한다.
- **H2 반증**: 외삽 성능에서도 L-mm이 우세 → "쉬운 학습이 좁은 일반화를 낳는다"는 교환관계가 없다는 뜻. 그러면 국소 정규화는 순수한 무료 이득이고, 본 논문의 척도 선택이 전면적으로 정당화된다.
- **전제 자체의 반증**: regime-switching synthetic에서 **어떤 조건에서도 grokking이 관측되지 않는다** → 태스크 난이도·용량·정규화 강도를 재설계해야 한다. (프로필 기준 Grokking track이 "Day 1-5, Week 1 setup" 단계이므로 이 위험이 실재한다 — 그래서 logistic map을 보조로 두어 grokking이 확실히 재현되는 앵커를 확보한다.)

### 비용 추정
- **모델 규모**: 프로필 기준 4층. grokking 관측에는 긴 학습이 필요하다(문헌상 수천~수만 에폭) — 이것이 주 비용이다.
- **run 수**: 4(정규화) × 3(전환강도) × 2(폭) × 5(seed) = **120 run** on regime-switching synthetic. logistic map 앵커 20 run. 실데이터 3종 × 4(정규화) × 5(seed) = 60 run. **총 200 run.**
- **run당 비용**: 소형 모델 × 장기 학습 → run당 GPU 수십 분~수 시간. 병렬 실행 가능(독립 run).
- **총 예상: GPU 1~2장 × 1~2주.** 분석·시각화 포함 3주.
- **부수 산출물**: 에폭별 곡선 + 전이점 자동 검출 파이프라인은 Grokking track 전체의 기본 인프라다. 즉 이 실험은 **track의 측정 도구를 만드는 일과 동시에 진행**된다.

### 왜 이 실험이 값진가
`_profile.md`가 Grokking track을 "**4-way intersection (0 papers found)**"으로 기록한다. 빈 영역에서 첫 논문을 쓸 때 가장 위험한 것은 "왜 이 교차가 흥미로운가"를 설명할 **구체적 손잡이가 없는 것**이다. 정규화 범위는 그 손잡이가 될 수 있다 — ① 실무적으로 모든 시계열 파이프라인이 반드시 내리는 결정이고, ② 본 논문이 **성능에 미치는 영향이 극단적임을 JF 게재 수치로 증명**했으며(샤프 7.20 → −0.13), ③ 그런데 **동역학에 미치는 영향은 아무도 보지 않았다.** 즉 "중요함은 이미 입증되었고 미탐구 영역이 명확한" 드문 조합이다.

그리고 [09_my_research.md](09_my_research.md)의 반면교사 표에 정리한 ML 학회 요건 — seed 분산 보고, 학습 곡선, baseline 용량 통제 — 이 이 실험 설계에 **처음부터 내장**되어 있다(5 seed, 동역학이 측정 대상 자체, 용량 통제 축). 프로필 기준 목표가 "NeurIPS 2027 1순위 / TMLR backup"이므로, 본 논문이 JF 기준으로 통과한 것과 다른 기준을 처음부터 만족시키는 설계가 필요하다.
