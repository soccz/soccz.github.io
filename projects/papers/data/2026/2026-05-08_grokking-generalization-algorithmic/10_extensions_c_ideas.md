## 실험 아이디어 1 — "TS 그로킹 위상 다이어그램"

### 가설

Power 2022의 (weight decay × 데이터 비율) 위상 다이어그램이 시계열 예측 Transformer에서도 (non-stationarity 강도 × 훈련 데이터 길이) 위상 다이어그램으로 재현된다. 구체적으로, 비정상성이 강하고 훈련 데이터가 짧을수록 "암기" 구역에 속하며, 적절한 weight decay와 충분한 훈련 길이가 있을 때 "지연 일반화(TS 그로킹)" 구역이 존재한다.

### 데이터

- **합성 데이터**: regime-switching 프로세스 (예: 두 가우시안 분포 사이에서 전환하는 시계열)
  - 비정상성 강도: 전환 빈도 (1/50 에서 1/1000 스텝)
  - 훈련 길이: 100, 200, 500, 1000 타임스텝
- **실제 데이터 검증**: ETT-mini, Weather-mini (이미 보유)

### 비교 조건

| 조건 | 설정 |
|------|------|
| 기준 | Weight decay=0, 고정 분포 |
| 실험 1 | Weight decay 변화 (0 → 0.1 → 1.0) |
| 실험 2 | Non-stationarity 강도 변화 |
| 실험 3 | 훈련 데이터 길이 변화 |

### 측정 지표

- In-sample MSE 수렴 시점 ($t_{\text{train}}$)
- Out-of-sample MSE 최적 도달 시점 ($t_{\text{val}}$)
- "TS 그로킹 지수": $t_{\text{val}} / t_{\text{train}}$ > threshold 이면 그로킹 발생으로 분류
- 어텐션 헤드의 Fourier 분석: 특정 주파수에 특화된 헤드가 그로킹 이후 등장하는지

### 예상 결과

높은 비정상성 + 짧은 훈련 데이터 → "암기" 또는 "혼돈" 구역
낮은 비정상성 + 적당한 훈련 데이터 + 적당한 weight decay → "TS 그로킹" 구역

### 반증 조건

"TS 그로킹 지수"가 어떤 조건에서도 1에 가깝거나 (그로킹 없음), 또는 MSE 개선이 항상 gradual하다면 → TS에서 그로킹이 발생하지 않는다고 결론.

### 비용 추정

- GPU 시간: RTX 4090 기준 10,000 스텝 × 15 조건 = ~5시간
- 코드: Power 2022 `openai/grok` 코드베이스를 TS 예측용으로 수정 (2-3일 작업)
- 총 추정: 1주일 이내에 파일럿 결과 도출 가능

## 실험 아이디어 2 — "회로 형성 추적: 언제 어떤 헤드가 먼저 일반화 회로를 구성하는가?"

### 가설

Power 2022의 모듈 산술 과제에서 그로킹이 진행되는 동안 (즉 훈련 정확도 100% 이후, 검증 정확도 100% 이전), Transformer의 특정 어텐션 헤드가 특정 역할을 먼저 전담하는 순서가 존재한다. 이 순서가 Nanda 2023의 Fourier 회로 형성 순서와 일치한다면, 회로 형성 순서가 그로킹의 "내부 타임라인"을 구성한다.

### 데이터

- Power 2022와 동일한 설정: 2-layer Transformer, mod 97 나눗셈, 50% 분할, 적당한 weight decay
- 체크포인트: 1K, 2K, 5K, 10K, 20K, 50K, 100K, 200K, 500K, 1M 스텝

### 비교 조건

| 분석 방법 | 내용 |
|----------|------|
| 어텐션 패턴 시각화 | 각 체크포인트에서 attention weight 행렬 시각화 |
| Fourier 분석 | 각 헤드의 활성화 패턴을 주파수 도메인 변환 |
| Activation patching | 특정 헤드를 그로킹 전/후 버전으로 교체 후 성능 변화 |
| 인과 구조 추정 | 어떤 헤드가 어떤 순서로 일반화 성능에 인과적으로 기여하는지 |

### 측정 지표

- 각 헤드의 "Fourier 순도": 주파수 집중도 (entropy of frequency spectrum)
- 헤드 ablation에 따른 검증 정확도 변화
- "회로 완성 시점": 모든 Fourier 헤드가 형성되는 스텝

### 예상 결과

그로킹 기간 동안 Layer 1 헤드가 먼저 입력(a, b) 의 개별 주파수를 인코딩하고, Layer 2 헤드가 이를 조합해 출력 주파수를 만드는 순서로 회로가 완성된다. 회로 완성 시점이 검증 정확도 급상승과 거의 일치한다.

### 반증 조건

- 두 레이어 헤드가 동시에 형성되거나, 순서가 랜덤이면 → 순차적 회로 형성 가설 반증
- Fourier 분석으로 특정 주파수 집중이 보이지 않으면 → 다른 내부 메커니즘 존재 시사

### 비용 추정

- 코드: `openai/grok` + 어텐션 시각화 + 주파수 분석 코드 (이미 Nanda 2023 코드 참고 가능)
- 체크포인트 저장: 10개 × ~6MB = 60MB
- 분석 시간: 각 체크포인트당 1시간 이내 (visualization + Fourier)
- 총 추정: 2주 이내에 완성 가능, Grokking track의 초기 결과로 논문 섹션 하나를 구성할 수 있는 분량
