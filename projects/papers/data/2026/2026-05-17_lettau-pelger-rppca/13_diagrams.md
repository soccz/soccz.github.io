## 17.1 논문 전체 흐름

```
┌────────────────────────────────────────────────────────────┐
│                  [출발: 자산가격 패널 X]                    │
│              X (T×N): T시점 × N자산 초과수익                │
└──────────────────────────┬─────────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────────┐
│           [요인 모델 가정]  X = F Λ' + e                    │
│   F (T×K): 잠재요인     Λ (N×K): 로딩    e: 잔차            │
└──────────────────────────┬─────────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────────┐
│            [APT의 두 함의 — 둘 다 만족해야]                  │
│  ① Var(X) = Λ Var(F) Λ' + Var(e)   (시계열 공변)            │
│  ② E[X_i] = Λ_i · E[F]              (횡단면 평균)           │
└──────────────────────────┬─────────────────────────────────┘
                           │
              ┌────────────┴────────────┐
              ▼                         ▼
   [전통 PCA: ① 만 사용]    [RP-PCA: ① + ② 둘 다]
   분산 큰 요인만 잡음         γ 가중치로 결합
              │                         │
              ▼                         ▼
        γ = -1 (PCA)              γ > -1 (RP-PCA)
       약한 요인 놓침            약한 요인도 잡음
              │                         │
              └─────────┬───────────────┘
                        ▼
              ┌──────────────────┐
              │  실증: SR 2배     │
              │  (PCA → RP-PCA)  │
              └──────────────────┘
```

## 17.2 RP-PCA 추정 절차

```
       INPUT: 자산 패널 X (T×N), 요인 수 K, RP 가중 γ
                          │
                          ▼
       ┌──────────────────────────────────────────┐
       │ Step 1: 자산별 평균 계산                  │
       │   X̄ = ⅟T · 𝟙' X     (1×N 행벡터)        │
       └──────────────────────┬───────────────────┘
                              ▼
       ┌──────────────────────────────────────────┐
       │ Step 2: 변형된 모멘트 행렬               │
       │   M = ⅟T · X'X + γ · X̄' X̄    (N×N)     │
       │                                          │
       │   γ = -1: 표본 공분산 (표준 PCA)         │
       │   γ = 0:  2차 모멘트 (분산+평균제곱)     │
       │   γ > 0:  평균 정보 강조                 │
       └──────────────────────┬───────────────────┘
                              ▼
       ┌──────────────────────────────────────────┐
       │ Step 3: 고유분해                         │
       │   M = U Σ U'                             │
       │   상위 K 고유벡터 → Λ̂ = U_{1:K} · √N    │
       └──────────────────────┬───────────────────┘
                              ▼
       ┌──────────────────────────────────────────┐
       │ Step 4: 요인 회귀                        │
       │   F̂ = X · Λ̂ / N           (T×K)        │
       │   Ĉ = F̂ · Λ̂'              (T×N)        │
       └──────────────────────┬───────────────────┘
                              ▼
       OUTPUT: 요인 F̂, 로딩 Λ̂, 공통성분 Ĉ
```

## 17.4 Strong vs Weak Factor 분류

```
            요인의 영향력 스펙트럼
   ──────────────────────────────────────────►
   강함                                    약함
   
   [Strong Factor]              [Weak Factor]
   ─────────────                ─────────────
   • 거의 모든 자산에 영향        • 일부 자산에만 영향
   • Λ'Λ/N → Σ_Λ (PD)            • Λ'Λ → I_K (bounded)
   • 고유값 O(N) 폭발            • 고유값 O(1) 분리
   • PCA로 항상 검출             • PCA 임계값↓시 실패
   • 예: 시장 요인               • 예: anomaly 요인
   
   분석 도구:                    분석 도구:
   Bai (2003) CLT                Random Matrix Theory
   Theorem 1, Lemma 1            Theorem 2, Lemma 2
   
   실증에서:                     실증에서:
   1번째 요인 (분산 5)            2~6번째 요인
                                  (분산 0.05~0.3)
```

## 17.5 Phase Transition — 검출 가능/불가능의 경계

```
   고유값 위치 분포 (큰 표본 극한)
   
            ▲ 밀도
            │
            │  ┌──────────┐                  
            │ ╱            ╲       ★ ← Spike 1 (강한 요인)
            │╱     Bulk     ╲           검출 OK
            │   (Marchenko-  │
            │   Pastur 분포) │  ★ ← Spike 2 (적당한 신호)
            │                │       검출 OK (편향有)
            │                │ 
            │                │★ ← Spike 3 (임계 위)
            │                │      간신히 검출
            │                ┃ ← θ_crit = 1/G(b⁺)
            │                ┃   ◄── 임계값
            │       ✗        │
            └──────[a, b]────┴──────────────►
                                          고유값 크기
   
   ★ 신호 θ > θ_crit  →  표본 고유값 ≈ G⁻¹(1/θ)
                         ρ² = 1/(1 + θ B(θ)) > 0   (검출!)
   
   ✗ 신호 θ < θ_crit  →  표본 고유값 → b (bulk로 흡수)
                         ρ² → 0                     (검출 실패)
                         ◄── 데이터를 무한히 늘려도 못 잡음
```

## 17.6 Signal-Strengthening — γ가 신호를 끌어올리는 방식

```
   PCA의 신호 행렬 M_PCA (K×K 대각)
   
   ┌─────────────────────────────────────┐
   │ σ²_F1 + cσ²_e                       │ ← 요인1 (강함)
   │              σ²_F2 + cσ²_e          │ ← 요인2
   │                          ⋱           │
   │                       σ²_Fk + cσ²_e │ ← 요인k (분산↓ 안잡힘)
   └─────────────────────────────────────┘
                ↓
   분산 σ²_Fk가 임계 미만 → ✗ 검출 실패
   
   ════════════════════════════════════════
   
   RP-PCA의 신호 행렬 M_RP-PCA ((K+1)×(K+1) 비대각)
   
   ┌──────────────────────┬────────────────┐
   │                      │ Σ_F^½ μ_F (1+γ̃)│  ← 평균 정보가
   │  Σ_F + cσ²_e         │   비대각 항      │     끼어들어옴
   │   (K×K)              │                │
   ├──────────────────────┼────────────────┤
   │ μ_F' Σ_F^½ (1+γ̃)    │ (1+γ)(μ_F'μ_F  │
   │                      │  + cσ²_e)      │
   └──────────────────────┴────────────────┘
                ↓
   고유값 = Σ_F + (1+γ)·μ_F μ_F' 의 고유값
                ▲
                │
            ┗━━━ γ 클수록 신호 끌어올림
                "분산 작아도 평균(μ_F) 크면 검출됨"
```

비유:
```
   분산 σ²_F 만의 PCA 신호:    [▮▮]
                                  ↑ 임계값
   
   평균 정보를 더한 RP-PCA:    [▮▮▮▮▮▮]  ← 임계값 넘음!
                              ────┬──── 추가된 부분
                                  │
                              (1+γ)μ_F μ_F'
```

## 17.7 GMM 해석 — 왜 더 효율적인가

```
   [표준 PCA] = OLS first-order condition만 사용
   
        모멘트 조건 K개:
        ┌─────────────────────────────────────┐
        │ E[(X - F Λ')F] = 0    (K개 조건)    │
        └─────────────────────────────────────┘
                          ↓
                   K개 미지수 정확 식별
                          ↓
                     [표준 OLS 해]
   
   ════════════════════════════════════════════
   
   [RP-PCA] = OLS FOC + APT pricing moment
   
        모멘트 조건 K+1개:
        ┌─────────────────────────────────────┐
        │ E[(X - F Λ')F] = 0       (K개)      │ ← 시계열 모멘트
        │ E[X - F Λ'] = 0          (1개)      │ ← APT 모멘트 (평균)
        └─────────────────────────────────────┘
                          ↓
              가중 결합 [I_K  0 ; 0  γ]
                          ↓
                 [GMM 해 = RP-PCA]
                          
   "모멘트가 하나 더 있으면 추정량이 더 효율적"
   (조건이 더 빡빡 → 정답 주위 변동 작음)
```

## 17.11 Cauchy Transform 직관

```
   G(z) = lim ⅟N Σ 1/(z - λ_i)
         (bulk 고유값들의 평균 reciprocal distance)
   
                 ▲ G(z)
                 │
                 │      G(z) 감소 함수
                 │ ╲
                 │  ╲     z=b에서 1/G(b⁺) = θ_crit
                 │   ╲___╲
                 │           ╲_______________  z → ∞ 면 G → 0
                 │
                 └───┬─────────────────────►  z
                     b (bulk 윗 끝)
   
   사용법:
   - 신호 θ_i 주어졌을 때
   - 1/θ_i 를 y축에 찍고
   - G(λ) = 1/θ_i 만족하는 λ를 찾으면
   - 그게 표본 고유값 ĥθ_i = G⁻¹(1/θ_i)
   
   ★ θ_i가 1/G(b⁺) = θ_crit 이하면 ⇒ 해 없음 ⇒ 검출 실패
```

i.i.d. 잔차 케이스 명시 공식:
```
   G(z) = (z - σ²_e(1-c) - √((z-σ²_e(1+c))² - 4cσ⁴_e)) / (2cz σ²_e)
   θ_crit = σ²_e (c + √c)        ◄ 깔끔한 임계값
   
   예: σ²_e = 1, c = N/T = 370/650 ≈ 0.57
       √c ≈ 0.755
       θ_crit ≈ 1.33
   
   → 요인 분산 신호가 1.33 이상이어야 PCA로 검출
   → 실증에서 5번째 요인 신호 0.05 << 1.33
   → 그래서 PCA로는 5번째 못 잡고 RP-PCA만 잡는다
```

## 17.12 자기점검

### 핵심 3가지
1. **17.5의 phase transition 그림에서, 신호 θ가 θ_crit 위/아래일 때 표본 고유값과 ρ²의 운명은?**
2. **17.6의 signal-strengthening에서, 분산이 작은 요인을 검출하는 핵심 키워드는?**
3. **17.10의 표에서 왜 K=5가 K=3보다 RP-PCA의 우월성을 더 잘 보여주는가?**

### 답변
1. θ > θ_crit: 고유값 → G⁻¹(1/θ) (정확한 위치), ρ² = 1/(1+θB(θ)) > 0 (검출). θ < θ_crit: 고유값 → b (bulk 흡수), ρ² → 0 (검출 실패).
2. 평균 (μ_F). 분산은 작아도 평균이 크면 (1+γ)μ_Fμ_F' 항이 신호를 끌어올림.
3. K=3에서는 모두 강한 요인 — PCA로도 검출 가능. K=5에는 4·5번째 weak factor 포함 — PCA가 못 잡는 영역. 그래서 K=5에서 RP-PCA의 진가 발휘.
