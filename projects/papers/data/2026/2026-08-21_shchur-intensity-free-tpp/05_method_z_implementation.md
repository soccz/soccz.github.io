## 합성 데이터 생성 (Appendix E.1)

원문 진술: 합성 데이터는 Omi et al. (2019)를 따라 잘 알려진 점과정으로 생성하며, **각 과정마다 시퀀스 64개, 시퀀스당 사건 1024개**를 샘플링한다.

| 과정 | 정의 / 파라미터 |
|---|---|
| Poisson | $\lambda^*(t)=1$ |
| Renewal | 로그정규, $\mu=1.0$, $\sigma=6.0$ |
| Self-correcting | $\lambda^*(t)=\exp\left(t-\sum_{t_i<t} 1\right)$ |
| Hawkes1 | $M=1$, $\mu=0.02$, $\alpha_1=0.8$, $\beta_1=1.0$ |
| Hawkes2 | $M=2$, $\mu=0.2$, $\alpha_1=0.4$, $\beta_1=1.0$, $\alpha_2=0.4$, $\beta_2=20$ |

**읽는 법**: 이 다섯 과정은 의도적으로 서로 다른 "성격"을 고른 것이다 — Poisson은 기억 없음, Renewal은 기억 없으나 간격 분포가 자유, Self-correcting은 **사건이 나면 강도가 내려가는**(억제) 과정, Hawkes는 자기흥분. 특히 Self-correcting이 들어간 것이 중요하다: 고전 Hawkes 계열이 원리적으로 표현 못 하는 억제 구조가 벤치마크에 포함돼 있다는 뜻이다. Renewal의 $\sigma=6.0$ 은 극단적으로 넓은 로그정규로, **꼬리가 매우 두꺼운 상황**에서의 견고성을 시험한다.

## 학습·추론 의사코드

```python
# 학습 한 스텝 (마크 없는 경우)
for batch in loader:                      # 시퀀스 64개
    tau = batch.inter_event_times         # (B, L) 양수
    h   = rnn(embed(tau))                 # 이력 임베딩 h_i (B, L, H)
    c   = concat([h, y, e])               # 문맥 벡터 (식 (3)의 입력)

    w   = softmax(c @ V_w + b_w)          # (B, L, K)  성분 비중
    s   = exp(c @ V_s + b_s)              # (B, L, K)  로그축 폭  (양수 제약)
    mu  = c @ V_mu + b_mu                 # (B, L, K)  로그축 중심

    logp = logsumexp(log(w) + lognormal_logpdf(tau, mu, s), dim=-1)   # 식 (2)
    loss = -logp.mean()                   # 적분 항 없음 — 이것이 요점
    loss.backward(); opt.step()

# 다음 사건 시각 점예측  (닫힌형, §3.2)
E_tau = (w * exp(mu + s**2 / 2)).sum(-1)

# 샘플링 (재파라미터화, §3.2)
z    = sample_categorical(w)              # 성분 선택 (이산 — 그래디언트 없음)
eps  = randn_like(z_selected_mu)
tau_ = exp(s_z * eps + mu_z)              # mu, s 에 대해 미분 가능
```

**구현상의 요점 세 가지.**
1. `logsumexp` — 혼합 밀도의 로그는 반드시 log-sum-exp로 계산해야 수치적으로 안전하다. 성분이 64개이고 각 성분 밀도가 매우 작을 수 있으므로, 곧이곧대로 `log(sum(w*p))` 를 쓰면 언더플로가 난다.
2. **적분이 없다** — 강도 기반 구현이라면 여기에 몬테카를로 적분 루프가 들어갔을 자리다. 코드 라인 수와 학습 시간의 차이가 이 논문의 실질적 이점 중 하나다(원문이 학습 시간 비교표를 제시했는지는 **미확인**).
3. **점예측의 함정** — `E_tau` 는 닫힌형이지만 꼬리에 민감하다([05_method_d](05_method_d_lognormmix.md) 참조). 실무에서는 같은 파라미터로 중앙값을 이분 탐색해 쓰는 편이 안전하다(모델 변경 없이 가능).

## 재현성 관점의 총평

- **강점**: 코드·데이터 공개, 10회 분할 반복, 표준편차 보고(Table 4~6), 합성 데이터의 **참 모델 NLL** 병기(Table 5) — 참값이 있어 "얼마나 모자라는가"를 절대 기준으로 볼 수 있다는 점은 이 분야에서 드물게 좋은 관행이다.
- **약점**: RNN 은닉 차원 등 일부 용량 설정이 본 실행에서 확인되지 않았고, 모델별 파라미터 수·학습 시간이 정렬돼 있는지 확인할 표를 찾지 못했다($K$ 비대칭이 그 우려를 키운다).

## 이 절의 핵심 한 문장

**구현은 "출력층을 혼합 밀도로 바꾸고 적분 루프를 지운다"가 전부이며, 재현 자료는 충실하지만 모델 간 예산 정렬($K=64$ vs $K=4$)은 비교의 공정성을 일부 훼손한다.**
