## 아이디어 1: Inter-Stock Attention Map의 APF 모티프 분석 — 종목 상관 어텐션에서 2D 패턴 발굴

### 가설

MASTER의 inter-stock 어텐션 행렬 $A_{inter} \in \mathbb{R}^{N \times N}$은 시장 국면에 따라 서로 다른 2D 구조적 패턴(APF 용어로 motif)을 보인다. 강세장에서는 block 구조(섹터 내 밀집 상관), 폭락장에서는 stripe 구조(특정 "공포 리더" 종목이 전체에 영향), 횡보장에서는 diagonal 구조(종목별 독립 움직임)가 우세할 것이다.

### 데이터

- MASTER의 공개 체크포인트 (csi300_opensource_0.pkl) 사용
- CSI300 테스트 기간 (Q3 2020 ~ Q4 2022): 총 약 500 거래일
- 각 날짜마다 $A_{inter,t} \in \mathbb{R}^{N \times N}$ ($t=1,\ldots,T$) 추출

### 비교 조건

- **국면 분류**: 해당 날의 VIX 대응 지표 또는 CSI300 30일 수익률로 (1) 상승장, (2) 횡보장, (3) 하락장 구분
- **Motif 측정**: APF의 모티프 분류기(diagonal/stripe/block/edge 등)를 inter-stock 행렬에 적용
- **대조군**: 랜덤 특징으로 학습한 모델의 $A_{inter}$와 MASTER의 $A_{inter}$ 비교 → 학습된 패턴이 random과 다른지 확인

### 예상 결과

국면별로 dominant motif가 달라지며, 특히 폭락장에서 stripe (리더 종목 중심) 패턴이 강화될 것이다. 이는 MASTER가 시장 구조를 의미 있게 학습했음을 시각적으로 증명하고, APF의 금융 도메인 적용 가능성을 실증한다.

### 반증 조건

국면에 관계없이 $A_{inter}$가 항상 유사한 패턴을 보이거나, 랜덤 모델과 구분되지 않는다면 MASTER의 inter-stock 어텐션이 실제로 의미 있는 상관 구조를 학습하지 못한다는 뜻이다 — 이는 07_limits의 반박 1을 지지하는 결과가 된다.

### 비용 추정

- GPU: T4 × 1, 약 4시간 (MASTER inference 500일 × $A_{inter}$ 추출)
- 코드: MASTER 공식 코드 기반, attention weight 추출 hook 추가 (약 100줄 추가)
- APF 모티프 분류기: 기존 APF 코드 재사용 (이미 개발됨)
- **총 비용**: 낮음. 새 모델 학습 없이 기존 체크포인트 활용.

## 아이디어 2: Market-Guided Gating을 ProTran-TFA에 이식한 소규모 실험 — 팩터 선택 게이팅의 전이 가능성 검증

### 가설

ProTran-TFA의 입력 전처리 단계에 MASTER 방식의 market-guided gating을 추가하면, 시장 국면 변화가 큰 기간(2022년 금리 급등기, 2020년 COVID 폭락기)에서 팩터 선택 성능이 향상된다.

### 데이터

- P1 ProTran-TFA 보유 데이터: GSPC/IXIC 2022-2024
- 팩터 공간: FF5 (시장 베타, 소형주, 가치, 수익성, 투자성향) + 모멘텀 = 6~7개 팩터
- 시장 게이팅 입력: S&P500 VIX, 10Y-2Y 금리 스프레드, DXY (달러 지수), GSPC 30일 rolling 수익률/변동성

### 실험 설계

**모델 A (기준)**: 기존 ProTran-TFA (게이팅 없음, 모든 팩터 동등 입력)

**모델 B (MASTER 게이팅 추가)**: ProTran-TFA 입력 전에 시장 벡터 $m_\tau \in \mathbb{R}^{D_m}$ ($D_m$≈15) 기반 게이팅 계수 $g \in \mathbb{R}^7$ 생성 후 팩터 재가중치

**비교 지표**:
- IC, Rank IC (팩터 예측 순위 vs. 실제 팩터 수익률 순위)
- 시장 국면별 성능 분해 (상승장/하락장/횡보장 구간 분리)
- 해석 가능성: 게이팅 계수 $g$를 국면별로 시각화 → "금리 급등기에 어떤 팩터가 선택됐는가" 확인

### 예상 결과

- 전체 기간 성능 개선은 미미하거나 없을 수 있음 (팩터가 7개로 적어 선택 효과 제한적)
- 그러나 **2022년 금리 급등기** 같은 극단적 국면에서 게이팅 모델이 가치 팩터를 강화하고 성장 팩터를 약화시키는 패턴이 관찰될 경우, ProTran-TFA의 컨디셔닝 메커니즘 강화 근거가 생김

### 반증 조건

게이팅 계수가 모든 국면에서 거의 동일한 값(≈1)으로 수렴한다면, 팩터 수가 너무 적어($F=7$) 게이팅의 효과가 없거나, market vector의 63차원 정보가 7개 팩터 선택에는 과도하게 풍부하다는 뜻이다. 이 경우 더 단순한 regime detection (HMM 2-state)이 더 적합할 수 있다.

### 비용 추정

- GPU: 없음 (CPU로 충분, 팩터 수가 7개)
- 코드: ProTran-TFA 기존 코드에 gating layer 추가 (약 50줄)
- 데이터: 이미 보유 (GSPC/IXIC 2022-2024)
- **총 비용**: 매우 낮음. 1~2일 내 완료 가능한 소규모 실험.
