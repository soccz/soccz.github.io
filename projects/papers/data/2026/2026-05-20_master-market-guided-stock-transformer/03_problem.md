## 📌 이 챕터 다 읽으면 알 수 있는 것

- 주가 예측의 문제 지형도 (왜 어렵고, 어디서 막히는가)
- Stock-level (종목 자체) vs Market-level (시장 전체) signal 의 분리
- Cross-time correlation 의 의미와 기존 방법이 못 잡는 이유
- 기존 접근 (ALSTM, GAT, DTML) 의 진화와 각 단계의 한계
- MASTER 가 푸는 정확한 problem statement 와 해결 전략

---

> **배경 사다리**: ① **주식 예측** = "내일 (5일 후) 어떤 종목이 더 많이 오를까" 를 맞추는 문제. 절대값 예측이 아닌 **상대 순위 (ranking)** 예측. ② **Information Coefficient (IC)** = 예측 순위와 실제 수익률 순위의 상관계수 (높을수록 좋음, 0.05 이상 유의). ③ **Self-attention** = 시퀀스의 각 원소가 다른 원소들을 "얼마나 참고할지" 가중치를 학습하는 메커니즘. ④ **Cross-time correlation** = 종목 A 의 시각 $t$ 신호와 종목 B 의 시각 $t' \neq t$ 신호 사이의 상관. 시간 어긋남 (temporal misalignment) 이 핵심. ⑤ **Time-aligned** = 같은 시각 $t$ 의 정보끼리만 비교하는 가정. 이 다섯 개념으로 본 챕터 전체를 읽을 수 있다.

### 🌱 주식 예측 문제 — 일상 비유

**1주일 후 학생들 시험 순위 맞히기** (이게 주식 예측의 본질):

| 학생 비유 | 주식 비유 |
|----------|----------|
| 학생 = 종목 | 300명 학생 |
| 시험 점수 = 5일 후 수익률 | 미래 수익률 |
| 학생의 과거 성적 = 시계열 데이터 | 8일치 가격 데이터 |
| 학생들의 친구 관계 = 상관관계 | 종목 간 동조성 |
| 학교 분위기 (시험 직전 사기) = 시장 국면 | $m_\tau$ (S&P, VIX 등) |

**3가지 어려움**:
1. **잡음**: 시험 당일 컨디션 (= 일일 수익률 잡음) 이 실력보다 크게 영향
2. **친구 관계 시차**: 친구 A 가 어제 우울하면 친구 B 가 3일 뒤 영향받음 (cross-time)
3. **분위기 의존성**: 활기찬 학교에선 모범생 성적 ↑, 침체된 학교에선 노력파 성적 ↑ (국면별 신호)

## 1. 실제 문제: 주식 예측은 왜 어렵고, 어디서 막히는가

### 1.1 본질적 어려움 3가지

주식 가격 예측은 수십 년째 극도로 어려운 문제. 시장 데이터는:

| 특성 | 의미 | 영향 |
|------|------|------|
| **낮은 SNR (Signal-to-Noise Ratio)** | 신호 ≪ 잡음 (SNR ≈ 1:20) | 작은 IC (0.05) 가 좋은 수준 |
| **Non-stationary** | 데이터 분포가 시간에 따라 변화 | 학습-테스트 분포 차이 → 일반화 어려움 |
| **Fat-tail (kurtosis ↑)** | 극단 수익률 자주 발생 | Outlier 처리 critical |

### 1.2 구조적 어려움 3가지

이 본질적 어려움 위에 **구조적 어려움** 추가:

#### 상황 1 — 거시 충격의 파급 (Cross-time correlation)

**시나리오**: 미국 금리 발표 (시각 $\tau$) → 코스피 전체가 동시에 움직임. 그러나:
- 금리 민감 산업 (금융, 부동산) 즉시 반응
- 수출 산업 (반도체, 자동차) **1-3일 뒤** 반응 (환율 영향)
- 내수 산업 (소비재, 유통) **3-5일 뒤** 반응 (소비 심리 변화)

**문제**: 종목 간 상관관계가 "오늘" 또는 "3일 뒤" 또는 "5일 뒤" 로 **시간을 가로지름**. 이것이 **cross-time correlation** 의 정확한 의미.

**🎯 구체 증거** (학계 보고):
- Eun & Shim 1989: 미국 → 일본 주식시장 영향이 **0-2 거래일 시차** 로 강함
- Forbes & Rigobon 2002: 1997 아시아 위기 시 국가 간 전염이 1-5일 시차
- 코로나 2020-Q1: 미국 시장 폭락 → 중국 시장 1-3일 뒤 follow

→ Cross-time 상관은 학계에서 **stylized fact**.

#### 상황 2 — 시장 국면별 특징 유효성

같은 158 팩터라도 국면별로 신호 강도 다름:

| 국면 | 강한 팩터 | 약한 팩터 |
|------|---------|----------|
| 강세장 (저변동성) | 모멘텀, 추세 | 가치, 변동성 |
| 폭락장 (고변동성) | 유동성, 변동성 | 모멘텀 |
| 횡보장 | 가치 (PER, PBR) | 모멘텀 |
| 금리 상승기 | 가치, 배당 | 그로스 |

**🎯 구체 증거 — 모멘텀 크래시**:
- Asness et al. 1997: 모멘텀 IC 평균 +0.05
- Daniel & Moskowitz 2016: **폭락 직후 모멘텀 IC = -0.15 ~ -0.30** (정반대)
- → 평균을 내면 모멘텀이 약한 양의 신호처럼 보이지만, **실제는 국면별 양극단**

기존 고정 가중치 모델: 이 양극단을 평균내서 약한 신호로 변환 → 정보 손실.

#### 상황 3 — 계산 비용 vs 표현력 트레이드오프

CSI300 유니버스 setting:
- 종목 수 $N \approx 300$
- 시점 수 $T = 8$
- 특징 수 $F = 158$

**Naive 접근 (모든 것을 한 번에)**:
- 모든 종목·시각을 하나의 시퀀스로: $N \cdot T = 2400$ 길이
- Attention 행렬: $2400^2 = 5,760,000$ 쌍
- **계산 불가** (메모리 + 시간)

**해결**: 어떻게 분해할 것인가? → MASTER 의 답 = **Intra → Inter 2-step**.

### 🔑 핵심 통찰

> 주식 예측은 **3 본질 어려움 + 3 구조 어려움 = 6 개 문제** 의 결합. 단일 trick 으로 못 풀고, 여러 design choice 의 결합이 필요.

## 2. 기존 접근 계보: 진화와 한계

### 2.1 개별 종목 시계열 모델 (LSTM, ALSTM, 2017-2019년대)

**무엇이었나**: LSTM 이나 GRU 로 각 종목의 시간 패턴을 **독립적**으로 학습. 각 종목은 다른 종목을 전혀 참고 X.

```
종목 1: [t=1,2,...,8] → LSTM → 예측
종목 2: [t=1,2,...,8] → LSTM → 예측 (독립)
종목 3: [t=1,2,...,8] → LSTM → 예측 (독립)
...
```

**대표 모델**:
- Vanilla LSTM (Hochreiter & Schmidhuber 1997 → 주식 적용 2017-)
- ALSTM (Attention LSTM): 시간 축에 attention 추가

**왜 부족했나**: 
- 종목 간 상관관계 **완전 무시**
- "삼성전자 급등 → SK하이닉스 follow" 패턴 학습 불가

**남긴 교훈**: 종목 내 시간 패턴 (temporal pattern) 추출 능력은 강하다. 이후 방법들이 이를 기반으로 삼음 (LSTM → encoder 역할).

### 2.2 그래프 기반 종목 상관 (GAT, RSR, 2020-2022년)

**무엇이었나**: Graph Attention Network (GAT) 를 사용해 종목들을 그래프 노드로, 상관관계를 엣지로 모델링.

**2단계 구조**:
```
종목 1: LSTM → 표현 v_1 ─┐
종목 2: LSTM → 표현 v_2 ─┤
종목 3: LSTM → 표현 v_3 ─┼→ GAT (그래프 어텐션) → 갱신된 표현
...                       ┘
```

**대표 모델**:
- RSR (Relational Stock Ranking, 2019): 산업 분류 기반 그래프
- HATS (2020): 다중 관계 그래프
- 다양한 변형들

**왜 부족했나**:
- **(a) 그래프 구조가 사전 정의** (산업 분류 기반) 또는 시간 불변 가정 → 동적 관계 변화 적응 X
- **(b) 종목 간 어텐션이 "같은 시각" 표현끼리만** → cross-time 상관 학습 X
- (c) Symmetric edge 가정 → leader-follower 비대칭 못 잡음

**남긴 교훈**: 종목 간 관계를 어텐션으로 학습하는 방향이 유효함을 입증.

### 2.3 동적 다중 관계 모델 (DTML, 2022-2023년)

**무엇이었나**: Dynamic Temporal Multi-relational Learning. 종목 간 관계를 시간에 따라 **동적으로 학습** + 여러 관계 유형 (동일 산업, 공급망, 지수 소속 등) 동시 모델링.

**개선점**:
- 동적 그래프 (시간에 따라 엣지 변화)
- 다중 관계 (multi-relational)
- Asymmetric 어텐션 (방향성)

**왜 부족했나**:
- 여전히 **시간 정렬 (time-aligned) 가정** 유지: 종목 $i$ 의 시각 $t$ 표현이 종목 $j$ 의 **시각 $t$ 표현**과만 상관된다고 가정.
- 모든 특징을 **동등하게 취급** → 시장 국면별 특징 유효성 변화 포착 X.

**남긴 교훈**: 다중 관계를 학습하는 방향 맞음. 그러나 **"언제" 상관되는지의 차원** 이 빠짐.

### 2.4 기존 방법들의 공통 한계 (Gap)

모든 방법의 공통 아키텍처:
```
"각 종목 → 순차 인코더 (LSTM/Transformer) → 종목 표현 (단일 벡터) → 종목 간 혼합 (graph or attn)"
```

이 패턴에서 **종목 간 혼합 단계가 항상 "같은 시각의 표현" 끼리** 이루어짐. 결과:

> **핵심 gap**: **종목 간 상관관계의 시간 비정렬성 (temporal misalignment)** 과, **시장 국면에 따른 특징 선택의 동적성** 을 **동시에 해결** 하는 아키텍처가 존재하지 않는다.

### 🎯 구체 증거 — 두 gap 의 영향

**Gap 1 (cross-time)**:
- Time-aligned 모델은 시차 효과 모두 손실
- 예: 반도체 장비 → 메모리 반도체의 3일 시차 효과 학습 불가
- 결과: 시차 정보가 큰 신호일 때 (특히 시장 충격 후) 성능 ↓

**Gap 2 (국면 적응)**:
- 고정 가중치 모델은 모멘텀 크래시 같은 국면 전환에 망함
- 평균 IC = 0.05 처럼 보이지만 강세장만 0.08, 폭락장 -0.10 → 위험 ↑

### 🔑 핵심 통찰

> 진화 경로 (LSTM → GAT → DTML → MASTER) 의 각 단계는 **새 차원 추가**: 시간 → 종목 → 동적 관계 → cross-time + 국면. MASTER 는 두 새 차원을 한 번에 추가.

## 3. Stock-level vs Market-level Signal 의 분리

### 3.1 두 종류 신호의 정의

**Stock-level signal** (종목 자체 신호):
- 종목 $n$ 의 가격, 거래량, 기술 지표
- $X \in \mathbb{R}^{N \times T \times F}$, $F = 158$ Alpha 팩터
- 각 종목 고유의 정보

**Market-level signal** (시장 전체 신호):
- 시장 지수 (CSI300, CSI500, CSI800) 의 통계
- $m_\tau \in \mathbb{R}^{63}$
- 모든 종목에 공통 영향

### 3.2 왜 분리하는가

| 분리 이유 | 설명 |
|----------|------|
| **다른 변화 속도** | Stock-level 은 일일 변동, Market-level 은 며칠-주 단위 변동 |
| **다른 역할** | Stock-level = 예측 대상의 raw 정보, Market-level = "어떤 stock 정보 신뢰할까" 조절자 |
| **다른 차원** | Stock = 158 × N × T, Market = 63 (낮은 차원) |
| **다른 신호-잡음 비** | Stock 잡음 ↑, Market 상대적으로 robust |

### 3.3 MASTER 의 분리 + 결합 방식

```
Stock-level X (N × T × 158) ─→ 게이팅 입력
                                  ↑ (조절)
Market-level m_τ (63) ──→ W_g → 게이팅 계수 g (158)
                                  ↓
                                Hadamard 곱
                                  ↓
                              X̂ (재가중치된 X)
                                  ↓
                              [어텐션 단계들]
```

**핵심 design**: Market-level 정보를 **gating signal** 로 사용 (직접 입력으로 안 씀). 이게 **간접 활용** 의 묘수.

### 🔑 핵심 통찰

> Market 정보를 **직접 입력으로 concat** 하면 모델이 무시할 수 있음 (낮은 차원, 다른 분포). **Gating 으로 사용** 하면 모델이 명시적으로 활용 강제. 이게 MASTER 의 design choice.

## 4. MASTER의 gap 해소 전략

MASTER 는 **두 가지 설계 선택**으로 두 gap 을 동시 해소.

### 4.1 선택 1 — 순서를 뒤집는다 (Intra → Inter)

**핵심 idea**: 종목 내 (intra) 시간 집계를 **먼저** 해서 "시간 지역 임베딩 (temporal local embedding)" 을 만든다. 이 임베딩은 $T = 8$ 시간 단계의 정보를 응축하여 "3일 전 신호까지 담은 지역 표현" 이 된다.

**메커니즘**:
1. Intra-stock attention: 각 종목 $j$ 의 시각 $t$ 임베딩 $H_{j,t}$ 가 $t' = 1, \ldots, T$ 정보 모두 흡수
2. Inter-stock attention 시각 $t$: 종목 $i$ 가 $H_{j,t}$ 어텐션 → 종목 $j$ 의 **여러 시각 정보를 간접 소비** → cross-time 상관 자동 모델링

→ **이게 "local embedding as relay"** 의 정확한 원리.

### 4.2 선택 2 — 시장 지수로 필터링한다 (Market-Guided Gating)

**핵심 idea**: 예측 시각 $\tau$ 의 시장 정보 (인덱스 수익률, 변동성 등) $m_\tau$ 를 입력으로 받아, **158개 Alpha 팩터 각각의 "오늘 유효성"** 을 자동으로 조절하는 게이팅 계수 만든다.

**메커니즘**:
1. $m_\tau$ → 선형 변환 → 158차원 로짓 $\ell$
2. $\ell$ → 온도 softmax → 게이팅 계수 $g$ (평균 1)
3. $g$ 가 입력 $X$ 와 element-wise 곱 → $\hat{X}$

→ 강세장에서 중요한 팩터, 폭락장에서 중요한 팩터를 **동적 re-weighting**.

### 4.3 두 선택의 결합

```
m_τ (시장 정보)
  │
  ▼
[게이팅] → g (158차원, 동적 가중치)
  │
  ▼ Hadamard 곱
X̂ (국면 적응된 stock-level 입력)
  │
  ▼ 선형 투영
X̃ ∈ ℝ^(N × T × d)
  │
  ▼ Intra-stock attention (시간 압축)
H ∈ ℝ^(N × T × d)  ← "각 시각에 종목 내 모든 시간 정보 포함"
  │
  ▼ Inter-stock attention (cross-time relay)
Z ∈ ℝ^(N × T × d)  ← "종목간 cross-time 상관 학습됨"
  │
  ▼ Temporal aggregation
e ∈ ℝ^(N × d)
  │
  ▼ Prediction
s ∈ ℝ^N (예측 스코어)
```

**최종**: **시장 국면에 최적화된 특징 집합** 을 가진 종목들이, **시간을 가로질러 서로 정보를 교환** 하는 구조 완성.

## 5. 문제 정식화 (Problem Formulation)

### 5.1 입출력

**입력**:
- $X \in \mathbb{R}^{N \times T \times F}$, $F = 158$ (Alpha158)
- $m_\tau \in \mathbb{R}^{D_m}$, $D_m = 63$

**출력**:
- $s \in \mathbb{R}^N$, 각 종목의 5거래일 후 수익률 예측 스코어

### 5.2 손실 함수

학습 목표 (추정 — 원문 직접 미확인):
$$\mathcal{L} = -\text{IC}(s, y) \quad \text{또는} \quad \mathcal{L} = \frac{1}{N}\sum_n (s_n - y_n)^2$$

(여기서 $y$ 는 실제 5일 후 수익률)

### 5.3 평가 metric

- IC, IC_IR (statistical)
- Rank IC, Rank IC_IR (rank-based statistical)
- 누적 수익률, Sharpe (portfolio)

## 6. 핵심 한 문장

> 본 논문이 푸는 문제는 **(i) 종목 간 cross-time 상관** 과 **(ii) 시장 국면별 특징 유효성** 을 동시에 모델링하는 것이고, 기존 방법들 (ALSTM → GAT → DTML) 은 각각 한 차원씩 보강했지만 둘을 동시 해결한 첫 모델이 MASTER 이다.

## 7. 자기점검

### 핵심 5가지

1. **주식 예측의 본질적 어려움 3 + 구조적 어려움 3?**
2. **기존 모델 (LSTM → GAT → DTML) 의 진화 단계와 각 한계?**
3. **Cross-time correlation 의 정확한 의미와 학계 증거?**
4. **Stock-level vs Market-level signal 분리의 이유와 결합 방식?**
5. **MASTER 의 두 design choice 와 결합 효과?**

### 답변

1. **본질**: (i) 낮은 SNR (신호 ≪ 잡음, ~1:20), (ii) Non-stationary (시간 분포 변화), (iii) Fat-tail (극단 값 ↑). **구조**: (i) Cross-time correlation (시차 효과), (ii) 시장 국면별 특징 유효성 변화 (모멘텀 크래시 등), (iii) 계산 vs 표현력 trade-off ($(NT)^2 = 5.76M$ 쌍 계산 불가). 6개 어려움의 결합이라 단일 trick 으로 안 풀림.

2. **LSTM (2017-)**: 각 종목 독립 시간 모델링, 종목간 X. 한계: 종목 상관 무시. **GAT (2020-)**: 종목 그래프 + 어텐션, time-aligned. 한계: 사전 그래프, cross-time X. **DTML (2022-)**: 동적 다중 관계 + 비대칭. 한계: 여전히 time-aligned, 특징 균등 취급. 진화: 시간 → 종목 → 동적 → 국면 + cross-time (MASTER).

3. **정확한 의미**: 종목 $i$ 의 시각 $t$ 신호와 종목 $j$ 의 **시각 $t' \neq t$** 신호 사이의 상관. **학계 증거**: (i) Eun & Shim 1989 미국→일본 0-2일 시차, (ii) Forbes & Rigobon 2002 위기 시 1-5일 전염, (iii) 반도체 공급망 (장비→메모리) 3일 시차, (iv) 코로나 2020-Q1 미국→중국 1-3일 follow. 학계의 **stylized fact**.

4. **분리 이유**: (i) 다른 변화 속도 (stock 일일, market 주 단위), (ii) 다른 역할 (stock = raw 정보, market = 조절자), (iii) 다른 차원 (158 vs 63), (iv) 다른 신호-잡음 비. **결합 방식**: Market 정보를 **gating signal** 로 사용 → 직접 입력으로 안 쓰고 stock 정보의 가중치 조절. 이게 "간접 활용" 의 묘수 — 직접 입력으로 concat 하면 모델이 무시 가능, gating 으로 사용하면 명시적 활용 강제.

5. **Choice 1 (Intra → Inter)**: 종목 내 시간 압축으로 local embedding 생성 → inter-stock 에서 cross-time 자동 모델링 (relay). **Choice 2 (Market-Guided Gating)**: $m_\tau$ → 158 팩터 동적 가중치 → 국면별 특징 적응. **결합 효과**: 국면 적응 된 종목 정보가 cross-time 교환됨 → 두 gap (cross-time + 국면) 동시 해결. 결과: +13% statistical, +47% portfolio metric 개선.
