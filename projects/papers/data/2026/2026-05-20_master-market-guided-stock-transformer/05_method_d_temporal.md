> **배경 사다리**: ① Cross-Entropy Loss = 분류 문제의 손실함수. ② MSE (Mean Squared Error, 평균제곱오차) = 회귀 문제에서 예측값과 실제값의 차이를 제곱해 평균. ③ Rank IC = 예측 순위와 실제 수익률 순위의 Spearman 상관계수. 이 절은 앞 세 파일의 연속이므로 $H$, $Z$ 등 기호가 앞 파일에서 이어진다.

### 🌱 Temporal Aggregation — 일상 비유

**한 줄로**: "8일치 정보를 '오늘 입장에서 어떤 과거가 가장 중요한가?' 라는 질문으로 한 줄 요약".

- **다른 방법**: 8일치를 산술 평균 → 모든 날을 똑같이 취급 (구식, 정보 손실)
- **MASTER 방법**: 가장 최신날(t=T) 임베딩이 Query → "내가 예측하는 입장에서 며칠 전이 중요해?" 라고 묻고 차등 가중
- **결과**: 1개의 종합 벡터 $e_n \in \mathbb{R}^d$ → 이 벡터 → 선형 레이어 → 1개의 수익률 점수 $s_n$

**왜 마지막 시각 Query**: 예측은 "지금 이후 5일"이 타깃이므로, 가장 최신 시점이 가장 예측과 관련 깊다. 그가 "과거의 어떤 패턴이 지금 상황과 닮았나?" 를 골라낸다.

## 1. 단계 4: 시간 집계 (Temporal Aggregation)

### 무엇을 하는가

교차 종목 임베딩 $Z \in \mathbb{R}^{N \times T \times d}$에서, 각 종목 $n$에 대해 "마지막 시각($t=T$)의 임베딩이 전체 T개 시간 임베딩을 쿼리"하여 하나의 종합 종목 임베딩 $e_n \in \mathbb{R}^d$을 만든다.

### 수학적 구조

$$e_n = \text{Attn}\left(Z_{n,T}, Z_{n,:}, Z_{n,:}\right)$$

| 기호 | 의미 |
|------|------|
| $Z_{n,T}$ (Query) | 종목 $n$의 가장 최신(예측 직전) 시각의 임베딩이 "과거를 어떻게 요약할지" 질문 |
| $Z_{n,:}$ (Key, Value) | 종목 $n$의 모든 $T$개 시각 임베딩 |
| $e_n$ | 최신 시각이 과거를 취사선택해 만든 종합 주식 표현 |

**일상 비유**: 8일치 일기를 다 쓴 후, 오늘(마지막 날) 입장에서 "내일 시험에 가장 중요한 내용이 무엇이었을까?"를 묻고 과거 7일 일기에서 관련 내용을 골라 요약본을 만드는 것이다.

**왜 이 형태**: 단순 평균(mean pooling) 대신 어텐션 기반 집계를 쓰는 이유는, 최신 시각이 "지금 시점에서 중요한 과거"를 능동적으로 선택할 수 있기 때문이다. 예측 시점에 가장 관련 있는 과거 패턴이 강조된다.

**조심할 점**: 이 단계에서 Query가 $Z_{n,T}$ 단 하나뿐이므로 어텐션 출력 $e_n$도 단일 벡터다. 이전 단계처럼 $T$개의 임베딩을 유지하지 않는다. 즉, 이 단계는 정보를 요약·압축하는 병목이다.

## 2. 단계 5: 예측 (Prediction)

$$s_n = W_p e_n + b_p$$

$s_n \in \mathbb{R}$이 종목 $n$의 "5거래일 뒤 수익률" 예측 스코어다. $s_n$이 높을수록 수익률이 높을 것으로 예측.

**실제 사용법**: 모든 종목의 $s_n$을 내림차순으로 정렬해 상위 $k$%를 롱 포지션(매수)으로 구성하는 포트폴리오를 만든다. 이 과정이 IC/Rank IC와 포트폴리오 성과를 연결한다.

## 3. 학습 설정

### 3.1 데이터 분할

| 기간 | 용도 |
|------|------|
| Q1 2008 ~ Q1 2020 | 학습 (Train) |
| Q2 2020 | 검증 (Validation) |
| Q3 2020 ~ Q4 2022 | 테스트 (Test) |

- 총 학습 기간: 약 12년
- 테스트 기간: COVID-19 후반부 + 2021 강세장 + 2022 하락장 포함 (다양한 시장 국면 포함)

### 3.2 입력 데이터

**종목 특징**:
- 사용 팩터: **Alpha158** — Qlib 프레임워크의 158개 알파 인자
- Alpha158은 MACD, RSI, Williams %R 등 기술적 지표와 가격-거래량 기반 팩터를 포함하는 산업 표준 팩터 라이브러리
- **정규화**: RobustZScoreNorm (학습 전체 종목 기준 중간값/MAD 추정, 이상값 ±3 클리핑)
- **레이블**: 5거래일 수익률, CSZscoreNorm(날짜별 단면 표준화) + 극단값 5% 제거

**시장 특징**:
- 63차원 $m_\tau$ (앞서 설명)
- 사전 처리 없이 raw 또는 간단한 스케일링 적용 추정 (원문 미확인)

### 3.3 조기 종료 (Early Stopping)

학습 손실 임계값(training loss threshold) 기반 조기 종료를 사용한다. 검증 세트의 처리 오류(이전 공개 버전에서 발견된 이슈)가 있었지만, 조기 종료 기준이 "검증 손실"이 아닌 "학습 손실 임계값"이므로 체크포인트와 실제 결과에는 영향 없음 (GitHub README 기준).

### 3.4 하이퍼파라미터

- $T = 8$ (lookback 창)
- $\beta$ 최적값: Figure 4 ablation으로 결정 (구체적 값 원문 미확인)
- $(N_1, N_2)$ 최적 조합: ablation으로 결정 (구체적 값 원문 미확인)
- 모델 hidden dimension $d$: 원문 미확인
- 옵티마이저: Adam 계열 추정 (원문 미확인)

## 4. 전체 처리 흐름 요약 (치수 추적)

```
X ∈ ℝ^(N × T × F)     시장벡터 m_τ ∈ ℝ^63
        │                      │
        └──────────────────────┘
               ↓ 게이팅
       X̂ ∈ ℝ^(N × T × F)
               ↓ 선형 투영 + Intra-stock attention
        H ∈ ℝ^(N × T × d)
               ↓ Inter-stock attention (T번 수행)
        Z ∈ ℝ^(N × T × d)
               ↓ 시간 집계 (마지막 시각 → 과거 어텐션)
        e ∈ ℝ^(N × d)
               ↓ 선형 레이어
        s ∈ ℝ^N   →   순위화 → 포트폴리오
```

## 5. 핵심 한 문장

> 시간 집계 단계는 "최신 시각이 과거를 취사선택해 요약"하는 어텐션으로 구현되어, 예측 직전 시각의 맥락에서 가장 유용한 과거 신호를 선별하는 방식으로 마무리되는 설계다.
