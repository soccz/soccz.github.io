# 07_limits — 가정·한계·반박

## 📌 이 챕터 다 읽으면 알 수 있는 것

- MASTER 의 명시된 가정 3가지 + 암묵적 가정 3가지
- 반박 가능한 지점 4가지 (각각의 검증 방법 포함)
- 재현성 평가 (코드, 데이터, 검증 데이터 오류)
- Look-Ahead Bias 위험 검토
- 가장 강한 한계 5가지의 종합

---

> **배경 사다리**: ① **도메인 이전(Domain Transfer)** = 한 시장에서 학습한 모델을 다른 시장에 적용. ② **분포 이동(Distribution Shift)** = 학습 데이터와 테스트 데이터의 통계적 성질이 다른 상황. ③ **과적합(Overfitting)** = 모델이 학습 데이터의 잡음까지 외워 새 데이터에 일반화 못함. ④ **Look-Ahead Bias** = 미래 정보가 과거 학습에 누출되는 버그. ⑤ **거래 비용 (Transaction Cost)** = 매매 시 발생하는 수수료 + 슬리피지. 보통 한 번 매매당 0.1-0.3%. ⑥ **Herding behavior** = 군집 행동. 개인 투자자 비중 높은 시장에서 강하게 나타남.

### 🌱 한계 분석 — 일상 비유

학생 (MASTER) 의 성적이 좋아도, 다음 의심들 가능:

| 의심 | 비유 |
|------|------|
| "우리 학교만 잘하나?" | 단일 시장 (중국) 만 테스트 |
| "한 과목만 잘하나?" | Alpha158 만 사용 (펀더멘털 X) |
| "친구 도움 받았나?" | Cross-time 효과의 isolation 약함 |
| "시험 비용 안 계산?" | 거래 비용 미반영 |
| "다음 학기엔?" | 시장 regime change 검증 미달 |

→ 본 챕터는 **5 가지 의심을 정직하게 인정** 하고 **반박 가능한 검증** 제시.

## 1. 명시된 가정 (Explicit Assumptions)

### 1.1 가정 A — Alpha158 특징으로 충분하다

**가정**: 입력 특징으로 Alpha158 만 사용. 이것이 "주식의 역사적 패턴을 잘 포착" 한다고 암묵적 가정.

**Alpha158 의 한계**:
- **기술적 분석 기반** (가격, 거래량 파생 지표)
- **펀더멘털 정보 X** (실적, 재무비율, ROE, PER, PBR)
- **뉴스 감성 X** (텍스트 정보)
- **거시경제 지표 X** (CPI, GDP, 환율)

**🎯 구체 영향**: 
- Fundamental 신호가 강한 시기 (예: 가치 투자 부활 2022) 에 모델 성능 ↓ 가능
- 텍스트 정보가 시장 영향 ↑ 인 시기 (예: 트위터 트레딩 2021) 에 성능 ↓

**잠재 개선**: Alpha360 (펀더멘털 추가), Alpha558 (sentiment 추가), 또는 다중 데이터 소스 결합.

### 1.2 가정 B — T=8 lookback 으로 충분하다

**가정**: 단 8 거래일 (약 1.5주) 의 과거 데이터로 5 거래일 뒤 수익률 예측.

**한계**:
- **중장기 모멘텀 (12개월) 효과 못 잡음**: Jegadeesh & Titman 1993 의 12-1 모멘텀 (12개월 누적 - 1개월 reversion) 학습 불가
- **계절성 효과 (분기 결과 발표)**: 분기별 패턴 학습 X
- **장기 추세 변화 (1년 이상)**: 시장 regime change 학습 X

**🎯 구체 영향**:
- 모멘텀 크래시 (2022 같은 큰 regime change) 시 모델이 빠르게 적응 못 할 위험
- 분기 보고서 효과 (실적 발표 → 후속 가격 효과) 손실

**잠재 개선**: 
- Multi-scale lookback: $T = 8$ (단기) + $T = 60$ (중기) + $T = 252$ (장기) 결합
- Hierarchical attention (단기 정밀 + 장기 sparse)

### 1.3 가정 C — 중국 시장의 상관관계 안정성

**가정**: 모델이 Q1 2008 ~ Q1 2020 의 12년 데이터로 학습한 상관관계 패턴이 Q3 2020 ~ Q4 2022 에도 유효.

**도전 사례**:
| 사건 | 영향 |
|------|------|
| **COVID-19 (2020)** | 시장 구조 변화 + 비대면 산업 부상 |
| **2021년 교육·기술 규제** | 알리바바, 텐센트 급락 → 섹터 관계 변화 |
| **2022 금리 상승기** | 가치주 vs 그로스주 관계 역전 |
| **지수 리밸런싱** | CSI300 구성 종목 변화 |

**🎯 구체 영향**: 학습 기간의 안정 가정이 테스트 기간에 깨지면 → 모델이 과거 패턴에 묶여 새 환경에 적응 X.

**잠재 개선**: Online learning, regime-aware models, transfer learning 기법.

## 2. 암묵적 가정 (Implicit Assumptions)

### 2.1 가정 D — 단일 시장 가정

**가정**: 오직 **중국 A주 시장만 테스트**. 미국 (S&P500), 한국 (KOSPI), 일본 (Nikkei), 글로벌 시장에서의 유효성 **미검증**.

**왜 문제인가**:
- 시장마다 거래 규칙 다름 (T+1 vs T+0, 매도 제한 등)
- 투자자 구성 다름 (중국 개인 70-80% vs 미국 기관 80%)
- 정보 효율성 다름 (선진 시장 vs 신흥 시장)
- 시장 미시구조 다름 (호가 단위, 거래 시간)

**🎯 구체 증거 — 시장 차이**:
| 시장 | 개인 투자자 비중 | 정보 효율성 |
|------|----------------|------------|
| 중국 A주 | 70-80% | 중간 |
| 한국 KOSPI | 40-60% | 중상 |
| 미국 S&P | 10-20% | 상 |
| 일본 Nikkei | 20-30% | 중상 |

→ 중국에서 좋은 모델이 미국에서도 좋다는 보장 X.

### 2.2 가정 E — 동일 게이팅 계수 가정

**가정**: 모든 $N$ 개 종목에 **동일한 게이팅 계수 $g$** 를 적용. "시장 국면이 모든 종목에 동일하게 영향" 가정.

**현실과의 충돌**:
- **금리 상승 시**: 성장주 (그로스) 하락 ↑, 가치주 영향 ↓ (반대 방향)
- **산업별 베타 차이**: 베타 1.5 종목과 0.5 종목은 같은 국면에 다르게 반응
- **규제 영향**: 특정 섹터 (예: 교육, 빅테크) 만 충격받는 경우

**🎯 구체 영향**: 단일 게이팅이 이런 섹터별·종목별 차이를 못 잡음 → 1차 근사 정확도 한계.

**잠재 개선**: 
- Hierarchical gating: 시장 + 섹터 + 종목
- Mixture of Experts (MoE): 종목 유형별 다른 expert

### 2.3 가정 F — 거래 비용 무시 가정

**가정**: 포트폴리오 지표 계산 시 거래 비용 (수수료, 슬리피지) **미포함**.

**실무 영향**:
- 중국 A주 거래 비용: **약 0.15-0.25%** 매매당
- 회전율 (turnover) 높을수록 비용 ↑
- MASTER 가 매일 portfolio 재구성 시 연간 회전율 수백%
- **연간 거래 비용 ≈ 5-10%** 가능

**🎯 구체 영향**: +47% portfolio 개선의 상당 부분이 거래 비용으로 잠식. 실제 운용 가치 < 보고값.

**잠재 개선**: 
- Turnover penalty in loss function
- Trade frequency reduction (예: 주간 rebalance 대신 월간)

## 3. 반박 가능한 지점

### 3.1 반박 1: Cross-Time 상관 학습 vs 다른 이유

**반박의 핵심**: MASTER 의 성능 향상이 실제로 "cross-time 종목 상관 포착" 때문인지, **다른 이유** (단순히 intra-stock attention 의 강력함, 더 많은 파라미터) 인지 구분 어려움.

**기존 ablation 의 한계**:
- "MASTER = 시장 게이팅 + intra + inter" 라는 결합 효과만 보고
- 각 컴포넌트의 isolated contribution 불명확
- 특히 **"inter 없는 MASTER" (intra 만)** 와의 직접 비교 부족

**검증 방법**:
- $N_2 = 0$ ablation (inter 제거) → intra 만의 효과 측정
- $N_1 = 0$ ablation (intra 제거) → inter 만의 효과 측정
- 두 ablation 의 정확한 수치 비교 → cross-time relay 의 분리된 기여 quantify

**🔑 핵심 통찰**: 원문 ablation 이 이를 명시적으로 다루는지 미확인. 명확한 분리가 없다면 Claim 1 의 mechanism 근거 약함.

### 3.2 반박 2: 중국 시장 개인투자자 특성으로 인한 과대 추정

**반박의 핵심**: 중국 A주 시장은 **개인 투자자 비중 70-80%** + **군집 행동 (herding) 강함**. 이 환경에서 포착된 종목 상관이 다른 시장에서도 작동할 가능성 ↓.

**🎯 구체 증거**:
- Bian, Da, Lou, Zhang 2022: 중국 개인 투자자의 herding 가 정보 효율성을 낮춤
- Allen et al. 2007: 중국 시장이 다른 신흥 시장보다 retail-driven
- Lin, Ban 2024: 중국 시장의 lead-lag 효과가 미국보다 큼

**검증 방법**: 동일 구조를 S&P500 (개인 ↓, 정보 효율 ↑) 또는 KOSPI200 (중간) 에 적용 → 개선폭 유지 여부 확인.

### 3.3 반박 3: 단순 모델 (XGBoost) 의 baseline 약화 가능성

**반박의 핵심**: 만약 baseline 모델들이 충분히 튜닝되지 않았다면 → MASTER 우위 과대평가.

**검증 방법**:
- 각 baseline 의 하이퍼파라미터 검증 절차 명시 (원문 미확인)
- AutoML 또는 Bayesian optimization 으로 baseline 재튜닝
- 동일 데이터·동일 튜닝 시간 보장

### 3.4 반박 4: Test 기간 (2020-2022) 의 specific 시기 효과

**반박의 핵심**: Test 기간이 COVID 회복 (2020-Q3) + 강세장 (2021) + 약세장 (2022) 의 특수 조합. 다른 test 기간에선 다른 결과 가능.

**🎯 구체 증거**:
- 2008 금융위기, 2015 중국 증시 폭락 같은 다른 시기엔 모델 성능 다를 가능성
- 모델이 2020-2022 의 특정 패턴 (COVID 회복, 메가캡 주도) 에 적응했을 가능성

**검증 방법**:
- Walk-forward validation: 여러 test 시기에 대해 반복 평가
- 다른 기간 (예: 2015-2018) 의 out-of-sample 검증

## 5. 타임리프트 위험 (Look-Ahead Bias)

### 5.1 일반적 위험

주가 예측 논문의 공통 위험으로, **미래 데이터가 과거 학습에 누출** 되는 문제. 

**대표 사례**:
- Normalization 통계 (mean, std) 를 전체 데이터에서 계산 → 학습 시 미래 정보 누출
- Feature engineering 시 미래 가격 사용 (예: 5일 후 수익률을 특징으로 사용)

### 5.2 MASTER 의 처리

**RobustZScoreNorm 의 중간값/MAD 계산**:
- "학습 전체 데이터" (Q1 2008 ~ Q1 2020) 에서 추정한 후 테스트 (Q3 2020 ~ Q4 2022) 에 적용.
- **표준적인 방법** 이며 look-ahead bias 방지.

**잠재 미세 이슈**:
- 학습 데이터가 Q1 2008 ~ Q1 2020 이고 테스트가 Q3 2020 ~ Q4 2022
- **검증 Q2 2020 의 정규화 파라미터** 가 학습 데이터 전체를 보고 결정된다는 점
- 이론적으로 미세한 영향 가능 (실무 영향 미미)

**검증**: Rolling window 정규화 (학습 시점까지의 데이터만 사용) 로 비교 → 결과 변화 미미 예상.

### 🔑 핵심 통찰

> MASTER 의 look-ahead bias 처리는 standard. 우려할 수준 아님. 더 우려할 부분은 **feature engineering** 시 Alpha158 자체의 계산이 robust 한지 (Qlib 표준 사용 → robust).

## 6. 요약: 가장 강한 한계 5가지

> **주요 한계**:
> 1. **중국 단일 시장 특화** → 일반화 가능성 불명확 (US, KR, JP 미검증)
> 2. **T=8 × Alpha158** 의 좁은 입력 공간 (중장기 모멘텀 + 펀더멘털 + 뉴스 X)
> 3. **모든 종목 동일 게이팅** 의 oversimplification (섹터·종목별 차이 무시)
> 4. **거래 비용 미반영** → 실무 적용 시 성과 축소 가능 (회전율 ↑ 시 5-10% 비용)
> 5. **Cross-time 상관 포착의 mechanism isolation** 부족 (Intra ablation 직접 수치 미확인)

### 한계의 우선순위

| 순위 | 한계 | 영향 |
|------|------|------|
| 1 | 단일 시장 | 일반화 ↓↓↓ |
| 2 | 거래 비용 | 실무 가치 ↓↓ |
| 3 | 좁은 입력 (Alpha158) | 정보 손실 ↓↓ |
| 4 | 동일 게이팅 | 정확도 ↓ |
| 5 | Mechanism isolation | 과학적 강도 ↓ |

→ **후속 연구 우선순위**: 단일 시장 → 거래 비용 → 다양 입력 → hierarchical gating → ablation.

## 7. 핵심 한 문장

> MASTER 는 강력한 정량 증거에 기반한 좋은 논문이지만, **5가지 한계** (단일 시장, 좁은 입력, 동일 게이팅, 거래 비용, mechanism isolation) 이 후속 연구의 빈 공간을 명확히 정의한다. 각 한계는 반박 가능한 검증 방법이 있으며, 가장 시급한 검증은 **외부 시장 (US, KR) 검증** 과 **거래 비용 반영 백테스팅** 이다.

### 답변

1. **A. Alpha158 충분성**: 기술 분석 한정 → 펀더멘털/뉴스/거시 누락 → 가치 투자 시기 또는 텍스트 정보 ↑ 시기에 성능 ↓. **B. T=8 충분성**: 중장기 모멘텀 (12개월), 계절성, regime change 못 잡음. **C. 상관관계 안정성**: 2008-2020 학습 → 2020-2022 적용. COVID, 규제, 금리 변화로 상관 변화 가능. 위험: 학습 시기와 다른 환경에 적응 X.

2. **D. 단일 시장**: 중국 70-80% 개인 투자자 → US/KR/JP 와 시장 미시구조 다름. 영향: 외부 시장 적용 시 성능 ↓ 가능. **E. 동일 게이팅**: 모든 종목에 같은 $g$ → 섹터별 차이 (금융 vs IT) + 베타 차이 무시. 영향: 1차 근사 정확도 한계. **F. 거래 비용 무시**: 중국 0.15-0.25% × 회전율 → 연간 5-10% 비용. 영향: +47% portfolio 의 상당 부분 잠식 → 실제 운용 가치 < 보고값.

3. **반박 1 (Cross-time mechanism isolation)** 이 가장 critical. 왜냐하면: (i) MASTER 의 핵심 contribution claim 이 cross-time 효과인데, (ii) 이게 진짜 cross-time 때문인지 intra 의 단순 강력함인지 분리 ablation 부족 → (iii) 논문의 mechanism 입증이 statistical 우위에 비해 약함. 다른 반박 (단일 시장, baseline 튜닝, test 기간) 은 후속 검증으로 보완 가능하지만, mechanism 은 본 논문의 핵심 주장이라 더 critical.

4. **강점**: (i) MIT 라이선스 코드 + 사전학습 체크포인트 4개, (ii) Qlib 표준 데이터 사용, (iii) 검증 데이터 오류 발견 + 정직한 보고 + 학습 손실 임계값 early stopping 으로 robust, (iv) GitHub issues 활용. **약점**: (i) 원본 데이터 사유 (proprietary), (ii) Qlib 버전 호환성 복잡, (iii) MASTER 의 ±std 직접 미확인, (iv) baseline 튜닝 procedure 미명시.

5. **(1) 외부 시장 검증 (US S&P, KR KOSPI, JP Nikkei)**: 일반화 가능성 입증. **(2) 거래 비용 반영 백테스팅**: 실무 가치 quantify (회전율 패널티 포함). **(3) 다양 입력 (펀더멘털, 뉴스 sentiment)**: 입력 공간 확장으로 신호 다양화. **(4) Hierarchical gating (시장 + 섹터 + 종목)**: 단일 게이팅의 oversimplification 보완. **(5) Mechanism isolation ablation**: Intra/Inter 각각의 contribution 정확 수치 보고 + 역순 (Inter→Intra) 비교.
