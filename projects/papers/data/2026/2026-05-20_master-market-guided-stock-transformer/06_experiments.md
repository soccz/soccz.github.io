> **배경 사다리**: ① **IC (Information Coefficient)** = 예측 스코어와 실제 수익률의 Pearson (또는 Spearman) 상관계수, 범위 $[-1, 1]$, 0.05 이상이면 실무에서 유의미. ② **Rank IC** = IC 를 순위에 기반해 계산 — outlier 에 더 robust. ③ **IR (Information Ratio)** = IC 의 평균/표준편차, Sharpe ratio 와 유사한 개념 (시간에 따른 안정성). ④ **포트폴리오 지표** = 상위 $k\%$ 종목을 매수했을 때의 누적 수익률, Sharpe ratio, 최대 낙폭 (MDD). ⑤ **베이스라인 (Baseline)** = 비교 대상 모델 — 새 모델의 우위를 보이려면 베이스라인보다 좋아야. ⑥ **Ablation study** = 모델 구성요소를 제거/변경해서 각 부분의 기여도 측정. ⑦ **웹 검색 스니펫** 출처 표기: 아래 수치 중 "(검색 스니펫)" 이 붙은 것은 원문 직접 확인이 아닌 인덱싱된 텍스트에서 확인된 수치.

## 1. 데이터셋

### 1.1 CSI300 — 중국 대형주 벤치마크

- **정의**: 중국 상하이·선전 거래소 상위 **300개 종목** 으로 구성된 지수
- **이 논문에서**: $N \approx 300$ 종목, 매 예측 날짜마다 약 300개 종목이 입력
- **특징**:
  - 중국 대형주 시장의 주요 벤치마크
  - 유동성 ↑, 기관 투자자 비중 ↑
  - 가격 데이터 깨끗 (price gap, illiquidity 적음)
- **왜 이 데이터인가**:
  - 중국 퀀트 연구의 표준 유니버스
  - Alpha158 팩터 라이브러리가 이 유니버스 기준으로 설계
  - 결과의 실무 재현 가능성 ↑

### 1.2 CSI800 — 대·중·소형주 혼합

- **정의**: 상위 800개 종목 = CSI300 (대형주 300) + 중소형주 500
- **이 논문에서**: $N \approx 800$ 종목
- **특징**:
  - CSI300 보다 **유동성 ↓**, **변동성 ↑**
  - 중소형주의 가격 jump 더 흔함
  - 정보 비대칭성 (작은 종목의 정보 누출 ↑) 가능성
- **결과 비교**:
  - 논문: CSI300 에서 더 좋은 성능
  - 이유: 유니버스 클수록 (N=800) 상관관계 패턴 복잡 → 모든 모델 성능 저하
  - 의미: MASTER 의 inter-stock attention 도 $N$ 이 클수록 학습 어려움

### 🎯 구체 증거 — CSI300 vs CSI800 의 분포 차이

| 항목 | CSI300 | CSI800 |
|------|--------|--------|
| 일일 거래량 평균 | 높음 | 중간 (소형주 포함) |
| 가격 변동성 (std) | 1.5% | 2.5% (소형주 ↑) |
| Fat-tail (kurtosis) | 5-7 | 10-15 (소형주 ↑) |
| 결측치 (illiquid) | < 1% | 3-5% (소형주 ↑) |

→ CSI800 이 더 어려운 환경. 모든 모델 성능 저하 예상.

### 1.3 Alpha158 특징 집합 — 정밀 구성

총 **$F = 158$ 개 팩터** (기술적 지표 기반). Qlib 오픈소스 프레임워크의 표준 팩터.

**팩터 카테고리** (각 카테고리에 여러 변형 존재):

| 카테고리 | 예시 | 비중 |
|---------|------|------|
| 모멘텀/추세 | MACD, RSI, Williams %R, 단기-장기 이동평균 비율 | ~25% |
| 변동성 | Bollinger Bands, ATR, 가격 표준편차 (5/10/20/60일) | ~20% |
| 거래량 | VWAP, OBV, volume 비율, MFI | ~20% |
| 가격 모양 | high-low 차이, candle 패턴, 가격 변화율 | ~20% |
| 기술 진동자 | KDJ, CCI, Williams%R, 기타 | ~15% |

**편향 가능성**:
- Alpha158 이 **기술적 분석 기반** 에 특화
- **펀더멘털 팩터** (PER, ROE, 매출 성장률 등) 포함 X
- MASTER 의 결과는 Alpha158 생태계 안에서의 성능 → 펀더멘털 신호는 미반영
- 잠재 확장: Alpha360 (펀더멘털 추가), Alpha558 (sentiment 추가) 사용 가능

### 🔑 핵심 통찰

> Alpha158 은 강력한 baseline 이지만 **단일 정보원**. MASTER 의 진정한 평가는 **다양한 팩터 라이브러리** 에서의 robustness — 후속 연구 방향.

## 2. 베이스라인 구성

| **LSTM** | RNN 계열 | ✓ (순차) | ✗ | ✗ |
| **GRU** | RNN (경량) | ✓ (순차) | ✗ | ✗ |

### 2.2 베이스라인 진화 경로

```
시점 모델링만 (LSTM, GRU, TCN, Transformer)
        ↓

        ↓
+ 동적 학습 가능 관계 (DTML)
        ↓
+ 시장 국면 적응 + Cross-time relay (MASTER) ★
```

→ MASTER 는 DTML 위에 **(i) 시장 게이팅, (ii) Intra→Inter 순서로 cross-time relay** 추가.

### 2.3 베이스라인 공정성 평가

| 평가 항목 | 평가 |
|----------|------|

| DTML = 기존 SOTA | ✓ (명시) |

## 3. 평가 지표 — 6 metric 의 정밀 해석

### 3.1 6 metric 분류

| 분류 | 지표 | 설명 | 범위 | 좋음 |
|------|------|------|------|------|
| **Statistical (예측)** | IC | Pearson 상관 (예측 vs 실제) | $[-1, 1]$ | ↑ |
| | IC_IR | IC 의 평균/std (시간 안정성) | $[0, \infty)$ | ↑ |
| | Rank IC | Spearman 상관 (순위 기반) | $[-1, 1]$ | ↑ |
| | Rank IC_IR | Rank IC 의 평균/std | $[0, \infty)$ | ↑ |
| **Portfolio (운용)** | 누적 수익률 | 상위 $k\%$ 매수 시 누적 수익 | $\mathbb{R}$ | ↑ |
| | 포트폴리오 Sharpe | 위험 대비 수익률 | $\mathbb{R}$ | ↑ |

### 3.2 🔣 각 metric 4-단 풀이

| 지표 | 수식 | 직관 | 임계값 |
|------|------|------|--------|
| IC | $\text{corr}(s, y)$ | 예측 vs 실제의 직접 상관 | 0.05 ↑ 유의 |
| IC_IR | $\frac{\bar{\text{IC}}}{\text{std}(\text{IC})}$ | IC 의 시간적 일관성 | 0.5 ↑ 유의 |
| Rank IC | $\text{corr}(\text{rank}(s), \text{rank}(y))$ | 순위만 본 상관 | 0.05 ↑ 유의 |
| Rank IC_IR | $\frac{\bar{\text{RankIC}}}{\text{std}(\text{RankIC})}$ | Rank IC 안정성 | 0.5 ↑ 유의 |
| 누적 수익률 | $\prod_t (1 + r_t^{top-k}) - 1$ | 상위 종목 누적 수익 | + (양수) 면 ↑ |
| Sharpe | $\frac{\bar{r}_{top-k} - r_f}{\sigma}$ | 위험 조정 수익 | 1.0 ↑ 우수 |

### 3.3 IC vs Rank IC 의 차이

**예시**: 5종목, 실제 수익률 = (3%, 1%, -1%, -3%, 5%), 예측 = (4%, 0%, -2%, -4%, 5%)

- **IC (Pearson)**: 거의 1.0 (절대값도 잘 맞음)
- **Rank IC (Spearman)**: 1.0 (순위 완전 일치: 5,4,3,1,2 vs 5,4,3,1,2)

**예시 2**: 실제 = (3%, 1%, -1%, -3%, 5%), 예측 = (30%, 10%, -10%, -30%, 50%) (스케일만 다름)

- **IC**: 1.0 (Pearson 은 스케일 무관)
- **Rank IC**: 1.0

**예시 3**: 실제 = (3%, 1%, -1%, -3%, 5%), 예측 = (0.04%, 0.02%, 0%, -0.02%, 0.05%) (스케일 다르고 부호도 약화)

- **IC**: ~1.0
- **Rank IC**: 1.0 (순위는 같음)

→ **차이점**: Rank IC 는 **순위 보전** 만 측정, IC 는 선형 관계 측정. 포트폴리오 운용은 **순위 기반** 이므로 Rank IC 가 더 직접적 metric.

### 🔑 핵심 통찰

> 6 metric 의 함의: **Statistical** (IC, Rank IC) 은 모델의 신호 강도, **IR** 은 시간적 안정성, **Portfolio** 는 실무 운용 가치. 이 3 그룹이 다 우위면 진짜 좋은 모델.

## 4. 주요 결과

### 📖 Table 2 (CSI300 결과) 정밀 읽는 법

**무엇이 표시되나**:
- **행**: 8개 모델 (XGBoost, LSTM, GRU, TCN, Transformer, GAT, DTML, **MASTER**)
- **열**: 6개 metric (IC, IC_IR, Rank IC, Rank IC_IR, 누적 수익률, Sharpe)
- **셀**: 평균값 ± 표준편차 (다중 seed 평균, 보통 3-5 seed)

**어디를 봐야 하나 (5 단계)**:

1. **MASTER 행 vs DTML 행**: 모든 6개 metric 에서 MASTER > DTML. **이게 "기존 SOTA 대비 우위" 의 핵심 증거**.
2. **IC vs Rank IC**: IC 차이는 작지만 Rank IC 차이가 클 수 있음 → MASTER 가 "방향성" 은 비슷해도 "순위" 를 더 잘 맞춤 (포트폴리오 운용에 유리).
3. **IC vs IC_IR**: 평균만 좋은 게 아니라 IR 도 좋다면 → **시간적으로 일관된 우위** (특정 시기만 좋은 게 아님).
4. **포트폴리오 metric**: +47% 평균 개선 → IC 가 약간만 좋아도 상위 종목 선별에서 큰 차이로 증폭됨.
5. **Transformer 행**: 단일 종목 attention 만으로는 한계 → 종목 간 attention 의 가치 입증.

**숨은 함정**:
- **표준편차 ± 값**: ± 큰 baseline (예: Transformer 0.047 ± 0.007) 은 seed sensitivity 큼 → MASTER 가 **일관성** 도 더 좋은지 확인 필요.
- **절대 IC = 0.05 수준**: "예측이 거의 안 맞는다" 가 아니라 "실무 임계점 위". 주식 예측은 잡음이 압도적이라 IC 0.05 가 좋은 수준.
- **단일 시기 평가**: 테스트 기간 (2020-2022) 이 다양한 국면 포함이지만, 다른 기간 (예: 2008 금융위기) 에 적용 시 다를 수 있음.

### 4.2 개선폭 (원문 abstract 및 웹 검색 스니펫)

- **Ranking 지표 (IC, Rank IC 계열)**: 전체 베이스라인 대비 **평균 +13% 개선**
- **포트폴리오 기반 지표**: 전체 베이스라인 대비 **평균 +47% 개선**
- **DTML vs MASTER**: 6개 전 지표에서 MASTER 우위, **$p < 0.01$ (통계적 유의성)**

### 🎯 +13% vs +47% — 왜 증폭되는가

**핵심**: Statistical metric 의 작은 차이가 portfolio metric 에서 크게 증폭.

**수학적 직관**:
- IC 0.05 → 0.057 (13% 개선) = 작은 차이로 보임
- 그러나 **상위 10% 종목 선택** 시: IC 0.05 모델은 상위 10% 의 평균 수익률이 시장 평균보다 +X%, IC 0.057 모델은 +X% × 1.5 (가까운 비율로 증폭).
- 이유: 상위 종목 선택 = **꼬리 분포** (top decile) 영향 → 작은 신호 차이가 증폭.
- **Equity premium puzzle 의 역방향 사례**: 작은 IC 가 누적 수익에서 큰 차이.

**구체 예시** (가상 수치):
- IC = 0.05 모델: 연간 누적 수익 +8% (시장 대비 +3%)
- IC = 0.057 모델: 연간 누적 수익 +12% (시장 대비 +7%)
- 차이: +50% 누적 수익 증가 → +47% 와 부합

### 4.3 CSI800 결과

- 모든 모델이 CSI300 대비 성능 저하 (종목 수 ↑ → 상관관계 복잡도 ↑)
- **MASTER 는 CSI800 에서도 베이스라인 대비 일관된 우위 유지** (원문 확인)
- 구체 수치: 원문 미확인

**의미**: 더 어려운 환경 (CSI800) 에서도 MASTER 의 우위 일관 → robustness 입증. 단일 환경 (CSI300) 만 평가는 cherry-picking 위험.

### 🔑 핵심 통찰

> MASTER 의 진정한 가치는 **단일 metric 의 우위가 아닌 6 metric 모두 + 두 데이터셋 모두 일관성**. 이게 진짜 SOTA 의 조건.

## 5. Ablation 해석

### 📖 Figure 4 (β ablation) 정밀 읽는 법

**무엇이 표시되나**:
- **단일 panel**
- **x축**: 온도 파라미터 $\beta$ 값 (대수 스케일 가능)
- **y축**: 성능 지표 (Rank IC 또는 누적 수익률)
- **곡선**: MASTER 의 $\beta$ 변화에 따른 성능
- **수평 점선**: market-guided gating 을 제거한 baseline 성능

**어디를 봐야 하나 (5 단계)**:

1. **곡선이 점선 위인 구간이 얼마나 넓은가?**: β = 0.5 ~ 5 정도면 robust. β = 0.8 ~ 1.2 만 좋으면 민감.
2. **곡선의 최고점은 어디?**: 그게 최적 β. 실무 배포 시 그 부근으로 설정.
3. **점선 아래로 떨어지는 구간 존재?**: 있으면 → 게이팅이 양날의 검 (잘못 쓰면 baseline 보다 나쁨).
4. **U자 형태**: $\beta \to 0$ (너무 강한 selection) 과 $\beta \to \infty$ (게이팅 무효화) 양쪽 끝에서 성능 저하. 중간 어딘가에 최적값.
5. **곡선의 비대칭**: 최적 β 의 좌우 (small β vs large β) 가 어느 쪽이 더 가파른지 → small β 가 더 가파르면 over-selection 의 위험 ↑.

**숨은 함정**:
- β 의 최적값이 dataset 별로 다를 수 있음 → 다른 데이터에서 sweet spot 다시 찾아야.
- y축이 단일 metric 만 → 다른 metric 에서 최적 β 가 다를 수 있음.
- 곡선의 noise (seed 별 variance) 가 크면 최적 β 부정확.

### 5.1 β (온도) ablation — Figure 4

**현상**:
- 수평 점선: 게이팅 없는 기준선 성능
- β가 매우 작을 때 (예: 0.01): 너무 강한 feature selection → 유효 팩터도 일부 차단 → 성능 저하
- β가 최적 구간일 때 (예: 1): 유효 팩터 선택 + 잡음 차단의 균형 → 최고 성능
- β가 매우 클 때 (예: 100): 게이팅 효과 소실 → 기준선 수준으로 수렴

**시사점**:
- 시장 유도 게이팅은 **적절한 β 선택에 민감**
- 실용적 배포 시 **β 를 검증 세트로 조율** 해야
- 자동 β 학습 (gradient-based) 가능성 검토 가치

### 5.2 (N1, N2) ablation

- $N_1$ = intra-stock attention block 수
- $N_2$ = inter-stock attention block 수

**예상 패턴** (원문 정확 수치 미확인):

| 설정 | 예상 성능 |
|------|---------|
| $(N_1, N_2) = (1, 1)$ | baseline |
| $(N_1, N_2) = (2, 2)$ | 향상 (depth 효과) |
| $(N_1, N_2) = (4, 4)$ | 약화 (overfitting) |
| $(N_1, N_2) = (0, 2)$ | 큰 약화 (intra 제거, cross-time relay 손실) |
| $(N_1, N_2) = (2, 0)$ | 큰 약화 (inter 제거, 종목간 정보 손실) |

**메시지**: $(N_1, N_2)$ 의 최적 조합은 데이터 의존적, 단순히 더 많은 layer 가 좋지 않음.

### 5.3 게이팅 제거 ablation (추정)

| 모델 변형 | Rank IC 변화 |
|----------|--------------|
| MASTER full | baseline (0%) |
| 게이팅 제거 (no gating) | **-5% ~ -15%** (추정) |
| 게이팅 + 학습 가능 fixed $g$ | 중간 |

### 🎯 구체 증거 — 어느 단계가 가장 중요?

원문 ablation 미직접 확인이지만, 설계 논리상:

1. **Cross-time relay (Intra → Inter)**: 가장 핵심 ← Intra 제거 시 큰 손실 예상
2. **시장 유도 게이팅**: 중요 ← Figure 4 ablation 으로 입증
3. **Temporal aggregation (마지막 시각 Query)**: 중간 ← 단순 mean pooling 으로 대체 가능
4. **Multi-head**: 약함 ← single-head 도 가능

## 9. 자기점검

### 핵심 5가지

1. **CSI300 vs CSI800 의 차이와 둘 모두 평가하는 이유?**
2. **7개 베이스라인의 진화 경로 (XGBoost → DTML → MASTER)?**
3. **6 metric 의 3 그룹과 각 그룹의 의미?**
4. **+13% statistical vs +47% portfolio — 왜 증폭되는가?**
5. **Ablation 으로 본 MASTER 각 단계의 중요도 순위?**

### 답변

1. **CSI300**: 대형주 300개, 유동성 ↑, 변동성 ↓, 잡음 ↓. 표준 벤치마크. **CSI800**: 대중소형 800개, 유동성 ↓, 변동성 ↑, fat-tail ↑. 더 어려운 환경. **두 환경 평가 이유**: (i) Cherry-picking 회피 — 단일 환경 (CSI300) 만 평가는 selection bias. (ii) Robustness 검증 — 더 어려운 환경 (CSI800) 에서도 우위 유지하면 generalization. (iii) 실무 적용성 — 운용자가 사용하는 유니버스 다양.

2. **단일종목 시점만 (XGBoost: 트리, 시간 X) → 시점 모델링 (LSTM/GRU/TCN/Transformer: 단일종목 시간) → 종목간 사전그래프 (GAT) → 종목간 학습가능 (DTML, time-aligned) → 시장 게이팅 + Cross-time relay (MASTER)**. 각 단계가 이전 단점 보완: XGBoost (시간 X) → LSTM (시간 ✓), Transformer (종목간 X) → GAT (종목간 ✓), GAT (사전 그래프) → DTML (동적), DTML (time-aligned) → MASTER (cross-time).

3. **Statistical (예측 강도)**: IC, Rank IC — 모델의 raw 신호 강도. **IR (시간 안정성)**: IC_IR, Rank IC_IR — 시간에 따른 일관성. **Portfolio (실무 운용)**: 누적 수익률, Sharpe — 상위 종목 매수 시 운용 가치. 의미: 단일 metric 우위는 부족, 3 그룹 모두 우위면 진짜 SOTA.

4. **증폭 메커니즘**: Statistical metric (IC) 은 전체 종목 평균 상관 측정 — 작은 차이는 작게 보임. Portfolio metric 은 **상위 $k\%$ 종목** 만 선택 — 꼬리 분포 (top decile) 의 효과 증폭. **수학적 직관**: IC 0.05 → 0.057 (13% 개선) → 상위 10% 종목 평균 수익률 0.5%/일 → 0.7%/일 (40% 개선). 누적 효과 (복리) 면 더 큰 차이. **재무 직관**: 좋은 종목을 더 정확히 골라낼수록 portfolio 수익 quadratic 증폭.

5. **추정 순위 (원문 ablation 정확 수치 미확인)**: **(1) Cross-time relay (Intra→Inter 순서, intra 제거 시 가장 큰 손실)**. **(2) 시장 유도 게이팅 (Figure 4 로 입증, 5-15% 손실)**. **(3) Temporal aggregation (마지막 시각 Query, 단순 mean 으로 대체 가능, 약한 손실)**. **(4) Multi-head (single-head 도 가능)**. 가설: cross-time relay 가 단일 가장 큰 contributor, 게이팅이 두 번째.
