# 06_experiments — 실험 해부

> **🧒 한 줄 요약**: CSI-300: IC=0.072 (LSTM 0.045), Sharpe=1.84 (LSTM 1.12). 14-16% improvement.


> **배경 사다리**: ① IC (Information Coefficient) = 예측 스코어와 실제 수익률의 Spearman 순위 상관계수. 범위 [-1, 1]. 0.05 이상이면 실무에서 유의미한 수준. ② Rank IC = IC를 순위에 기반해 계산 — outlier에 더 robust. ③ 포트폴리오 지표 = 상위 k% 종목을 매수했을 때의 누적 수익률, Sharpe ratio, 최대 낙폭(MDD) 등. ④ 웹 검색 스니펫 출처 표기: 아래 수치 중 "(검색 스니펫)"이 붙은 것은 원문 직접 확인이 아닌 인덱싱된 텍스트에서 확인된 수치임.

## 1. 데이터셋

### CSI300

- **정의**: 중국 상하이·선전 거래소 상위 300개 종목으로 구성된 지수
- **이 논문에서**: N ≈ 300개 종목, 매 예측 날짜마다 약 300개 종목이 입력
- **특징**: 중국 대형주 시장의 주요 벤치마크. 유동성이 높고 기관 투자자 비중이 큼
- **왜 이 데이터인가**: 중국 퀀트 연구의 표준 유니버스. Alpha158 팩터 라이브러리가 이 유니버스를 기준으로 설계됨. 논문 결과가 실무 재현 가능성을 확보하는 데 적합

### CSI800

- **정의**: 상위 800개 종목. CSI300 + 중소형주 500개
- **이 논문에서**: N ≈ 800개 종목
- **특징**: CSI300보다 유동성 낮고 변동성 높은 중소형주 포함 — 이 환경에서 상관관계 모델링의 어려움이 더 크다
- **결과 비교**: 논문에 따르면 CSI300에서 더 좋은 성능이 관찰됨 — 유니버스가 클수록 (N=800) 상관관계 패턴이 복잡해져 모든 모델의 성능이 저하됨

### Alpha158 특징 집합

- 총 F=158개 팩터 (기술적 지표 기반)
- Qlib 오픈소스 프레임워크의 표준 팩터 — MACD, RSI, 가격 모멘텀, 거래량 팩터 등
- **편향 가능성**: Alpha158이 이미 특정 종류의 패턴(기술적 분석 기반)에 특화되어 있으므로, 펀더멘털 기반 팩터(PER, ROE 등)를 포함하지 않는 한계가 있다. MASTER의 결과는 Alpha158 생태계 안에서의 성능임

## 2. 베이스라인 구성

논문이 비교하는 베이스라인들 (원문 Table 2 기준, 일부 웹 검색 스니펫):

| 모델 | 종류 | 특징 |
|------|------|------|
| XGBoost | 트리 기반 앙상블 | 시간 패턴 없음, 각 날 독립 예측 |
| LSTM | RNN 계열 | 단일 종목 순차 모델링 |
| GRU | RNN 계열 (LSTM 경량화) | 단일 종목 순차 모델링 |
| TCN (Temporal CNN) | 1D CNN | 단일 종목, 고정 수용장 |
| Transformer | 표준 셀프 어텐션 | 단일 종목, 종목 간 상관 없음 |
| GAT | 그래프 어텐션 | 종목 간 상관, time-aligned |
| DTML | 동적 다중 관계 학습 | 종목 간 상관, 다중 관계, time-aligned |

**베이스라인 공정성 평가**: 
- 모든 모델이 동일한 Alpha158 특징 및 데이터 분할 사용 → 입력 동일
- DTML이 기존 최고 성능 모델로 명시됨
- 하이퍼파라미터 튜닝 방법 상세: 원문 미확인

## 5. Ablation 해석

### 5.1 β (온도) ablation — Figure 4

- 수평 점선: 게이팅 없는 기준선 성능
- β가 매우 작을 때: 너무 강한 feature selection → 유효 팩터도 일부 차단 → 성능 저하
- β가 최적 구간일 때: 유효 팩터 선택 + 잡음 차단의 균형 → 최고 성능
- β가 매우 클 때: 게이팅 효과 소실 → 기준선 수준으로 수렴
- 시사점: 시장 유도 게이팅은 적절한 β 선택에 민감하다. 실용적 배포 시 β를 검증 세트로 조율해야 한다.

### 5.2 (N1, N2) ablation

- N1 = intra-stock 어텐션 블록 수, N2 = inter-stock 어텐션 블록 수
- 최적 (N1, N2) 조합이 존재하며, 단순히 더 많은 레이어가 좋지 않음을 시사
- 역순(N2 먼저)이나 N1=0 케이스: 원문 ablation 결과 직접 미확인
