Overview

혼자 쓰는 실전형 홀덤 연습장

이 프로젝트는 단순 카드 게임보다 "왜 졌는지 계속 남는 연습 환경"에 초점을 맞췄습니다. 사용자는 혼자 입장하고, 나머지 7석은 각기 다른 성향의 AI가 채웁니다. AI는 핸드 강도만 보지 않고 포지션, 팟 압박, 보드 텍스처, 사용자의 누적 플레이 성향을 반영해 결정을 내립니다.

Table
8인 텍사스 홀덤
한 명의 사용자와 7명의 AI가 블라인드, 포지션, 스트리트, 쇼다운 흐름을 따라 플레이합니다. UI는 모바일과 데스크톱에서 같은 흐름으로 접근할 수 있게 구성했습니다.
Pressure
하루 2회 뱅크롤 지급
칩을 모두 잃으면 바로 무한 재도전할 수 없습니다. 정해진 지급 횟수 안에서 버티고, 이기면 계속할 수 있는 구조로 긴장감을 만들었습니다.
Review
패배 분석과 복기
큰 팟 손실, 쇼다운 패배, 얇은 레이즈 같은 패턴을 기록합니다. 핸드별로 당시 승률과 상대 족보를 남겨 다음 판단의 근거로 쓰게 했습니다.
Training Loop

한 판을 끝내고 바로 배우는 흐름

게임의 핵심 루프는 입장, 핸드 플레이, 결과 확인, 복기, 다음 핸드입니다. 사용자가 진 뒤에도 결과 로그가 남아서 같은 실수를 반복하는지 확인할 수 있습니다.

01
Private Access
키 번호가 포함된 링크로 입장합니다. 공개 게임보다 개인 연습 테이블에 가깝게 설계했습니다.
02
AI Pressure
각 AI는 다른 스타일로 폴드, 콜, 레이즈를 선택하고 때로는 진실인지 유도인지 모를 멘트를 던집니다.
03
Hand Result
승패, 팟, 쇼다운 족보, 손실 칩을 즉시 기록합니다. 큰 팟에서는 경고성 코칭을 더 강하게 표시합니다.
04
Replay
스트리트별 액션을 다시 보고, 어떤 지점에서 무리했는지 복기합니다.
Systems

AI와 기록 시스템

프로급 솔버를 완전히 구현한 것은 아니지만, 단순 랜덤 AI와는 다르게 느껴지도록 플레이 근거와 압박 장치를 넣었습니다. 중요한 것은 사용자가 "상대가 생각하고 있다"는 감각과 "내 실수가 누적된다"는 감각을 받는 것입니다.

Opponent AI
프리플랍 차트, 포지션, 핸드 강도, 팟 크기, 공격 성향을 섞어 의사결정합니다. Solver Max, Cold 4Bet, Final Boss처럼 이름과 성향이 다른 상대를 둬 테이블 분위기가 매번 다르게 보이게 했습니다.
Table Talk
AI 멘트는 전부 힌트가 아닙니다. 일부는 진짜 강함을 드러내고, 일부는 콜을 유도하거나 겁주는 식으로 작동합니다. 한국어 멘트만 남기도록 정리했습니다.
Weakness Log
쇼다운 패배, 큰 팟 손실, 얇은 레이즈, 약한 콜 같은 항목을 누적 기록합니다. 단발 결과보다 반복되는 약점을 보기 위한 장치입니다.
Ledger Guard
서버 세션 장부는 서명 토큰과 전환 검사를 사용합니다. 비정상적인 칩 증가나 지급 횟수 조작은 저장 단계에서 거부되도록 만들었습니다.
AI Strength

목표는 "진짜 솔버 엔진"이 아니라, 사용자가 방심하면 계속 압박받는 프로/GTO 연습 상대입니다. 그래서 AI는 강한 범위에서 공격하고, 사용자가 너무 자주 접거나 큰 팟에서 얇게 따라가는 패턴을 보이면 그 성향을 이용합니다.

Guardrails

의도적으로 정한 범위

Solo Only
멀티플레이 서버가 아님
초대 링크는 접속 편의를 위한 것이고, 실시간 여러 유저가 같은 테이블에 앉는 구조는 아닙니다. 지금 버전은 혼자 연습하는 데 집중했습니다.
No Gambling
실전 돈 거래 없음
게임머니는 학습 압박을 만들기 위한 장치입니다. 결제, 환전, 실제 베팅 기능은 없습니다.
Practice Tool
GTO 학습 보조
AI는 솔버식 압박을 흉내 내는 연습 상대입니다. 완전한 상용 솔버나 실제 프로 플레이어의 대체물은 아닙니다.
Stack

구현 스택

Frontend
Vanilla HTML/CSS/JavaScript
게임 UI, 카드 렌더링, 테이블 상태, 리플레이, 로컬 접근 키 처리를 별도 프레임워크 없이 구현했습니다.
Engine
Poker Engine
engine.js에서 덱, 셔플, 족보 평가, 승률 추정, 멀티 상대 equity 계산을 분리했습니다.
Runtime
OpenAI Sites Runtime
정적 앱을 빌드해 Sites 서버 엔트리로 묶고, 장부 API를 통해 세션 저장과 조작 방어를 처리합니다.
